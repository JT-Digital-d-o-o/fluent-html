# `LinkTag` missing `hreflang` typed setter — i18n apps use `addAttribute('hreflang', ...)`

## Problem

`LinkTag` (returned by `Link()`) covers the typed setters for `rel`, `href`, `type`, `media`, `sizes`, `crossorigin`, `integrity`, and `as` — but not `hreflang`. The `hreflang` attribute is standard for `<link rel="alternate">` tags in multilingual sites. Without a setter, apps fall back to `.addAttribute("hreflang", ...)`, which the guidelines explicitly say to avoid for standard HTML props.

## Evidence

```ts
// jtdigital-landing-page/src/shared/seo.ts:295-299
ForEach(props.alternates!, (alt) =>
  Link()
    .setRel("alternate")
    .addAttribute("hreflang", alt.hreflang)   // ← escape hatch for a standard attribute
    .setHref(alt.href)
)
```

```ts
// jt-cut/src/shared/components/layout.view.ts:143
Link().setRel("alternate").addAttribute("hreflang", loc).setHref(`...`)
// jt-cut/src/shared/components/layout.view.ts:145
Link().setRel("alternate").addAttribute("hreflang", "x-default").setHref(`...`)
```

```ts
// filmplast-v2/src/shared/seo.ts:207-217
const entries = Object.entries(hreflangMap) as [Locale, string][];
return [
  ...entries.map(([, lang]) =>
    Link().setRel("alternate")
      .addAttribute("hreflang", lang)   // ← escape hatch
      .setHref(`${config.url}/${lang}`)
  ),
  Link().setRel("alternate")
    .addAttribute("hreflang", "x-default")   // ← escape hatch
    .setHref(`${config.url}/en`)
];
```

`LinkTag._sk` in `document.ts:134` is `['rel', 'href', 'type', 'media', 'sizes', 'as', 'crossorigin', 'integrity']` — `hreflang` is absent.

## Why it matters

`hreflang` is a first-class SEO attribute used by every multi-language site to signal language alternates to Google. Its absence from `LinkTag` pushes 4 apps (and more when i18n is added) to the `addAttribute` escape hatch. The CLAUDE.md project guideline says "never `addAttribute` for standard HTML props" but the library doesn't provide the typed alternative for this specific attribute.

## Rough idea (not a design)

Add `setHreflang(hreflang?: string): this` to `LinkTag` and append `'hreflang'` to `LinkTag._sk`. One-liner change; the attribute serializes exactly as its name. Also consider `setTitle(title?: string)` for `<link rel="alternate" title="...">` which is similarly used by feed discovery.
