# `textAlgebra` reconstructs `new Set([...blockElements])` on every `tag()` call

## Problem

`textAlgebra` is the canonical algebra for extracting plain-text content from a `View` tree. Its `tag` callback creates a brand-new `Set` containing 18 block-element names **on every invocation** — once per `Tag` node in the tree:

```ts
// src/fold/algebras/text.ts:16-22
tag: (element, _, childText) => {
  // Block-level elements get newlines
  const blockElements = new Set([
    'p', 'div', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
    'li', 'dt', 'dd', 'blockquote', 'pre', 'br',
    'article', 'section', 'header', 'footer', 'nav', 'aside',
    'tr', 'th', 'td'
  ]);

  if (blockElements.has(element)) {
    return childText + "\n";
  }
  return childText;
},
```

For a realistic page of ~200 tags, this creates and immediately discards 200 `Set` instances, each containing 18 string entries. The `Set` constructor must hash all 18 strings on every call.

## Evidence

`src/fold/algebras/text.ts:16` — `const blockElements = new Set([...])` is inside the `tag` arrow function body, not at module scope. Every `foldView(textAlgebra, view)` call triggers this allocation for every `Tag` node in the tree.

Contrast with `render.ts:8-11` where the equivalent `VOID_ELEMENTS` set is correctly hoisted to module scope and shared across all render calls.

## Why it matters

`foldView(textAlgebra, ...)` is the standard way to extract text for accessibility auditing, search indexing, or content hashing. On a realistic 200-tag page it wastes 200 × 18-string-Set allocations per traversal. The fix is a one-line hoist with zero behavior change. This also sets a bad precedent for future algebras authored by app developers who copy this pattern.

## Rough idea (not a design)

Move `blockElements` to module scope as a `const`:

```ts
// src/fold/algebras/text.ts — BEFORE (per-call inside tag callback)
const blockElements = new Set([...]);

// AFTER — module-level, allocated once at import time
const BLOCK_ELEMENTS = new Set([
  'p', 'div', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
  'li', 'dt', 'dd', 'blockquote', 'pre', 'br',
  'article', 'section', 'header', 'footer', 'nav', 'aside',
  'tr', 'th', 'td'
]);

export const textAlgebra: ViewAlgebra<string> = {
  tag: (element, _, childText) =>
    BLOCK_ELEMENTS.has(element) ? childText + "\n" : childText,
  // ...
};
```
