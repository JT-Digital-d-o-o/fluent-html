# No regression test for render stack-overflow at deep nesting (~3468 depth)

## Problem

The recon measured that `render(deep(3500))` throws `Maximum call stack size exceeded` between depth 3468 and 3500. This is a correctness bug. Despite being a known, measured failure mode, there is no test that exercises it. The deepest nesting tests in the suite are:

- `stream.test.ts:38` — 4 levels (`Div(Div(Div(Div(Span("Deep")))))`)
- `composition.test.ts:215` — 5-6 levels (Header/Nav/Main/Article/Footer)

Neither approaches the overflow boundary.

## Evidence

```ts
// test/stream.test.ts:38
it("renders deeply nested", async () => {
  const view = Div(Div(Div(Div(Span("Deep")))));
  assert.equal(await streamToString(view), render(view));
});

// test/composition.test.ts:215
it("Variadic deeply nested", () => {
  assert.strictEqual(render(Div(
    Header(Nav(A("Link").setHref("#"))),
    Main(Article(H1("Title"), P("Body"))),
    Footer(P("Footer"))
  )), `...`);
});
```

The recon explicitly documented the limit:

> "linear nesting `Div(Div(...Span))` overflows the call stack **between depth 3468 and 3500**. 1000 is fine, 5000 throws."
> — `00-recon/04-performance.md:97`

And the render path is purely recursive (`render.ts:240`, `stream.ts:182`). No test covers this boundary.

## Why it matters

Without a test:
1. The stack-overflow bug can silently regress (no fix is validated).
2. When the de-recursion RFC (F-D-001 / render work-stack) lands, there is no CI gate to confirm it actually raises the depth ceiling.
3. Apps that render recursive data structures (comment threads, nested menus, generated trees) hit this in production with no warning.

Frequency is 1 (the lib itself), but pain is high because the failure is a hard crash with no graceful recovery.

## Rough idea (not a design)

Add `test/deep-render.test.ts` with two cases:
- `assert.throws(() => render(makeDeep(3500)), /call stack/)` — confirms the current limit is not accidentally raised before de-recursion lands.
- After de-recursion merges, flip the assertion to `assert.doesNotThrow(() => render(makeDeep(10_000)))`.

`makeDeep(n)` is a simple helper: `let v = Span("leaf"); for (let i = 0; i < n; i++) v = Div(v); return v;`.

Wire the test into `npm test` alongside the existing suite.
