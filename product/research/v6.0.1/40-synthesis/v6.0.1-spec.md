## Lane 6.0.1 — Track A (correctness, behavior-only, no public-shape change)

**Narrative.** Six pure serialization/correctness fixes. Nothing in the public API changes
shape (`api_surface: []` across the board); output differs only for inputs that were already
malformed, malicious, or incorrect. Three cluster in `src/render/serialize.ts` and must land in
the order **A-006 → A-003 → A-007** (A-007 leaves the `hx-preload` line A-006 owns untouched);
A-003 + A-006 share a single edit to the `render ≡ renderToIterable` parity-fixture suite. The
theme of the track: make the runtime honor contracts the types already promise — closing XSS
holes, eliminating invalid duplicate-attribute HTML, repairing route-param substitution and the
HTMX serialization grammar, and turning on the dormant context test suite.

### RFC-A-001 — Boundary-aware route-param substitution `[6.0.1, P1]`

```ts
// internal only — no public symbol changes (api_surface: [])
function substituteParams(template: string, params: Record<string, string | number>): string;
function escapeRegExp(literal: string): string;
// both defineRoutes() route callables and .resolve() now call substituteParams,
// matching `:name` with a `(?![A-Za-z0-9_])` boundary lookahead and the /g flag.
```
*Rationale:* one shared, boundary-aware helper replaces two naive `String.replace(":name", …)`
loops so `:id` never matches inside `:idCard` and repeated params resolve all occurrences.

### RFC-A-002 — Context sync-only contract + CI test wiring `[6.0.1, P1]`

```ts
// no API change. createContext / createRequiredContext gain JSDoc stating the contract:
//   a scope is valid only on one uninterrupted synchronous call stack —
//   never hold an `await` open while a scope is live.
// package.json: add dist/test/context.test.js to `test` + `test:coverage`.
// stream.test.ts: add a scoped-context-read-during-streaming isolation test.
```
*Rationale:* the process-global value stack is safe only synchronously; document the boundary
(no async-isolation dep) and wire the previously-dead context + streaming tests into CI.

### RFC-A-003 — Eliminate duplicate-attribute emission `[6.0.1, P0]`

```ts
// internal only (api_surface: []) — in buildAttrs (src/render/serialize.ts):
const RESERVED_BAG_KEYS = new Set(['id', 'class', 'style']);  // dedicated setter wins; bag key skipped
// toggles: dedup by name + skip a name already emitted via reserved field or the generic bag.
// Precedence: dedicated setter > generic bag > bare boolean toggle.
```
*Rationale:* every attribute name must be emitted at most once — kills `disabled disabled` from
repeated `.toggle()` and `id="a" id="b"` from a setter colliding with `addAttribute`.

### RFC-A-004 — Extractor ↔ eslint class-vocab integrity `[6.0.1, P2]`

```ts
// tooling/test only; one generated symbol in the eslint plugin (non-semver-public):
export const VOCAB_UNITS: readonly string[];   // vocab.generated.ts — projection of lib UNITS
function blankVariantBodies(content: string): string;          // strip nested .on/.at before flat scan
function extractDefaultClasses(content: string): string[];     // (...) matched only inside [...]
function classEmittersMissingFromVocab(sources: string[]): string[];  // reverse parity guard
```
*Rationale:* kills spurious/partial-prefix and swallowed-call-expression classes, single-sources
the CSS unit list, and adds the reverse parity guard — this RFC **is** the lockstep machinery that
polices B-010 in 6.1.0.

### RFC-A-006 — Close three escape/injection holes `[6.0.1, P0 — security]`

```ts
// internal only (api_surface: []):
// 1. hx-preload string branch now routes through escapeAttr (serialize.ts).
// 2. setDataAttrs validates the computed data-* key via validateAttributeKey (core/tag.ts) — like setAria.
// 3. sanitizeRawContent neutralizes the state-arming openers, not just the closer:
const SCRIPT_OPENER_RE = /<!--|<script/gi;   // → <\!-- / <\script, blocking the double-escaped state
```
*Rationale:* closes an `hx-preload` attribute break-out, a `data-*` attribute-name injection, and
the `<script>` double-escaped break-out — all reachable from untyped/runtime-derived input.

### RFC-A-007 — HTMX serialization grammar repair `[6.0.1, P1]`

```ts
// internal only (api_surface: []):
function buildStatusConfig(cfg: HxStatusConfig): string;  // multi-word swap modifiers stay bound to swap:
class HxResponse {
  private _triggers: Map<string, Record<string, unknown> | null>;  // structured accumulator
  // serialized once at getHeaders(): all-bare → "a, b"; mixed/detailed → JSON object form
}
if (htmx.ignore) result += ' hx-disable';   // bare boolean — replaces inert hx-ignore="true"
```
*Rationale:* honors the `HxSwap` modifier grammar, stops `HX-Trigger` losing
JSON-parseable event names, and emits the real `hx-disable` instead of the no-op `hx-ignore="true"`.

## Lane 6.1.0 — Track B (HTML platform, additive)

**Narrative.** Two additive RFCs widen the HTML platform surface. B-008 retires the bare-string
head-element setters (the absorbed Track-D type debt F-D-101/F-D-102) and adds the
`fetchpriority` Core-Web-Vitals hint; B-010 brings native interactivity — Popover, invoker
Commands, and CSS anchor positioning — replacing hand-written `showModal()`/`close()` JS with
typed, nonce-free attributes. Every change is additive: open-union widenings keep all v6.0.0
callers compiling, and new setters/types collide with nothing. B-010 is the **only** class-emitting
survivor — its three `custom()` vocab rows + regenerated `vocab.generated.ts` + drift test must
land atomically with the emitters, or A-004's reverse-parity guard (shipped in 6.0.1) fails CI.

### RFC-B-008 — fetchpriority + head-element literal unions `[6.1.0, P0]`

```ts
// new types (src/elements/html-types.ts):
type FetchPriority = 'high' | 'low' | 'auto';                       // closed
type LinkElementRel = 'stylesheet'|'icon'|…|'preconnect'|'preload'|'modulepreload'|… | (string & {});
type LinkAs   = 'font'|'style'|'script'|'image'|… | (string & {});
type LinkType = 'text/css'|'font/woff2'|… | (string & {});
type ScriptType = 'module'|'importmap'|… | (string & {});
type MetaName = 'viewport'|'description'|'theme-color'|… | (string & {});
type Charset  = 'utf-8' | (string & {});

// new setter (copied per class — no shared ancestor):
ImgTag/LinkTag/ScriptTag/IframeTag.prototype.setFetchPriority(fetchpriority?: FetchPriority): this;

// retyped (bare string → open union; runtime byte-identical):
LinkTag.setRel(rel?: LinkElementRel)   LinkTag.setAs(as?: LinkAs)   LinkTag.setType(type?: LinkType)
ScriptTag.setType(type?: ScriptType)   MetaTag.setName(name?: MetaName)   MetaTag.setCharset(charset?: Charset)
BaseTag.setTarget(target?: BrowsingContext)   // reuses existing union
```
*Rationale:* typed resource hints + LCP priority promotion for the Core-Web-Vitals surface, with
`<link rel>` given its own grammar (`LinkElementRel`) distinct from anchor `LinkRel`.

### RFC-B-010 — Native Popover, Commands, anchor positioning `[6.1.0, P1 — class-emitting, lockstep]`

```ts
// Popover (any element) — closed unions, Id-typed target:
type PopoverState  = "auto" | "manual";
type PopoverAction = "show" | "hide" | "toggle";
Tag.prototype.setPopover(state?: PopoverState): this;
Tag.prototype.setPopovertarget(target: Id): this;
Tag.prototype.setPopovertargetaction(action?: PopoverAction): this;

// Invoker Commands (<button> only):
type CommandFor = "show-modal"|"close"|"request-close"|"show-popover"|"hide-popover"|"toggle-popover"|`--${string}`;
ButtonTag.prototype.setCommand(command: CommandFor): this;
ButtonTag.prototype.setCommandfor(target: Id): this;

// CSS anchor positioning (class emitters — register custom() vocab rows in lockstep):
type TailwindPositionArea = "top"|"bottom"|"left"|"right"|"center"|"top-left"|… | `[${string}]`;
Tag.prototype.anchorName(name: Id): this;      // → [anchor-name:--<id>]
Tag.prototype.positionAnchor(name: Id): this;  // → [position-anchor:--<id>]
Tag.prototype.positionArea(area: TailwindPositionArea): this;  // → position-area-<area>
```
*Rationale:* typed, zero-JS, nonce-free primitives for open/close and placement that map 1:1 to
native platform features — `openDialog`/`closeDialog` behaviors remain (no removal).

## Lane 6.1.0 — Track C (DX abstractions, additive)

**Narrative.** One additive RFC fills the two control-flow shapes the existing combinators can't
express — value→value mapping and independent-predicate chains — plus a separator combinator. All
three parallel the shipped `Match`/`ForEach` overload shape, emit no new markup, and preserve
(or tighten) the caller's literal types. New names only; zero collision with the index export list.

### RFC-C-005 — MatchValue / Cond / Intersperse `[6.1.0, P1]`

```ts
// src/control/match-value.ts — value-returning sibling of Match (returns the value's union, not View):
function MatchValue<T extends string|number, R>(value: T, cases: { [K in T]: R }): R;               // exhaustive
function MatchValue<T extends string|number, R, D>(value: T, cases: Partial<{[K in T]: R}>, def: D): R | D;

// src/control/cond.ts — first-truthy-wins guard chain (mandatory default; eager predicates):
function Cond<R, D>(branches: ReadonlyArray<readonly [boolean, R]>, defaultValue: D): R | D;

// src/control/iteration.ts — separator between mapped Views, never after the last:
function Intersperse<T>(items: Iterable<T>, renderItem: (item: T, index: number) => View,
                        separator: View | (() => View)): View;
```
*Rationale:* recovers the literal union that ternaries erase to `string` (`MatchValue`), models
independent-predicate chains `Match` can't (`Cond`), and gives `ForEach` + separator the `Array.join`
analogue (`Intersperse`) — `Join` folds into `Intersperse`, no `pick` alias (converge).

## Priorities & sequencing

**6.0.1:** P0 = A-006 (security), A-003 (invalid-HTML on every page) · P1 = A-001, A-007, A-002 ·
P2 = A-004 (tooling safelist; over-broad only bloats CSS, never breaks a page).
**6.1.0:** P0 = B-008 (broadest reach, no class-vocab touch) · P1 = B-010, C-005.

**Merge-blocking sequencing (hygiene, not redesign):**
1. `serialize.ts`: land A-006 → A-003 → A-007; A-007 must not re-touch A-006's `hx-preload` line.
2. A-003 + A-006 add `render ≡ renderToIterable` parity fixtures in one shared edit.
3. CHANGELOG: collapse to a single `[6.0.1]` (`### Security`/`### Fixed`/`### Docs & Tests`) + a
   single `[6.1.0]` (`### Added`) section.
4. B-010 vocab rows + regenerated `vocab.generated.ts` + drift test land atomically with the emitters.
5. Pin the exact htmx4 `hx-disable` name with a test before A-007 merges.
6. Assign doc-section ownership for the multi-RFC guideline files (`fluent-html.md`, `htmx.md`, `CLAUDE.md`).

## Parked-major ledger (do NOT ship in 6.0.x / 6.1.0)

- A-003 — `addAttribute("id"|"class"|"style", …)` compile-time-excluding overload (would break compiling code).
- A-007 — rename the `disable` (disabledElt) emitted attribute so it never shares `hx-disable` with `ignore`.
- A-002 — true async-isolated context (`AsyncLocalStorage` / render-id token) — contradicts zero-deps + sync hot path.
- B-010 — eventual deprecation/removal of `openDialog`/`closeDialog` behaviors.

## Class-vocab lockstep (Guardrail 7)

B-010 is the **only** class-emitting survivor (3 emitters: `anchorName`, `positionAnchor`,
`positionArea`). A-004 single-sources `UNITS` via generated `VOCAB_UNITS` and adds the
reverse-parity guard; shipping in 6.0.1, it polices B-010 in 6.1.0 — B-010 **must** register its
three `custom()` rows or A-004's guard fails CI. B-008 and C-005 emit no classes.

## Rejected (for the record)

RFC-C-009 (Form<T> binding completeness) — rejected upstream, **not** reinstated; no survivor depends on it.
