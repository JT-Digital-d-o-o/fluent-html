# Juxtaposition: RFC-A-007 vs. Wave-3 verdicts vs. shipped code

RFC-A-007 bundled three serialization fixes. **Fix 2** (structured trigger
accumulator) and **Fix 3** (`ignore` → bare `hx-disable`) shipped and are tested.
**Fix 1** (the `buildStatusConfig` spaced-swap split) was **deliberately reverted**
during implementation — the shipped serializer (`serialize.ts:216-225`) is the
original `'swap:' + cfg.swap` flatten form. The correctness verdict had already
proven Fix 1 a byte-level no-op (`join(' ')` re-flattens the split identically), so
reverting it is consistent with that verdict — but it means every Fix-1-shaped
required_change is now either moot (the code-vs-prose contradiction, the no-op
attack) or a still-latent defect that the revert did NOT address (spaced `target`/
`select` orphaning under F-A-121; the unverified htmx grammar; the missing
spaced-swap regression test). Several doc updates the RFC promised (the `ignore`
JSDoc, the htmx.md spaced-swap note, the htmx.md trigger-accumulation note) did not
ship.
