# Juxta: RFC-C-005 vs. Wave-3 verdicts vs. shipped code

reconciliation `Cond` was **dropped** (verdict's correctness change: eager
`[bool,val]` tuples evaluate every predicate, unlike a short-circuiting ternary —
not a drop-in). Shipped: `MatchValue` (`src/control/match-value.ts`) +
`Intersperse` (`src/control/iteration.ts:119`), both exported from `src/index.ts`
and tested in `test/control-flow.test.ts`. One verdict file
(`V-RFC-C-005-combined.md`) with 4 `required_changes`, killer_objection: null.

## Notes on the implementation beyond the verdict

- `MatchValue` uses `Object.prototype.hasOwnProperty.call(cases, value)` rather
  than `value in cases` (`match-value.ts:32`) — correctly distinguishes a present
  key with a falsy value (`""`, `0`) from an absent one, returning the value not
  the default. Verified by the test at `control-flow.test.ts:266-268`. Sound.
- `Intersperse` accepts any `Iterable<T>` and iterates with a `for…of` + index
  counter (`iteration.ts:124-131`), consistent with `ForEach`'s single-pass
  iterable support. The thunk separator is invoked per-gap inside the loop, never
  for the last item. Sound.
