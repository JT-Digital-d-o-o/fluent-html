# buildStatusConfig flattens a modifier-bearing HxSwap into space-delimited tokens, orphaning the modifier

## Problem
`HxStatusConfig.swap` is typed `HxSwap`, which includes modifier strings such as `"outerHTML scroll:top"` (a space-separated style+modifier). `buildStatusConfig` serialises each status directive as `key:value` and joins them with a **single space**. A swap value that itself contains a space therefore produces tokens that htmx will mis-parse: the modifier becomes a free-floating token and any directive after it is detached from `swap`.

## Evidence

```ts
// src/htmx.ts:177-185 — swap accepts a full HxSwap (incl. modifiers)
export type HxStatusConfig = {
  swap?: HxSwap;       // e.g. "outerHTML scroll:top"
  target?: HxTarget;
  select?: string;
  ...
};
```

```ts
// src/render/serialize.ts:211-220
function buildStatusConfig(cfg: HxStatusConfig): string {
  const parts: string[] = [];
  if (cfg.swap) parts.push('swap:' + cfg.swap);
  if (cfg.target) parts.push('target:' + cfg.target);
  ...
  return parts.join(' ');
}
```

Reproduction:

```
buildStatusConfig({ swap: "outerHTML scroll:top", target: "#main" })
// → "swap:outerHTML scroll:top target:#main"
//                       ^^^^^^^^^^ orphaned: not attached to swap:, parsed as its own token
```

The intended directive `swap:outerHTML` with a `scroll:top` modifier collapses; htmx sees three space-separated tokens (`swap:outerHTML`, `scroll:top`, `target:#main`) and the scroll behaviour is silently lost or misapplied.

## Why it matters
`hx-status:<code>` is the sanctioned way to special-case error responses (e.g. `5xx → swap an error panel with a scroll-to-top`). Anyone who passes a perfectly valid `HxSwap` (the type invites it) with a modifier gets a broken attribute and no compile-time or runtime warning. Low frequency but a clear correctness hole where the type contract and the serializer disagree.

## Rough idea (not a design)
Patch (6.0.1): tighten `HxStatusConfig.swap` to `HxSwapStyle` (no embedded spaces possible) — this is the conservative fix and arguably the only shape htmx’s per-status config supports cleanly. If full `HxSwap` must stay, join the directives with a delimiter htmx tolerates for grouped sub-directives rather than a bare space. Validate the chosen direction against the htmx 4 `hx-status` grammar in Wave 2.
