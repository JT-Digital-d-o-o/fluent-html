# `view-transition-name` is unreachable as a typed primitive

## Problem
The View Transitions API (same-document + the newer cross-document `@view-transition`) is the marquee TW4-era platform feature for animating SSR/HTMX navigations. To opt an element into a named transition you must set the CSS `view-transition-name` property on it. fluent-html has no method for this, and it isn't a class in the vocab — the `transition` family stops at `transition`/`duration`/`animate`/`ease` (vocab.ts:177-181), all of which are the *old* CSS transitions, not the View Transitions API. The only way to tag a hero image so it morphs across an HTMX swap today is `Img().addAttribute("style", "view-transition-name: hero")` — an untyped inline-style string that bypasses the class-vocab entirely and isn't safelistable.

## Evidence
```ts
// src/class-vocab/vocab.ts:177  — Transitions & Animation section
opt("transition", "transition"),
pre("duration", "duration"),
pre("animate", "animate"),
pre("ease", "ease"),
```
Grep for `view-transition` / `viewTransition` across `src/` returns only SVG `text-anchor` false-positives — the capability is entirely absent.

## Why it matters
This is the core's most-natural intersection with HTMX: `outerMorph` swaps + named view transitions are how a v6 SSR app gets app-like animated navigation. Because every page is server-rendered, the *only* place to emit `view-transition-name` is at render time — exactly fluent-html's job. Leaving it to `addAttribute("style", …)` means no type safety, no Tailwind purge-safety, and no autocomplete on a feature the framework otherwise actively encourages.

## Rough idea (not a design)
Additive (6.1.0): a `.viewTransitionName(name: string | Id)` method that emits TW4's arbitrary-property utility `[view-transition-name:NAME]` (purge-safe, single class) with an `Id` overload so it can be wired to a `defineIds` target. Register the `[view-transition-name:…]` shape in the extractor/eslint vocab as a sanctioned arbitrary property. Pairs with a future `@view-transition` `<meta>`/`<link>` helper but the per-element name is the primitive.
