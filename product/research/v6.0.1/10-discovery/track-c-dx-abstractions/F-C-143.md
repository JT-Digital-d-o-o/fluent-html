# Error wiring is one-sided — the input never learns it's invalid

## Problem
`f.error(name)` renders the message span, and `f.input(name)` wires the value, but the two never connect. A bound input with an error gets no `aria-invalid="true"` and no `aria-describedby` pointing at its message. So the binding wires *prefill* end-to-end but wires *validation* only halfway: the visible message appears, but the control is not programmatically marked invalid for assistive tech or for the `aria-invalid:`/`invalid:` Tailwind variant (which the vocab already supports — tailwind-types.ts:222).

## Evidence
```ts
// src/elements/forms.ts:340  — input wiring knows nothing about errors
input(name, type) {
  const tag = type ? (Input as (t: InputType) => InputTag)(type) : Input();
  tag.setName(name);
  const v = values[name];
  if (v !== undefined && v !== null) tag.setValue(String(v));
  return tag;
},
```
```ts
// src/elements/forms.ts:366  — error wiring knows nothing about the input
error(name) {
  const message = errors[name];
  return message ? El("span", message) : Empty();
},
```
`errors` is in scope for both factories, yet `input`/`textarea`/`select` never consult it. `aria-invalid` is a first-class ARIA state (aria-types.ts:38), so emitting it is type-safe and escape-safe.

## Why it matters
Server-rendered validation is the headline use case of `Form<T>` (the 422-re-render pattern in the guidelines). Without `aria-invalid`, the styled-error story breaks: an app can't target invalid inputs with `.on("aria-invalid", …)`/`invalid:` without re-deriving the error map it already passed to `Form`. Screen-reader users get a visible-only error. Medium pain, high frequency (every validated form).

## Rough idea (not a design)
Additive (6.1.0): in `createFormBinding`, when `errors[name]` is set, have the control factories emit `aria-invalid="true"` (and, if `error()` is given/derives a stable id, `aria-describedby` linking the two). Opt-out via an option if an app wants to suppress. No new visual opinion — just the missing ARIA glue.
