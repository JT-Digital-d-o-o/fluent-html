# Node discriminant `_t` is an untyped magic number duplicated across four files

## Problem
The runtime type tag `_t` (Tag = 1, RawString = 2) is the discriminant the hot-path
guards `isTag`/`isRawString` switch on. The writer (`setDiscriminant`) types it as a
bare `number`, and each consumer hardcodes the literal independently. The 1/2
constants are duplicated in four files with no single source of truth — exactly the
"no magic constants / use literal types" rule the project's TypeScript guideline
mandates.

## Evidence
```ts
// src/core/proto.ts:37 — accepts ANY number, no literal union
export function setDiscriminant(ctor: { prototype: object }, t: number): void {
  (ctor.prototype as unknown as NodeProto)._t = t;
}

// src/core/tag.ts:375
setDiscriminant(Tag, 1);
// src/core/raw-string.ts:12
setDiscriminant(RawString, 2);

// src/core/guards.ts:5,9 — the magic numbers restated, decoupled from the writes
export function isTag(v: unknown): v is Tag {
  return typeof v === 'object' && v !== null && (v as { _t?: number })._t === 1;
}
export function isRawString(v: unknown): v is RawString {
  return ... (v as { _t?: number })._t === 2;
}
```

Nothing prevents `setDiscriminant(Tag, 3)` or a guard checking `=== 1` for the wrong
node — both compile. The discriminant numbers and the guard comparisons can drift
silently.

## Why it matters
Low frequency (two node kinds today) but it is a foundational invariant on the
render hot path: if a third node kind is ever added (or the numbers reordered), the
duplicated literals are an easy desync with no compiler help. It is also a
self-inconsistency: `defineSchemaKeys`/`setDiscriminant` were introduced precisely to
centralize prototype writes, yet the discriminant value itself stayed an untyped
magic number.

## Rough idea (not a design)
Introduce `const NodeKind = { Tag: 1, RawString: 2 } as const` (or a `const enum`),
type `setDiscriminant(ctor, t: NodeKind)`, and have the guards compare against
`NodeKind.Tag`/`NodeKind.RawString`. No public shape change, no runtime behavior
change — internal-hygiene patch. Ships 6.0.1.
