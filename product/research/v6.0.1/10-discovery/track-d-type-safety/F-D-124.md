# proto.ts's "ONE place" claim is leaky — three prototype writes bypass it with their own casts

## Problem
`proto.ts` was introduced (per its own docstring) to be the single audited home for
prototype brand/method writes, replacing "~53 scattered `(X.prototype as any)`
casts… so adding an element no longer hand-suppresses `no-explicit-any`." But three
writes still bypass it, each re-introducing its own unsafe cast:

- `DocumentTag`'s `_doc` brand — an inline `(… as unknown as { _doc: true })` rather
  than going through `setDiscriminant`/a brand helper.
- `behavior` and `hxOn` — both registered via `(Tag.prototype as any)`.

So the codebase still has hand-rolled prototype casts that escape the one place that
was supposed to own them; the docstring overstates the invariant.

## Evidence
```ts
// src/core/proto.ts:4 — the claim
//  * `_t` node discriminant are written. Replaces ~53 scattered `(X.prototype as any)`
//  * casts ... with two typed calls and a single internal cast ...

// src/elements/document.ts:37 — a third brand, written inline, not via proto.ts
(DocumentTag.prototype as unknown as { _doc: true })._doc = true;

// src/core/behavior-methods.ts:145 / :169 — two method writes, each its own `as any`
(Tag.prototype as any).behavior = function (...) { ... };
(Tag.prototype as any).hxOn = function (...) { ... };
```

`_doc` is exactly the same kind of write `setDiscriminant` already performs for
`_t` — a numeric/literal brand on a subclass prototype the emitter discriminates on
(serialize.ts:344, :423) — yet it does not use it.

## Why it matters
Low pain, but it is a direct self-inconsistency on this track's core subject: the
unsafe-cast count in core is not actually centralized to "a single internal cast."
Each escaped write is a place a future maintainer copies the `as any` pattern from,
and the `_doc` one in particular is a near-duplicate of an existing typed helper.
Closing it makes `npx eslint src` enforce the invariant the docstring promises.

## Rough idea (not a design)
Extend proto.ts with a typed `setBrand(ctor, key)` (or generalize `setDiscriminant`)
and route `_doc` through it; register `behavior`/`hxOn` via a typed
prototype-extension helper instead of `as any`. Internal-only, no public shape
change. Ships 6.0.1.
