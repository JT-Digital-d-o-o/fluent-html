# All setup docs hardcode v3 pipeline — fully invalid on v4

## Problem

Every user-facing setup document teaches the Tailwind v3 build pipeline exclusively. A user following these docs on a v4 project gets a non-building project: the directives are unknown, the config file is ignored, and the PostCSS plugin is a different package. There is no mention of v4 anywhere in the setup docs.

## Evidence

`fluent-html/TAILWIND-SETUP.md` line 71 — documented CSS file:
```css
/* TAILWIND-SETUP.md:71 */
@tailwind base;
@tailwind components;
@tailwind utilities;
```
In v4 these directives do not exist. The replacement is `@import "tailwindcss";`.

`TAILWIND-SETUP.md` line 22 — install command:
```bash
npm install --save-dev tailwindcss autoprefixer postcss fluent-html-tailwind-extractor
```
v4 uses `@tailwindcss/postcss` (a separate package from `tailwindcss`) and `@tailwindcss/cli`.

`TAILWIND-SETUP.md` lines 58–63 — PostCSS config:
```javascript
// TAILWIND-SETUP.md:60
module.exports = {
  plugins: {
    tailwindcss: {},   // v3 plugin name; v4 requires "@tailwindcss/postcss"
    autoprefixer: {},
  },
};
```

`TAILWIND-SETUP.md` lines 100–108 — build scripts:
```bash
tailwindcss -i ./styles.css -o ./dist/output.css   # v3 CLI; v4 uses @tailwindcss/cli
```

`fluent-html-tailwind-extractor/README.md` line 26 teaches `tailwind.config.js` — which v4 no longer auto-loads (CSS-first `@theme` is the v4 configuration mechanism).

## Why it matters

New users and v4 upgraders hit a completely broken build with no guidance. The docs are authoritative; there is no v4 path documented. This affects every user who attempts v4 adoption using the official setup guide.

## Rough idea (not a design)

Rewrite `TAILWIND-SETUP.md` and extractor `README.md` for v4 as the primary path: `@import "tailwindcss"`, `@tailwindcss/postcss`/`@tailwindcss/vite`, `@tailwindcss/cli`, CSS-first `@theme` for custom tokens. Add a collapsible "v3 (legacy)" section. Update the install instructions and build scripts. Coordinate with F-C-011 (extractor redesign) since the config wiring changes together.
