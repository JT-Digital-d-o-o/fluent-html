## [4.2.0] - Fixes that compile: a swept fix contract, per-shape dynamic-arg messages, no autofix into a branded href

Three rules stop writing or printing fixes that fail tsc. `no-tailwind-in-raw-class` takes its autofixes from a generated contract swept against the resolved fluent-html and Tailwind; `no-dynamic-typed-styling-arg` and `no-dynamic-class-argument` stop prescribing `staticManifest` and print a rewrite for the argument's shape; `prefer-set-method` stops autofixing a raw href into fluent-html 8's branded `setHref`. The new messageIds make this a minor. Nothing here needs a fluent-html newer than 8.0.0: the producers `preferBrandedSetter` names exist since 8.0.0.

### 🐛 Fixed

- **`no-tailwind-in-raw-class` autofixes type-check and render their class.** On 4.1.0, 6,124 classes and 145 variant heads autofixed into code tsc rejects (`border-b-2` → `.border("b-2")`, TS2769; `rotate-x-45` → `.rotate("x-45")`, TS2345), and `setClass("p-4 js-hook")` autofixed to a chain that rendered only `class="js-hook"`. Fixes now come from `src/fix-contract.generated.ts`: each candidate call is compiled against the resolved fluent-html, in plain and `hover:` object form, then rendered, and it is kept only when tsc reports nothing and the rendered class equals the class (or carries the same declarations). Swept against fluent-html 8.1.0 and Tailwind 4.3.3, 0 of 23,661 tokens fail and 9,833 classes autofix (was 6,728). The autofix is partial: each token with an accepted chain is fixed, the rest stay in the raw call and are still reported, and a kept `setClass()` goes first (`setClass("p-4 js-hook")` → `.setClass("js-hook").p("4")`, which renders `class="js-hook p-4"`). On the template's pure-prior apps, `eslint --fix` now leaves tsc at 3 and 4 errors (was 27 and 30). Over 852 files in 58 fleet repos (untyped), the rule reports what 4.1.0 reported: 0 new, 0 dropped, 0 crashes.
- **`mask-*-%` classes are reported.** On 4.1.0, 378 of them passed silently. The Tailwind token shape now accepts `%` and a trailing `/[...]`, and a functional-root guard reads `TAILWIND_FUNCTIONAL_ROOTS` from the generated vocab.
- **A fix that would fail is reported without one, and the report says why.** `untypedValue` names the call tsc rejects and the method whose typed values it misses (1,650 withheld classes); `variantHeadUntyped` names a Tailwind variant head that `.variant()` does not accept (156 heads). In a type-aware config, `hostRejects` withholds a fix the project's own types reject: palette literals under the palette opt-out are withheld in 26 of 26 cases per pure-prior run. A variant head with no method resolves through the tier-1 table: `focus-visible:outline` names `.focusVisible({ … })`, never `.variant("focus-visible", { … })`.
- **`prefer-set-method` stops autofixing a raw href into a compile error.** `A("Team").addAttribute("href", "/team")` was fixed to `.setHref("/team")`, which fluent-html 8 rejects (TS2345). An `href` on `A()` or on an unknown receiver is now reported under the new `preferBrandedSetter` message, which names `routes.x.resolve([params,] query?)`, `assetUrl(path)` and `externalUrl(url)`, with no autofix, unless the value already satisfies the brand: an `https` literal, a `#…` template and a `.resolve()`, `assetUrl()` or `externalUrl()` call keep the autofix, as does `Link()`. On an 11-site fixture, `--fix` followed by tsc goes from 3 TS2345 to 1 (an aliased `A as Anchor` import; 0 such imports in the fleet).

### ✨ Added

- **An exact `.cssProp()` successor for utilities with no fluent method.** `place-items-center` autofixes to `.cssProp("place-items", "center")`, which renders `[place-items:center]` (509 such classes). A no-method root without an exact successor names its CSS property (`Use .cssProp("<prop>", value).`), and a root that does have a method names that method: on 4.1.0, 501 of 11,839 no-method reports named a root with a live method (`outline` 293, `flex` 26).
- **`npm test` runs the fix contract and compiles printed rewrites.** `test/fix-contract.mjs` lints, fixes, type-checks and renders 23,661 tokens and fails on any autofix that does not type-check or that renders another class (on 4.1.0, 6,269 of 13,172 fail); it also render-checks variant-headed tokens (25.3 to 27 s; the full `npm test` 60 s). A compile step pastes every rewrite the dynamic-argument rules print into a fixture and type-checks it. `npm run gen:vocab` regenerates the contract through `scripts/gen-fix-contract.mjs` (34.5 to 55 s), and `gen:vocab --check` exits 1 when the committed tables differ from a fresh sweep or when the fluent-html and tailwindcss versions recorded in the header differ from the resolved ones. In a standalone plugin checkout the generator and the contract test skip instead of failing with `ERR_MODULE_NOT_FOUND`.

### 🔧 Changed

- **The fix tables follow the installed fluent-html.** A generated entry applies only while the host's own derivation still yields the call it was swept from (a host that adds a `placeItems` row no longer gets `.cssProp("place-items", "center")`), and a residue row whose method the installed fluent-html lacks is skipped instead of crashing the run (eslint exited 2 on a host without `colEnd`/`rowEnd`). The contract compiles against the resolved `node_modules/fluent-html`, and the devDependency moves from 8.0.0 (`7cf5b23`) to 8.1.0 (`656e812`); their class-vocab is identical (159 of 159 methods).
- **Dynamic-argument messages stop prescribing `staticManifest`.** `no-dynamic-typed-styling-arg` and `no-dynamic-class-argument` told authors to put the token in `defineTheme()`'s `staticManifest`, which `defineTheme` rejects (TS2353) and which never clears the extractor's throw (11 of 11 calls still throw with it). Each report now picks its text by the argument's shape and prints a rewrite from the call's own source: a ternary becomes `.whenElse(...)` (`.when(...)` when one branch is `undefined`; a non-boolean test is wrapped in `Boolean()`), a `MatchValue` becomes `.whenMatch(...)`, a keyed map becomes `.whenMatch(...)` over only the keys its key type admits (an open `string` key, or a config without type information, gets the generic text), and a runtime unit amount goes to `.addStyle(...)`, which accumulates where two `.setStyle` fixes on one chain lost the width. For class strings, a constant becomes a styler applied with `.apply(...)`, named from a class-suffixed identifier (`LABEL_CLASSES` → `label`) or else `styler`; an assembled class name branches with one literal per case; a computed `.cssClass()` hook becomes a literal. The "missing from the CSS" claim is gone: the template's theme force-list keeps a token class held in a variable present (376 forced classes). Detection, severity and the reported nodes are unchanged (identical over 5,702 canonical-fleet files and 437 agent-run files), and the ternary and `MatchValue` rewrites render byte-identical in 13 of 13 cases.
