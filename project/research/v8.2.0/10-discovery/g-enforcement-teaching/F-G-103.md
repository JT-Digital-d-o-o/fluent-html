# fluent-html's own CLAUDE.md is 23 commits stale and teaches runtime-false claims

## Problem

The lib repo vendors the guidelines through `scripts/guidelines.sh pull`: root `CLAUDE.md` plus `.ai/web-development/*`. The last pull was ac24da0 (2026-08-03). Since then guidelines has 23 web-development commits, and the copies differ by 934 lines. `npm run guidelines:check` exists (package.json:76), but no workflow runs it.

This stale file is what every agent working in the lib loads. This review's own agent context carries it verbatim, including the 406 claim below. The template copy (`projects-template/CLAUDE.md`, `.ai/web-development/CLAUDE.md`) is byte-identical to guidelines HEAD. Only the lib copy drifted.

## Evidence (executed)

**Runtime-false claims (Chromium, lib htmx beta6 and template htmx 4.0.0, `stale-claims.mjs`):**

1. **fluent-html/CLAUDE.md:272.** Claim: "`.setEnctype()` alone → urlencoded → 406". A form with only `enctype="multipart/form-data"` + `hx-post` sends `Content-Type: multipart/form-data` on **both** bundles. The `{ encoding }` option also sends multipart; neither sends `application/x-www-form-urlencoded`. The linked `.ai/web-development/htmx.md:200` repeats the claim. gl/CLAUDE.md:271 and gl/htmx.md:282 have the corrected text.
2. **fluent-html/CLAUDE.md:321.** Claim: `back` restores "HTMX's prior page snapshot (content + scroll)". After an `hx-push-url` swap to /b, `.behavior("back")` produced request log `GET / hx=- hist=true` on both bundles. The server-rendered `#stamp` changed, so the content was re-fetched, not restored from a snapshot. Scroll returned to 1200. gl/CLAUDE.md:343 was fixed in template v3.6.1.
3. **fluent-html/CLAUDE.md:267.** Claim: "Anchors with a swap verb need `.cursor(\"pointer\")` (the verbs don't add it)". The ✓ at :329 `A("Projects").nav(projectRoutes.list()).cursor("pointer")` renders `class="cursor-pointer cursor-pointer"` through the template verbs. The template lint accepts a `.nav()` anchor with no cursor (lint probe b.ts: 0 messages on that line).

**Marked lines that exist only in the stale copy.** 15 of 55; 0 flip marker for the same code:
- :316 `Button("Open").behavior("openDialog", …)` says "✗ legacy JS path — **kept**". tsc: TS2345 `'"openDialog"' is not assignable` (deleted 6.4.0).
- :395 `reply.redirect("/path")` ✓. The template rule `template/branded-redirect` errors on it (snippet lint run).
- :74 `.border("gray-300")`: a palette literal (TS2345 under the template's opt-out); gl/CLAUDE.md:74 has `.border("line")`. `guidelines-tokens.test.ts` guards the template's copy only.
- :250 `const card = (t: Tag) => …` ✓, while gl/CLAUDE.md:231 says "never a hand-written `(t: Tag) => …`" (see [[F-G-107]]).
- :297 `render(Partial(ids.mainContent, List(items)), Partial(ids.navBadge, …))` ✓ vs gl/CLAUDE.md:320 `render(Partial(ids.mainContent, List(items)))` ✗. Both were executed as the answer to a `.nav()` anchor on beta6 and 4.0.0 (`partial-main.mjs`). Both land: `#main-content` replaced once, badge "2" vs "0", no console errors. So gl's ✗ is a style rule that no layer holds, and the two copies disagree on it.

## Why it matters

impact 2 × pain 2 × reach 3 / S. Every agent session in the lib repo pays 460 lines of context, including this run's ~50 agents. Three of its instructions are false against both runtimes the lib ships and tests with. Claim 1 sends agents to add an unneeded pairing. Claim 3 emits a duplicate class. Claim 2 hides that back is a server round-trip, which matters for non-idempotent GETs and lost form state. Recon 02 priced the guided prose at ≤ 0 on every layer; a stale copy is negative.

## Rough idea (not a design)

The strongest layer is **ci**:
- test.yml runs `npm run guidelines:check`, or compares `.ai/` against the commit in `.ai/.guidelines-version` and against guidelines HEAD, and fails on drift.
- Better for guardrail 12: cut `fluent-html/CLAUDE.md` to the lib-development rules (build, vocab, release) plus a pointer to the vendored tree. That deletes the 460-line duplicate instead of re-growing it to 561.
- The Partial ✓/✗ pair should become one line marked `prose-only` (style) or be deleted, since both shapes work.
