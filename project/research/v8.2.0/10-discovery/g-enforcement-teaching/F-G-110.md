# Taught-but-unused audit: the low-use names work; the defects are elsewhere

## Problem

The audit's hypothesis: an API taught with 0 call sites has 0 exemplars and 0 tests, so it can be broken unnoticed (the `Partial()` story). It was measured name by name on 8.1.0 for every lib name taught in README, fluent-html/CLAUDE.md or gl/** with ≤5 app-authored canonical-era sites. Excluded as unverified or over the bar: `anchorName` 6, `outline` 6, and HxResponse members with no census count.

## Evidence (executed)

**The 32 names:**
- `setPopover gradient hxGet hxPost setCite setFormmethod HtmxConfig htmxIndicator setAs setDatetime setFetchPriority textShadow positionAnchor positionArea setEnctype addChild hx bgConic bgRadial setAllow setCrossOrigin setHeaders setImagesizes setImagesrcset setMedia setPopovertargetaction setSandbox static viewTransitionName El Repeat renderWithNonce`

**Counts:**

| Check | Result |
|---|---|
| Template exemplar (templates/full-stack/src + packages/ui/src) | 0 for **24/32**; 1-3 for HtmxConfig, htmxIndicator, setAs, setFetchPriority, setEnctype, hx, setCrossOrigin, renderWithNonce |
| Template test | 0 for **30/32** (setEnctype 3, hx 2) |
| Lib test hit (fluent-html/test) | ≥1 for **32/32** (1-111) |
| Taught line renders (dist 8.1.0) | **38/38**, 0 throws |
| Classes vs pinned oracle (4.3.3 + template @theme) | 0 rejected (bg-linear-to-r/oklch, bg-radial-[at_top_left], bg-conic-180, -bg-linear-65, text-shadow-lg, static, outline-hidden, …) |
| htmx-facing, executed in Chromium on beta6 and 4.0.0 | 6/6 work: `hxGet(route.resolve())` swaps; `hxPost` + `status.422` lands the error; `.htmxIndicator()` (the trigger gets `htmx-request`); `HtmxConfig({ transitions: true })` read into `htmx.config`; `viewTransitionName` computed; `setEnctype` alone sends multipart |

**Where this audit's names did turn up defects, they were claims, not code:**
- 4 emitters are taught with class output they no longer produce ([[F-G-104]]).
- `Tag().anchorName(id)` notation does not compile ([[F-G-101]] #10-12).
- `setEnctype` carries a stale 406 claim ([[F-G-103]]).
- `hxGet` is described as taking "a route callable" (TS2345, [[F-G-104]]).

Always-loaded cost: gl/CLAUDE.md spends 10 lines (~694 tokens) on these names. That includes `textShadow` as the naming-rule example (:216), with 0 fleet sites.

## Why it matters

impact 1 × pain 1 × reach 3 / S. This recalibrates the G lane. "Taught with 0 sites" is not a reliable breakage predictor for lib names, because lib unit tests exist. The `Partial()` class of defect lives in taught *snippets and claims* that nothing compiles or executes. [[F-G-101]] finds 24 such lines; this audit finds 0 broken names. An exemplar-or-test gate per taught name would add work and catch nothing measured here.

## Rough idea (not a design)

Park any per-name exemplar/test gate. The enforcement that holds this class is the snippet compile lane plus the output-assertion pass ([[F-G-101]], [[F-G-104]]): they compile and render every taught line whether or not its name has call sites. Prose deletable now: the 0-fleet-site examples in always-loaded CLAUDE.md, for example `.textShadow("lg")` at gl/CLAUDE.md:216 can become `.text("lg")`, which has 12,984 app-authored sites.
