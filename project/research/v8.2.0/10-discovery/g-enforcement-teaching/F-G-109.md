# The lib's examples fail their documented run command

## Problem

Each file in `fluent-html/examples/` opens with its run command, for example `Run: npx tsx examples/htmx.ts` (examples/htmx.ts:4). All 5 fail before printing anything. `src/elements/index.ts:98-100` and `src/index.ts:94-96` re-export the interfaces `NumericInputTag`, `DateTimeInputTag` and `NoMinMaxInputTag` inside a value `export { … }` block. tsc elides them, but esbuild/tsx cannot know they are types. No lane notices: `examples/` is outside the tsconfig `include`, and none of the 3 workflows touches it.

## Evidence (executed)

- `npx tsx examples/basic.ts` (tsx 4.21.0, node 26), and the same for all 5: `SyntaxError: The requested module './forms.js' does not provide an export named 'DateTimeInputTag'` at src/elements/index.ts:99.
- `npx tsc -p tsconfig.json --noEmit --isolatedModules`: exactly 6 × `TS1205: Re-exporting a type when 'isolatedModules' is enabled requires using 'export type'.` Lines: src/elements/index.ts:98, :99, :100 and src/index.ts:94, :95, :96.
- The examples themselves are sound. With imports pointed at `dist/src/index.d.ts`, `tsc --strict` reports 0 errors. Only the runnable path, the lib `src` through esbuild, is broken.
- The package ships `src/**/*.ts` (package.json `files`). Blind agents read `src/*.ts` (recon 02: 36 and 39 fluent-html src/d.ts reads per run). Any consumer tool that compiles those files with isolated-module semantics hits the same error.

## Why it matters

impact 1 × pain 2 × reach 1 / S. The only lib-owned runnable exemplars do not run, and nothing would say so. This is the same failure mode as the doc snippets: taught, uncompiled, unexecuted. Hurts verification-loop and evolvability (esbuild/tsx/vitest source paths).

## Rough idea (not a design)

The strongest layer is **type**: `isolatedModules: true` (or `verbatimModuleSyntax`) in the lib tsconfig makes TS1205 a CI error. The fix is `export type { NumericInputTag, DateTimeInputTag, NoMinMaxInputTag }` at both sites, with no public-shape change for tsc consumers (8.1.x). Add a CI step that runs each `examples/*.ts` with tsx and fails on a non-zero exit. Prose deleted: none.
