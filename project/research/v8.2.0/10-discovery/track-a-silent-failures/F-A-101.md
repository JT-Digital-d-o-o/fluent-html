# No executed runtime-grammar gate exists

## Problem
Guardrail 10 says every emitted htmx name must work in the pinned bundle. Nothing in the lib checks it, and the one check one layer up (projects-template `htmx-grammar-contract.test.ts`) matches attribute NAMES against `"hx-..."` string literals in the minified bundle. Every defect this run measured lives in values, option-bag shape, selector keywords, trigger semantics or event-detail shape, where a name check is blind. Worse, name checks invert: they flag working grammar (`hx-preserve`, read via a `[hx-preserve]` selector; the legacy `<hx-partial>` element, rewritten by a regex) and pass dead grammar.

## Evidence (executed)
Bundles (sha256): a7 = htmx 4.0.0-alpha7 `3fdcebab` (ttl, fluent-html-demos, jtdigital-landing-page via CDN), b4 = 4.0.0-beta4 `26382eb1` (planet-positive-sport, storysell-ai), b6 = 4.0.0-beta6 `28fae7bb` (lib pin, test/acceptance, na-cent, fl-um), ga = 4.0.0 `e484d917` (template + 12 canonical-era apps). Harness: Chromium 149 via playwright-core, 270 scenario runs (`probe.mjs` 212 in 108.7 s, `probe2.mjs` 14, `probe3.mjs` 44).

## Why it matters
impact 3 (each row above ships a feature that does nothing, or kills the request), pain 3 (clean on every layer an agent runs: 4/4 in-repo agents in recon 02 reached tsc and lint, 0/4 reached a browser), reach 3 (every consumer app; 238 live `show/scroll:window` sites alone, F-A-105). The Partial() lesson was recorded as "grep the bundle"; this shows grepping is the wrong oracle in both directions. Scorecard: silent-failure, verification-loop.

## Rough idea (not a design)
Enforcement layer: ci. A lib-side Playwright project (`test/grammar/`) that renders each typed emitter from `dist/` (hx(), setHtmx, hxGet/hxPost, Partial, hxResponse headers, HtmxConfig, behaviors lifecycle) and asserts an observable effect against the pinned bundle and the template-served bundle, wired into `test.yml`. The three harnesses in scratch are a starting point (about 27 s per bundle). Prose it lets us delete: the "attributes don't inherit / show:window is dead" warnings carried in template comments and guideline asides once each is pinned by a row.
