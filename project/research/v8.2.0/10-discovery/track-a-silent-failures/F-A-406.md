# TS2551 heals setter guesses into a setter for another attribute

## Problem
tsc's spelling suggester searches the element's whole member list. When a guessed setter does not exist, it can propose a neighbouring setter that writes a different attribute, and the healed call compiles:

```ts
Option("United States").setValue("us").setAriaLabel("USA")
// TS2551: Property 'setAriaLabel' does not exist on type 'OptionTag'. Did you mean 'setLabel'?
Option("United States").setValue("us").setLabel("USA")   // compiles; the list now shows "USA", no aria-label
```

More pairs follow the same pattern:
- SVG `setFillOpacity("0.5")` heals into `setOpacity`, which fades the stroke too.
- `setStopOpacity` on a shape becomes `setStrokeOpacity`.
- `setAriaAutocomplete("list")` on a combobox input becomes `setAutocomplete`: `autocomplete="list"` and no `aria-autocomplete`.
- `setIs` becomes `setId`.

## Evidence (executed)
- **Heal classification.** From the same 32,712-line harness as F-A-401. Of 2,462 TS2551 suggestions:
  - 1,455 name the right setter.
  - 52 heal into a class (F-A-401).
  - **207 heal into a compiling setter that writes another attribute**, in 13 families (counts in the evidence list).
- **Browser (Chromium).** A healed `setLabel` on `<option>` changes the displayed text (`option.label` "USA") and leaves `aria-label` absent.
- **Static layers.** The healed lines are clean for tsc by construction, and no eslint rule covers setter/attribute semantics.

## Why it matters
impact 2 × pain 2 × reach 1 / effort M = 2. There is no measured recurrence in the fleet. The pure prior routes aria through `addAttribute` (recon 02: 23/30 `addAttribute` calls). The finding matters for the verification loop: the only hint an agent gets points to a wrong but compiling call, and no test watches the suggestion table as the surface changes.

## Rough idea (not a design)
Test layer first: pin the generated heal table (wrong heals must stay at the measured set or shrink) next to `setter-errors.test.ts`. Then add trap members only for the highest-prior aria spellings, with a parameter literal that names `.setAria({ label })`. Weigh these against surface cost (S-23). No guideline prose.
