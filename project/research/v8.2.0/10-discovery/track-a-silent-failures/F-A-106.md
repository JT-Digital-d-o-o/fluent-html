# templates/web emits htmx into pages with no htmx

## Problem
The web template dropped htmx in the behavior-v4 cutover (a40bd01: "built-ins-only glue ... no htmx needed"), but three views still build their only request path with `setHtmx`. With no runtime to read `hx-post`/`hx-get`, the browser falls back to native behavior: a `<form>` without `method`/`action` submits as GET to the current URL, and an `<a>` without `href` is not a link.

```html
<form class="..." hx-post="/api/contact" hx-swap="outerMorph show:window:top"> ... </form>
<a class="cursor-pointer ..." hx-get="/blog/..." hx-target="body" hx-swap="outerMorph show:window:top" hx-push-url="true"> ... </a>
```

## Evidence (executed)
`tsx web-render.ts` renders `ContactForm` and `PostCard`/`PostCardCompact` from the template's own source with its installed fluent-html 8.1.0 (output above). `node web-run.mjs` serves them in Chromium, fills name/email/message, submits, then clicks a card:

| | contact submit | URL after submit | card click requests |
|---|---|---|---|
| templates/web as shipped (no htmx) | `GET /contact?name=Ana&email=a%40b.si&subject=&message=Hi` | `/contact?name=Ana&email=a%40b.si&subject=&message=Hi` | 0 |
| same markup + htmx 4.0.0 (control) | `POST /api/contact` | `/contact` | `GET /blog/hello` |

The server registers only `POST /api/contact` (`index.ts:198`), so the message is never received; the visitor's email and message land in the address bar, history and access logs. `grep -rn "setHtmx|hx(|\.nav(|hxGet|hxPost" templates/web/src`: 3 emitters, all dead. tsc, lint, and the full-stack `htmx-grammar-contract.test.ts` (which only covers `templates/full-stack`) are all clean.

## Why it matters
impact 3 (the template's contact form does not work and leaks PII into URLs), pain 3 (nothing fails: the page renders, the button submits, the URL even changes), reach 2 (every site scaffolded from templates/web; 0 derived repos found in the fleet today, 1 template). Scorecard: silent-failure, verification-loop. This is the grammar contract at page level: an emitted name must have a runtime to read it at all.

## Rough idea (not a design)
Enforcement layer: ci (template). In templates/web use `Form().setAction(...).setMethod("post")` and `A().setHref(...)` (progressive by construction), and add a render test over every web page that fails on any `hx-` attribute while `layout.ts` serves no htmx script. Lockstep: template only.
