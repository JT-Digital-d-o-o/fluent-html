# Advertised htmx literals that can never work

## Problem
`HxTarget` and `HxTrigger` both end in an open string arm, so their literal members exist only to steer autocomplete. Six of those literals steer to dead grammar:
- `target: "window"` / `"document"`: htmx resolves them to the `window`/`document` objects and then fails reading element properties, before any request.
- `trigger: "resize"` / `"scroll"`: on an element, `resize` never fires and `scroll` fires only if the element itself scrolls; the working forms (`resize from:window`, `scroll from:window`) are not in the union.
- `trigger: "sse:message"` / `"ws:message"`: htmx-2 extension syntax; the htmx 4 hx-sse extension dispatches a named SSE event as a plain DOM event of that name.

## Evidence (executed)
`node probe.mjs K,X` (Chromium):

| typed value | a7 | b4 | b6 | ga |
|---|---|---|---|---|
| `target: "window"` | 0 req, `TypeError: Cannot read properties of undefined (reading 'toLowerCase')` | 0, same + htmx:error | 0, same | 0, same |
| `target: "document"` | 0, same | 0 | 0 | 0 |
| `target: "body"` (control) | 1, landed | 1 | 1 | 1 |
| `trigger: "resize"` on a div, 2 viewport resizes | 0 | 0 | 0 | 0 |
| `trigger: "resize from:window"` (untyped tail) | 2 | 2 | 2 | 2 |
| `trigger: "scroll"` on a div, page scrolled 800px | 0 | 0 | 0 | 0 |
| `trigger: "scroll from:window"` (untyped tail) | 1 | 1 | 1 | 1 |

SSE, with the real `ext/hx-sse.js` of each bundle and a stream sending `event: message` and `event: ping` (listener inside `hx-sse:connect`, `... from:#conn`):

| trigger | b6 requests | ga requests |
|---|---|---|
| `sse:message` (typed) | 0 | 0 |
| `message` | 2 | 2 |
| `sse:ping` | 0 | 0 |
| `ping` | 2 | 2 |

Recon 03 counted the 23 DOM events as processed from a parser call; executed, 2 of them are dead on elements. Fleet (`census.mjs`): `target: "window"|"document"` 0 sites; `trigger: "resize"|"scroll"` 0; `sse:message|ws:message` 0 outside `src/htmx.ts`.

## Why it matters
impact 2 (a request that never fires or a trigger that never fires), pain 2 (tsc/lint clean; the window/document case at least logs an error), reach 1 (0 sites). The type presents these as vetted choices, which is the opposite of decision closure. Scorecard: silent-failure, decision-closure.

## Rough idea (not a design)
Enforcement layer: type (autocomplete) + ci rows. Because both unions keep their string tails, removing the six literals changes no compile result (8.1.x-safe); add `"resize from:window"` and `"scroll from:window"` as the advertised literals. Whether the string tails should close is the separate decision in L-063/L-079.
