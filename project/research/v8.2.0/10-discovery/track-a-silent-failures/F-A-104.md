# HxConfig.credentials: boolean kills the request

## Problem
`HxConfig.credentials?: boolean` looks like an on/off switch. htmx 4 merges `hx-config` into the `RequestInit` it hands to `fetch`, and `RequestInit.credentials` is the enum `"omit" | "same-origin" | "include"`. Any boolean makes `fetch` throw synchronously, so the request never leaves the browser. The one value that works is rejected by the type.

## Evidence (executed)
`node probe.mjs C` (Chromium, 4 bundles), button with `setHtmx(hx(u, { target: "#t", config }))`:

| config | emitted | requests reaching server | #t | error |
|---|---|---|---|---|
| `{ credentials: true }` | `hx-config="{&quot;credentials&quot;:true}"` | 0/4 | old | `TypeError: Failed to execute 'fetch' on 'Window': Failed to read the 'credentials' property from 'RequestInit': The provided value 'true' is not a valid enum value of type RequestCredentials.` |
| `{ credentials: false }` | `...:false` | 0/4 | old | same, `'false'` |
| `{ credentials: "include" }` (cast) | `...:&quot;include&quot;` | 4/4 | new | none |
| `{ timeout: 5000 }` (control) | | 4/4 | new | none |

`tsc -p tsprobe/tsconfig.json`: the boolean forms compile; `config: { credentials: "include" }` fails with `TS2322: Type 'string' is not assignable to type 'boolean | undefined'.` eslint (32 rules): 0 findings. The failure surfaces only as an `htmx:error` event; nothing renders, the button just does nothing.

Fleet (`census.mjs`): `credentials: true|false` inside an hx bag: 0 app sites (the 5 hits are Fastify/test helpers and the lib's own `test/htmx.test.ts`). The sibling key `mode` is overwritten by htmx after the merge (recon 03 S8: `mode:"cors"` -> `same-origin`), already parked as L-148.

## Why it matters
impact 3 (the request never fires), pain 3 (clean on tsc/lint/extractor/dev runtime; the type rejects the fix, so an agent that tries `"include"` is pushed back to the broken form), reach 1 (0 current sites). Scorecard: silent-failure, error-quality.

## Rough idea (not a design)
Enforcement layer: dev-throw now (serializer: a boolean `credentials` throws `hx-config credentials must be "include" | "same-origin" | "omit"`), then type in 9.0.0: `credentials?: RequestCredentials`, codemod dry run is trivially 0 sites. Drop `mode` in the same change (L-148).
