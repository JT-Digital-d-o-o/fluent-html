# Custom font sizes lose the size-coupled line-height every stock size has

## Problem

Every stock `text-*` size ships a paired `--text-*--line-height` (`text-6xl` = 60px / line-height 1).
`defineTheme({ fontSize })` is `Record<string, string>` and `themeToCss` emits only `--text-<name>`,
so Tailwind emits `.text-score{font-size:var(--text-score)}` with no line-height at all; the element
inherits the parent's unitless 1.5. An author who swaps `.text("6xl")` for a project token `.text("score")`
gets a line box 60% taller with no diagnostic.

## Evidence (executed)

`$A2 = <scratch>/wave1/A2`.

- Build (`@import "tailwindcss" source(none); @theme { --text-score: 64px; } @source inline("text-score text-6xl")`,
  postcss + @tailwindcss/postcss 4.3.3): `.text-6xl{font-size:var(--text-6xl);line-height:var(--tw-leading,var(--text-6xl--line-height))}`,
  `.text-score{font-size:var(--text-score)}`.
- Chromium: `text-score font-size=64px line-height=96px box=96px`; `text-6xl font-size=60px line-height=60px box=60px`.
- `node $A2/fontsize-leading.mjs` (5 canonical apps with fontSize tokens: fluent-html-home-page,
  home-page, sportoawards, stojnica, website-sales-funnel-automation-system): 0 define a
  `--text-*--line-height`; 130 `.text(<custom size>)` chains, 84 with no `.leading()` or `.apply`
  in the chain (sportoawards 75/89, website-sales-funnel-automation-system 5/10, home-page 4/20).
  Authors compensate by hand on large sizes (sportoawards `type.ts:12-60` pairs every display size
  with `.leading(...)`); the 84 are mostly 13-15px meta/body text, where inheriting 1.5 is close to stock.

## Why it matters

impact 1 (visual, not functional; large sizes are the visible cases) x pain 2 (nothing reports it;
the fix is a per-site `.leading()` the author must know to add) x reach 2 (5/16 canonical apps) /
effort S.

## Rough idea (not a design)

Tokens-only extension of `defineTheme`: a fontSize value may carry a line-height, emitted as
`--text-<name>--line-height`; the typed key stays the size name. Lets apps delete the hand-paired
`.leading()` calls on custom sizes.
