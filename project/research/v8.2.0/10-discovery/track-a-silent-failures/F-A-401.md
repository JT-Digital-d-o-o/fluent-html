# TS2551 heals three attribute guesses into styling methods that pass every layer

## Problem
The model has two priors for the `colspan` attribute: the attribute name `colspan` and the DOM property `HTMLTableCellElement.colSpan`. On a `TdTag` the first one fails with

```
error TS2551: Property 'colspan' does not exist on type 'TdTag'. Did you mean 'colSpan'?
```

and the second one compiles directly. Both land on the Tailwind grid utility `Tag.colSpan`, so `Td("Total").colSpan(2)` renders `<td class="col-span-2">Total</td>`. There is no `colspan` attribute, and the cell does not span. `rowspan` behaves the same way. An exhaustive enumeration found a third pair nobody had recorded: `.inert()` (DOM property `el.inert`) gets `Did you mean 'invert'?` on every HTML element class. The healed `.invert()` compiles, inverts the subtree's colours with a CSS filter, and leaves it fully interactive. That is the opposite of what `inert` is for (a modal's background).

## Evidence (executed)
- **Enumeration.** Every element factory (133 factories, 64 classes) was paired with every applicable attribute:
  - HTML per-element attributes and globals (html-element-attributes 3), SVG per-element attributes (svg-element-attributes 2), ARIA (aria-query 5).
  - Obsolete attributes were dropped, leaving 7,207 (element, attribute) pairs.
  - Each pair got up to 5 guess names (bare attribute, camelCase, DOM property from property-information, `set`+attribute, `set`+DOM property), each with its natural argument: 32,712 lines.
- **TypeScript 6.0.3 outcomes.**
  - 966 lines compile. 912 of them emit the right attribute; 52 emit a class (`.hidden()` x44, `colSpan`/`rowSpan` x8); 2 emit nothing (`setDownload()`, see F-A-404).
  - 2,462 lines get TS2551, 27,816 get TS2339 and 1,468 get an argument error.
- **The 2,462 TS2551 suggestions, re-compiled and rendered after the heal.**
  - 1,455 name the right setter.
  - **52 heal into a compiling class emitter:** inert->invert x44, colspan->colSpan x4, rowspan->rowSpan x4.
  - 207 heal into a setter for a different attribute (F-A-406).
  - 299 point at a styling method whose heal still fails.
- **Template program.** Run inside the scaffold's full program, the result is identical apart from 16 `navUp -> nav` suggestions and 16 colour-union texts. `tpl/src/app/probes/a4.ts:8-9` gets 0 tsc and 0 eslint 4.1.0 messages.
- **Browser (Chromium, Tailwind 4.3.3 build of the rendered classes).**
  - Class cell: `colSpan` 1 and width 140, the same as column 1. The `setColspan(2)` cell has `colSpan` 2 and width 150.
  - `.col-span-2{grid-column: span 2 / span 2}` exists in the CSS and does nothing on a table cell.
  - `.invert()` wrapper: `filter: invert(1)`, `inert` false; the inner button takes focus and the click lands. The `.toggle("inert")` wrapper blocks the click.
- **Pins.** `test/types/setter-probe/probe.ts` pins 12 guesses and none of these 3.
- **Fleet (dedup corpus).** 52 `.colSpan`/`.rowSpan` sites across 20 repos, all on grid items; 0 on a `Td`/`Th` chain. The hazard is latent and reached through the prior and through the compiler's own suggestion. Recon 02 probe #11 observed exactly that path.

## Why it matters
impact 2 × pain 3 × reach 2 / effort S = 12. This is the verification-loop failure in its purest form: the one layer every agent runs (tsc, 4/4 in recon 02) proposes the bug, and the other four layers (eslint, extractor, Tailwind, dev runtime) accept it. `inert -> invert` is new. It is also the worst of the three, because the bug looks like a styling glitch while the accessibility and interaction contract is lost.

## Rough idea (not a design)
Type layer, additive:
- On TdTag/ThTag, override `colSpan`/`rowSpan` with a parameter that intersects `TailwindColSpan` with a property whose key is the fix text. The override stays assignable, so TdTag is still a Tag, but a call now fails with a TS2345 that says `.setColspan(n)`.
- Add `colspan`/`rowspan`/`inert` trap members whose parameter is a message literal. This is the template's render-stance trick, which puts the fix at char 225.
- Pin all three guesses, plus the DOM-cased `.colSpan(2)` on a cell, in `setter-errors.test.ts`.

If the traps are judged surface cost, the fallback is a lint rule keyed on `Td(`/`Th(` receivers. No prose needs adding. The guideline line the rule replaces is none, because this was never taught.
