# Dead swap modifiers in the closed HxSwap union

## Problem
`HxSwap` is advertised as closed (a typo is a compile error), but 6 of its 15 modifier members are htmx-2 spellings htmx 4 never acts on: `scroll:window:top|bottom`, `show:window:top|bottom`, `focus-scroll:true|false`. htmx 4 parses `show:window:top` to `{ show: "window:top" }` and its handler matches only `'top'|'bottom'`; it reads `focusScroll`, not `focus-scroll`. The type then points the wrong way: the working `"innerHTML focusScroll:true"` is `TS2820 ... Did you mean '"innerHTML focus-scroll:true"'?`. The same strings reach two more sinks: `Partial(..., swap)` and `hxResponse().reswap(...)`.

## Evidence (executed)
`node probe.mjs M` (Chromium; target at y=2500, window pre-scrolled to 1200):

| swap | a7 | b4 | b6 | ga |
|---|---|---|---|---|
| `innerHTML` / `HX-Reswap: innerHTML` (baseline) | 1200 | 1200 | 1200 | 1200 |
| `innerHTML show:top` | 2508 | 2508 | 2508 | 2508 |
| `innerHTML show:window:top` | **2088** | 1200 | 1200 | 1200 |
| `innerHTML show:window:bottom` | 2088 | 1200 | 1200 | 1200 |
| `innerHTML scroll:window:top` | 1200 | 1200 | 1200 | 1200 |
| `outerMorph show:window:top` (fleet form) | 2088 | 1200 | 1200 | 1200 |
| `HX-Reswap: innerHTML show:window:top` | 2088 | 1200 | 1200 | 1200 |
| `focus-scroll:true` (typed; focused input below fold) | 0 | 0 | 0 | 0 |
| `focusScroll:true` (TS2820) | 2659 | 2659 | 2659 | 2659 |

On alpha7, `show:window:top` aligns the target's BOTTOM edge with the viewport (`scrollIntoView(false)`), so a full-page nav on `#main-content` lands the reader at the end of the new page.

Fleet (`grep` over the dedup corpus, comments and type declarations excluded): 238 live sites.
- htmx 4.0.0-alpha7 via CDN (inverted): ttl 49, fluent-html-demos 20, jtdigital-landing-page 13, projects-template-tests/test-hrastarr 32, test-artifact-deployment-2 29 = 143.
- htmx 2.x (works today, breaks on an htmx 4 upgrade): gzs/inovacije 84 (2.0.7), fivb-prototype 4, filmplast-v2 2 = 90.
- projects-template/templates/web 3 (no htmx at all, F-A-106); fluent-html-home-page 2 (doc strings).
- Canonical-era apps: 0 live sites; the vendored `swap-verbs.ts` comment "Not htmx 2's `show:window:top` ..." appears in about 20 of them, i.e. the template works around a literal the lib still offers.

History: template commit bb9f6e6 switched `.nav()` to `show:window:top` citing "a typed HxSwap literal since fluent-html v5.10.0", with a byte test asserting `hx-swap="outerMorph show:window:top"`; 13893a5 reverted it 13 days later. A typed literal plus a byte test is how it shipped dead.

## Why it matters
impact 2 (scroll resets that never happen, or scroll to the wrong end), pain 3 (compiles, lints, byte tests pass; TS2820 actively rewrites the working form into the dead one), reach 3 (238 live sites; 143 misbehaving today). Scorecard: silent-failure, error-quality, evolvability.

## Rough idea (not a design)
Enforcement layer: type. 9.0.0: delete the 6 members, add `focusScroll:true|false` (the TS2820 suggestion then points at the working spelling), codemod `show:window:top` -> `show:top` on page-root targets with a measured dry run (the 3 alpha7 repos + gzs/inovacije as the live repos). An additive 8.2.0 step could add `focusScroll:*` first. Pin each surviving modifier with an executed row (F-A-101). Prose deleted: the template comment at swap-verbs.ts:264-269 and its ~20 vendored copies.
