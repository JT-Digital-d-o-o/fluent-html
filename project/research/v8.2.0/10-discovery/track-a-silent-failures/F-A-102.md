# The recorded Partial() root cause is false

## Problem
The 8.0.0 CHANGELOG says `Partial()` "rendered `<hx-partial ...>`, an element name htmx 4 does not look for" and that "every partial swap has been inert in the browser since the htmx-4 cutover". The evidence was a string grep: the bundle has zero occurrences of the literal `hx-partial`. The bundle handles it with a regex instead:

```js
// beta6 htmx.js:1074-1075 (4.0.0: 1046-1047)
let response = text.replace(/<hx-([a-z]+)(\s+|>)/gi, '<template hx type="$1"$2').replace(/<\/hx-[a-z]+>/gi, '</template>');
```

So `<hx-partial hx-target="#a" hx-swap="outerMorph">` becomes exactly the `<template hx type="partial" ...>` that 8.0.0 started emitting. The false cause now propagates: ALGORITHM §0 ("Partial() shipped inert for a whole major"), scorecard finding 1, the capability scan's framing, the template contract's self-check (which asserts `hx-partial` is an UNREAD token: a working name), and `test/patterns.ts:198` ("the pre-htmx-4 element name must not come back").

## Evidence (executed)
`git archive 6de9c1f^ dist/src` into scratch `olddist/`; `OLD.render(OLD.Partial(ids.pa, ...), OLD.Partial(ids.pb, ...))` emits `<hx-partial hx-target="#pa" hx-swap="outerMorph"><div id="pa">A-new</div></hx-partial>` ×2. `node probe.mjs P` (Chromium, 4 bundles):

| response | a7 | b4 | b6 | ga |
|---|---|---|---|---|
| legacy `<hx-partial>` ×2 | pa=A-new, pb=B-new | same | same | same |
| current `<template hx type=partial>` ×2 | pa=A-new, pb=B-new | same | same | same |
| legacy `<hx-partial>` + main content | pb=B-new, main=MAIN-new | same | same | same |
| current Partial + main content | pb=B-new, main=MAIN-new | same | same | same |

16/16 outcomes identical between the two byte forms, 0 errors. Recon 03 §2.4 replayed the same bytes on beta4/beta6/4.0.0 (8/8); this run adds alpha7 (the build 3 live repos load from CDN) and the mixed main+partial response.

`node replica.mjs`: the template's name-only contract reports the legacy element as `["hx-partial"]` unread: its self-check at `htmx-grammar-contract.test.ts:124-127` asserts the false diagnosis as the proof that the check fires.

The transcripts behind "the guided agent shipped it broken" are gone (recon 02 §1.1: 1 jsonl survives, not a phase-2 one), so the August failure has no recorded cause.

impact 2 (the 8.0.0 bytes are harmless; the damage is to the verification loop: the program's founding anecdote teaches that grepping a minified bundle is an oracle), pain 2 (every Wave-1/2 agent and every guideline reader inherits the claim; two tests now pin it), reach 2 (ALGORITHM, scorecard, CHANGELOG, template test, lib test).
