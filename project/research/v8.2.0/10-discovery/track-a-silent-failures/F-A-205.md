# `.colspan` / `.rowspan` guesses self-heal into grid utilities that are inert on table cells

## Problem

The lowercase HTML-attribute guess fails, but the did-you-mean points at the Tailwind grid method:

```
colspan.ts(2,12): error TS2551: Property 'colspan' does not exist on type 'TdTag'. Did you mean 'colSpan'?
colspan.ts(3,12): error TS2551: Property 'rowspan' does not exist on type 'ThTag'. Did you mean 'rowSpan'?
```

`Td("wide").colSpan(2)` (the suggested fix, line 4 of the probe) compiles, lints, is safelisted and
passes the Tailwind oracle (`col-span-2` -> `grid-column: span 2 / span 2`), and renders
`<td class="col-span-2">`. `grid-column` has no effect on a `display: table-cell` box. This is the
oracle-is-non-null-only gap in its sharpest form: the class is valid, the element ignores it.

## Evidence (executed)

`$A2 = <scratch>/wave1/A2`.

- `tsc --strict --noEmit --pretty false $A2/tprobe/colspan.ts` against `dist/src/index.js`:
  the two TS2551 lines above; `Td("wide").colSpan(2)` produces no diagnostic.
- `node $A2/colspan-browser.mjs` (Playwright Chromium, 600px fixed table, CSS from the pinned
  design system): guess row `{"html":"<td class=\"col-span-2\">wide</td>","colSpanProp":1,"width":200,"gridColumn":"span 2 / span 2","display":"table-cell"}`;
  attribute row `{"html":"<td colspan=\"2\">wide</td>","colSpanProp":2,"width":399}`.
- `node --test dist/test/setter-errors.test.js`: 9 pass, 0 fail; the cases are `.src`, `.value`,
  `.id`, `.placeholder`, `.autocomplete`, `.viewBox`, field reads; no colspan/rowspan pin.
- `node $A2/colspan-census.mjs` (TS checker, 16 canonical apps): 630 `Td(`/`Th(` calls, 0
  `colSpan`/`rowSpan` on a TdTag/ThTag receiver, 3 `setColspan`, 4 `colSpan` on grid children.
  Recon 02 probe #11b reached the same class through all 5 layers.

## Why it matters

impact 2 (a table cell silently fails to span; layout breaks visibly but no layer names it) x pain 3
(the compiler's own suggestion is the bug) x reach 1 (0 fleet sites; recon 02 shows the guess
appears in probing) / effort S.

## Rough idea (not a design)

Type layer: on `TdTag`/`ThTag`, give `colSpan`/`rowSpan` a signature that fails with a message naming
`setColspan`/`setRowspan` (so TS2551 and completion both land on the attribute), and pin
`.colspan`, `.rowspan`, `.colSpan` on cells in `test/setter-errors.test.ts`.
