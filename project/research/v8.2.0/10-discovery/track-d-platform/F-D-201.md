# Typed open arms admit class strings that compile to no CSS; the oracle never enumerates the unions

## Problem
The validity oracle (`test/vocab-validity.test.ts`) compiles every member of the 33 `literals` rows and the `literals` groups, plus 1-7 hand-picked samples per `typeRef`/`theme` row. The 43 `typeRef` unions and their template-literal arms are never enumerated. Five arm shapes admit strings Tailwind 4.3.3 does not compile:

```ts
Div().gridCols("1.5")        // grid-cols-1.5         (also "-3", "0.25", "0")
Div().colSpan("0.25")        // col-span-0.25
Div().lineClamp("1.5")       // line-clamp-1.5
Div().duration("1.5")        // duration-1.5          (delay: same)
Div().scale("-3")            // scale--3              (scale bypasses signNeg, L-001)
Div().translate("x","-1.5/2")// -translate-x-1.5/2
Div().bgLinear(45.5)         // bg-linear-45.5        (bgConic: same)
Div().shadow("inherit/50")   // shadow-inherit/50     (textShadow, insetShadow: same)
Div().textShadow("none/50")  // text-shadow-none/50
Div().hover({ gridCols: "1.5", scale: "-3", textShadow: "none/40" })  // same, variant-prefixed
```

## Evidence (executed)
- `enum/enum.mjs` resolves every parameter type of the 159 vocab methods on `Tag` from `dist/src/*.d.ts` with the TS 5.9.3 checker: 205 signatures, 8,565 literal members, 5,348 open arms. `enum/run.mjs` renders each literal member and each open arm with fills (`${number}`: 13, 1.5, 0.25, -3, 1000, 0; `number`: 45, 45.5, -45, 400, 13, 1.5; `X/${number}`: 50, 37, 2.5, 0.5, 150, 1000). That is 112,036 calls, 290,043 emitted classes and 11,869 distinct classes, each checked with `design.candidatesToCss` on the lib's pinned 4.3.3. 101 distinct classes compile to null: bgLinear 26, bgConic 26, textShadow 12, shadow 6, insetShadow 6, gridCols 4, gridRows 4, lineClamp 3, colSpan 3, duration 3, scale 3, delay 3, translate 2. 0 failures come from the 8,565 literal members.
- `tsc --strict` on `enum/tsprobe.ts` against dist: exit 0 for all 17 probe lines. The two `@ts-expect-error` controls (`gridCols("brnad")`, `shadow("inherti/50")`) are consumed, so the check is live.
- In the scaffold copy (`app/src/app/d2probes/invalid-arms.ts`), all five layers pass silently:
  - tsc exit 0.
  - eslint (template config, plugin 4.1.0): 0 messages.
  - `tsx scripts/build-safelist.ts` (extractor 3.0.0-unreleased, `onUnresolved: "error"`): exit 0, and 18/18 probe classes are in `fluent-safelist.css`.
  - `postcss` Tailwind 4.3.3 build: 0 of 19 probe selectors get a rule, against 5/5 controls (`grid-cols-3`, `scale-150`, `shadow-black/50`, `bg-linear-45`, `hover:grid-cols-2`).
  - Render emits the dead class (`<div class="grid-cols-1.5">`).
- The reverse direction exists too. 1 of 224 ORACLE_ARGS tuples, `outline("2")`, is a value `TailwindOutline` rejects (TS2345), so the oracle validates a value the typed API cannot send (L-180).
- Reach. `census-arms.mjs` over the 58 dedup repos (12,811 files) finds 1,884 calls to the seven `${number}` methods, and 0 of them pass a decimal, negative, zero-grid or inherit/none-opacity value. The 16 canonical apps' shipped safelists (16,851 classes) contain 0 of these shapes.

## Why it matters
impact 2 × pain 2 × reach 1 / S = 4. The type says yes, the class does nothing, and no layer reports it: the silent-failure pattern guardrail 10 exists to prevent. The oracle's green run (564/564 in recon 03) covers samples and says nothing about the unions an agent actually writes into. Plausible agent guesses land here: `.duration("1.5")` for 1.5 s, `.scale("-100")` to flip, `.bgLinear(22.5)`.

## Rough idea (not a design)
Type layer plus CI. `${bigint}` rejects "1.5" and "0.25" and accepts "13" (measured with tsc 5.9.3; the sign still needs a separate arm rule). Swap it for the seven `${number}` arms, or close them to ladders. Make the gradient angle an integer arm, and drop `inherit/`/`none/` opacity for the shadow families. Extend the oracle to walk the typed unions the way this measurement did, so an open arm whose fills compile to null fails `gen:vocab --check` CI. Narrowing breaks 0 of 1,884 measured call sites, which the breaking-change lens should confirm for the 8.2.0 lane. No prose to delete.
