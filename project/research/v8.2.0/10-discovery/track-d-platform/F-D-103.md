# The htmx half of the grammar is hand-copied and frozen at beta4

`$S` = `<scratch>/wave1/D1`.

## Problem

The class half of fluent's grammar is derived: `gen:vocab --check` regenerates it from the pinned Tailwind design system and CI fails on drift (guardrail 9). The htmx half is typed by hand. Since beta6 the htmx package ships its own machine-readable grammar (`dist/htmx.d.ts`, 771 lines in 4.0.0, with `HtmxConfig`, `HtmxAjaxOptions`, `HtmxEventMap`; `dist/editors/jetbrains/htmx.web-types.json`, 49 attributes; `dist/ext/*.js` extension names). Fluent's types match none of the last three bumps.

## Evidence (executed)

`grammar-drift.py` over the four npm tarballs:

**Fluent's `HtmxGlobalConfig` is the beta4 d.ts, minus 9 keys.** All 13 fluent keys occur in beta4's `HtmxConfig` (fluent-only vs beta4: 0), including `inlineStyleNonce`, which htmx removed at beta5 and fluent still types (`patterns.ts:137`). Against 4.0.0's `HtmxConfig` (23 keys): missing in fluent 11 (`allowEmptySwapAfterOOB defaultFocusScroll defaultSettleDelay includeIndicatorCSS indicatorClass live morphIgnore morphScanLimit morphSkip morphSkipChildren requestClass`), fluent-only 1 (`inlineStyleNonce`), narrower upstream 2 (`history: boolean | 'reload'` vs fluent `boolean`; `mode` union vs fluent `string`).

**Fluent's `HxLocationConfig` vs 4.0.0 `HtmxAjaxOptions`** (what `HX-Location` JSON feeds `htmx.ajax`): missing `push`, `replace`, `selectOOB`; fluent-only `handler` (0 readers, recon 03 row 17). Executed consequence in [[F-D-105]].

**Name changes in the shipped manifests, per bump:**

| Bump | Changes | Count |
|---|---|---|
| beta4 -> beta5 | HtmxConfig -`inlineStyleNonce`; ext +`hx-prompt` | 2 |
| beta5 -> beta6 | HtmxConfig +`defaultSwapEmpty`; core event `htmx:swap:finally` -> `htmx:finally:swap`; ext +`hx-multipart` | 3 |
| beta6 -> 4.0.0 | HtmxConfig +`allowEmptySwapAfterOOB` +`live` -`defaultSwapEmpty`; verb +`query` (`hx-query`); ext `hx-optimistic` -> `hx-pending`; 10 of 14 hx-sse/hx-ws event names renamed (`htmx:after:sse:message` -> `htmx:sse:after:message`, `htmx:before:ws:request` -> `htmx:ws:before:message:outgoing`, ...) | 15 |

Fluent reflects 0 of the 20: `inlineStyleNonce` still typed; neither empty-swap key typed; `HxHttpMethod` (`htmx.ts:68`) rejects `"query"` (TS2322, recon 03 §2.2); `HxTrigger` still offers `'sse:message'`/`'ws:message'` (`htmx.ts:219-220`), which match neither the beta6 names nor the 4.0.0 names. Beyond names, the d.ts also gained `HtmxEventMap` (30 typed events) at beta6 and web-types grew 31 -> 46 -> 49 attributes.

**The manifests, not the release notes, are the oracle.** The 4.0.0 release notes list #3977 "reset trigger and swap modifiers"; the published 4.0.0 `htmx.js` contains 0 occurrences of `reset`. And the manifests are not infallible either: `HtmxConfig.noSwap: number[]` in d.ts, while 4.0.0 `htmx.js:2254-2257` matches string patterns (`"5xx"`), which fluent's `(number | string)[]` correctly allows. A derivation needs a curated override list.

## Why it matters

impact 2 × pain 2 × reach 2. Evolvability: every bump is a manual re-read of a 2,353-line bundle, and the last 3 bumps were not re-read at all (0/20). Silent-failure: a typed key that htmx dropped (`inlineStyleNonce`, `handler`, `sse:message`) compiles and does nothing; a live key (`defaultFocusScroll`, `allowEmptySwapAfterOOB`, `query`) is a compile error, so the type system steers toward the dead form (recon 03 §2.2 measured 6/6 broken lines compile, 4/4 working lines rejected). `events.ts:60-61` promises "a beta rename is a one-const edit re-verified by the pinned acceptance matrix"; the matrix is pinned to beta6 ([[F-D-101]]).

## Rough idea (not a design)

Layer: ci (plus type for the generated keys). `scripts/gen-htmx` reads the pinned `htmx.org` tarball's d.ts, web-types and ext names and either generates the config/location/method unions or `--check`s the hand-kept ones, with an explicit override table (e.g. `noSwap` strings). Tie it to the same CI job as `gen:vocab --check`, and point the eslint plugin's htmx name list at the same output ([[F-D-104]]). Additive keys 8.2.0; dropping `inlineStyleNonce`, `handler`, `sse:message`/`ws:message` goes to the 9.0.0 bundle (codemod: delete-key). Value grammar (swap modifiers, trigger modifiers) is not in any htmx manifest, so it stays with the runtime oracle (L-006/A1).
