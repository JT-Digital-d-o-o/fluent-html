# Extractor ships to 16 of 16 canonical repos as an untagged 3.0.0-unreleased whose own suite is red against lib 8.x

## Problem
`fluent-html-tailwind-extractor` has carried `"version": "3.0.0-unreleased"` since 43409f4 (2026-08-02). In practice it is released: every canonical-era app and both template variants build their CSS with it, pinned to `#main` or to the sha. Never cutting the release has three measured consequences:

1. The version string does not identify the build. 43409f4 and 83e81d2 both say `3.0.0-unreleased`; 43409f4's committed dist silently dropped every `md:`/`hover:` class from consumer safelists (`src/dist-parity.test.ts:1-7`, commit message of 83e81d2). Only a lockfile sha tells them apart.
2. The suite has been red since lib 8.0.0 pruned `.skewX` (2026-08-14, `fluent-html/CHANGELOG.md:117`), unnoticed for 48 days, because the repo has no CI and its devDependency is `file:../fluent-html` (package.json:57): the suite runs against whatever the sibling checkout holds.
3. The README tells consumers to `npm install --save-dev fluent-html-tailwind-extractor` (README.md:22), which returns E404.

## Evidence (executed)
- `node --import tsx --test src/*.test.ts` in the extractor (lib 8.1.0 via the `node_modules/fluent-html -> ../../fluent-html` symlink): `tests 56, pass 55, fail 1`; failing test `filters, transforms, list-style, will-change, v4 gradients`, `AssertionError: expected to include "skew-x-6"` at `src/extract.test.ts:113`.
- Every `.method(` in the extractor's test files and README checked against the 8.1.0 runtime surface (`00-recon/data/01-surface.json`): 1 stale name, `skewX`. The red test is exactly the 8.0.0 prune.
- `git tag` in the extractor: 0 tags. `.github`: absent. Last commit 83e81d2, 2026-08-03 (59 days before this run).
- `git show 43409f4:package.json` and `git show 83e81d2:package.json`: both `"version": "3.0.0-unreleased"`.
- Fleet (dedup corpus, installed `node_modules/fluent-html-tailwind-extractor/package.json`): 17 installs report `3.0.0-unreleased` (competify, competition, everyframe, everyframe-composer, fl-um, fluent-html-home-page, gzs/stem-50, home-page, na-cent, popri, sportoawards, stojnica, studio, website-sales-funnel-automation-system, workshop-toni, template full-stack, template web). The lockfiles of all 16 repos resolve `83e81d21411032ff950b203c1ab8955c8d4a92c1`. Older lines: 10 installs on 2.0.0, 14 on 1.1.1.
- `npm view fluent-html-tailwind-extractor` -> `E404 Not Found`.

## Why it matters
Reach 3: 16/16 canonical repos build CSS with this unversioned build. The extractor suite is the only place its fixtures pin the method-to-class mapping, and it is already red, so the next 8.2.0 vocab row lands on a suite nobody reads. Evolvability: the Wave-4 `lockstep.md` (publish order, peer constraints) has no extractor version to name. Verification loop: 0 gates.

## Rough idea (not a design)
Cut 3.0.0 for real (date the CHANGELOG, tag, drop `-unreleased`), replace the `skewX` fixture, and run the suite in CI against `fluent-html#main` (ci layer) so a vocab prune turns the extractor red the day it lands. Replace the README install line with the git spec consumers use.
