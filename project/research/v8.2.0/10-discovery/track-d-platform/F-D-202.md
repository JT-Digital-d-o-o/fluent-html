# no-tailwind-in-raw-class autofix rewrites valid Tailwind 4.3.3 classes into fluent calls that fail tsc

## Problem
The error-level escape-hatch rule autofixes a raw Tailwind token into a fluent chain by prefix-splitting the class against the vocab's method prefixes. It never checks that the split-off value is in the method's typed union. For every valid Tailwind 4.3.3 class the typed surface cannot express, the autofix writes code that does not compile. In 5 of the 6 examples below, the rewrite also targets a different CSS property than the original class. Examples from `eslint --fix-dry-run` on the scaffold:

```
addClass("justify-items-center") -> .justify("items-center")   TS2345 '"items-center"' is not assignable to 'TailwindJustifyContent'
addClass("scroll-mt-4")          -> .scroll("mt-4")            TS2345 '"mt-4"' is not assignable to 'TailwindScrollBehavior'
addClass("ring-offset-2")        -> .ring("offset-2")          TS2345
addClass("bg-cover")             -> .bg("cover")               TS2345 '"cover"' is not assignable to 'TailwindColor'
addClass("max-sm:hidden")        -> .variant("max-sm", { hidden: true })   TS2345
addClass("bg-linear-30")  [typed spelling .bgLinear(30) exists] -> .bg("linear-30")   TS2345
```

The message says "Replace with: .bg(\"cover\")", and tsc then rejects it without naming `.cssProp("background-size","cover")`, the only spelling that passes both layers. An agent that runs `lint:fix` and then `tsc` gets a loop where each layer's fix is the other layer's error.

## Evidence (executed)
- Scaffold probe (22 raw tokens in `.addClass()`): eslint 20 messages. 19 carry an autofix, 1 is `tailwindNoMethod` (`content-center`), and 2 tokens get no message at all (`pointer-coarse:p-4`, `noscript:hidden`; see F-D-204). `tsc -p tsconfig.d2.json` on the autofixed file: 19 errors, one per rewritten line (lines 3-5, 7-17, 20-24).
- Systematic sweep. `enum/run.mjs` renders every literal member of every typed union of the 159 vocab methods (112,036 calls) and yields the typed-reachable set (11,768 classes that compile). `getClassList()` on 4.3.3 minus that set, restricted to roots the coverage watch counts as covered, leaves 4,584 valid classes the typed surface cannot emit. The count is after removing 26 numeric-arm fill gaps: `@container`, `bg-linear-N` and `bg-conic-N` (24), and `scale-200`. Also 156 valid variant heads are rejected by `.variant()` (F-D-204).
- The plugin's `analyzeToken` (dist 4.1.0) over those: 4,371 utilities and 145 variant heads get a `fluentChain`, 210 get `tailwindNoMethod`, and 3 plus 11 are not reported.
- Every chain was written into `src/app/d2probes/chains.ts` and typechecked: 4,516 of 4,516 fail tsc. The 24 typed-reachable `bg-linear-N`/`bg-conic-N` classes are rewritten to `.bg("linear-N")`, which also fails (the correct call is `.bgLinear(N)`).
- Reach on the upgrade path. A census over the 42 pre-7 dedup repos found 46 raw unreachable tokens (`bg-clip-text` 5, `ring-offset-2` 5, `ring-inset` 5, `bg-no-repeat` 3, `border-collapse` 3, `scroll-mt-*` 5, and others) and 28 raw `max-sm:` heads (filmplast-v2) that this autofix would process when those repos move to 8.x. Canonical-era repos have 0 such raw tokens, because the rule blocks raw strings. Recon 02 measured the agent pure prior at 41/39 `addClass` calls per run.

## Why it matters
impact 2 × pain 3 × reach 2 / S = 12. The autofix is the enforcement layer's own suggested fix, and it points into a compile error that names the wrong union. Dimensions: error-quality (the fix is wrong), verification-loop (lint:fix then tsc does not converge), decision-closure.

## Rough idea (not a design)
Lint layer, plugin patch. Literal-list rows get exact patterns only. A prefix catch-all proposes a chain only when the value passes the row's closed values (theme namespaces checked against the plugin's generated class list, which already carries 1,073 TAILWIND_ROOTS). Otherwise the rule emits `tailwindNoMethod` naming `.cssProp()`. Add a plugin test that tsc-checks the proposed chain for every `getClassList()` class. No guideline prose to delete. It lets the "autofix sweeps introduced bugs twice" caution (S-25) stay a review bar, not a live hazard.
