# vertical-align has no method

`$E7` = `<scratch>/track-e/E7`

## Problem

`align-*` is a Tailwind utility root with a closed value list, parked as backlog in `IGNORED_ROOTS` (vocab-coverage.test.ts:48). L-159 left it parked on the evidence of 5 sweep hits with the rule "re-run the sweep, promote on evidence". The canonical fleet writes it through the hatch:

```ts
Span(...).cssProp("vertical-align", "middle")   // workshop-toni story.marks.view.ts:140
Td(...).cssProp("vertical-align", "top")        // everyframe ts-sdk-docs.view.ts:98
```

The pure-prior guesses: `Td().addClass("align-middle")` -> eslint 4.1.0 `'align-middle' ... is a Tailwind 'align-middle-*' utility with no fluent method. Use .cssProp() for arbitrary CSS, or file the vocab gap`; `Td().align("middle")` -> `TS2339: Property 'align' does not exist on type 'TdTag'`.

## Evidence (executed)

- `node $E7/fam.mjs` (58 dedup repos): 39 sites in 13 repos. Canonical: 12 cssProp sites in 5 repos (workshop-toni 5, everyframe 3, fluent-html-home-page 2, competify 1, website-sales-funnel 1). Pre-7: 22 class-string sites in 5 repos. Authored CSS: 5 lines in 3 repos.
- Values (canonical): top 7, middle 5; 12/12 are `align-top` / `align-middle`.
- First-commit dates (`git log -S'vertical-align' -- src`): everyframe 2026-07-09, workshop-toni 2026-08-03, website-sales-funnel 2026-09-03, fluent-html-home-page 2026-09-09, competify 2026-09-11.
- Sketch (`$E7/lib` + `$E7/probe2`): `Span().align("middle")`, `Td().align("top")` compile on tsc 5.9.3 and 6.0.3 and render `align-middle` / `align-top`; Tailwind 4.3.3 returns `vertical-align: middle` / `top`. `@ts-expect-error` on `Div().align("center")` holds, so the flex-alignment guess (the `.alignItems` prior, gl/views.md:84) fails with the vertical-align union printed instead of silently emitting a class.
