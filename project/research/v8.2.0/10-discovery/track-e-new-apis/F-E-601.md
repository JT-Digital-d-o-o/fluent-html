# No list-shaped IfThen: the non-empty guard is hand-rolled at 371 canonical sites, the shipped ForEachElse has 1

## Capability
Render a whole container (section with heading, table with thead, card) only when a list has at least one item, with the list bound in the branch and narrowed (`items[0]` is the element, not `T | undefined`), and with `null`, `undefined` and `[]` all taking the else branch. fluent-html ships one empty-state primitive, `ForEachElse` (src/control/iteration.ts:102), and it is row-level: the empty view replaces the rows while the container stays (`Ul(ForEachElse([], f, () => Li("none")))` renders `<ul><li>none</li></ul>`, executed). The fleet's dominant shape is container-level.

## Problem
Apps express "non-empty list" three ways, none of them the shipped one:

1. Restate the collection (taught at gl/fluent-html.md:415, gl/views.md:43):
   `IfThenElse(props.items.length > 0, () => Table(..., Tbody(ForEach(props.items, Row))), () => P(COPY.none))` (competition/src/app/competition/judging/views/judging.views.ts:27).
2. Coerce empty to null so IfThen's value overload binds a name, copied from the template's own exemplars:
   `IfThenElse(props.topPages.length > 0 ? props.topPages : null, (pages) => Div(Table(...)), ...)` (templates/full-stack/src/app/analytics/views/dashboard.view.ts:321, 9 copies in the template).
3. Two-step guards for optional lists: `IfThen(tags, (tags) => IfThen(tags.length > 0, ...))`, `const all = tags ?? []; IfThen(all.length > 0, ...)`, `IfThen(tags?.length ? tags : undefined, ...)` (one per agent run, below).

And the natural nullable idiom the guidelines teach for scalars (`IfThen(user.avatar, (a) => ...)`) silently mis-renders for optional arrays, because `[] != null` runs the branch:

```
render(IfThen([], (cs) => Section(H2('What it does'), Ul(ForEach(cs, (c) => Li(c))).grid().gap('3')).m('t', '16')))
-> <section class="mt-16"><h2>What it does</h2>
<ul class="grid gap-3"></ul></section>
```
13 canonical sites in 3 repos pass an optional array straight to IfThen this way (e.g. home-page/src/app/modules/views/modules.components.ts:632, a Section with eyebrow + heading; everyframe/src/app/marketing/views/dev.components.ts:91, a `Div(...chips).m("t","8")`).

## Why it matters
impact 2 x pain 2 x reach 3 / effort S(1) = 12. Three ways to say one thing (restated length check, coerce-bind, two-step optional guard) plus a fourth shipped one nobody uses (ForEachElse, 1 canonical site); the template teaches two of them by exemplar. The nullable idiom applied to an optional list renders a heading over an empty list (13 exposures). Dims: decision-closure (one way), silent-failure (empty container), context-economy (5 guideline lines + the ForEachElse reference line go).

## Rough idea (not a design)
Type layer: `IfAny`/`IfAnyElse` with the mutability-preserving `NonEmpty<A>`. Lint layer: `prefer-if-any` autofix for the four shapes above (receiver must be array-typed; 338/338 dry-run sites type-check after the fix). Delete gl/fluent-html.md:411-415, gl/CLAUDE.md:166-167, rewrite gl/views.md:43 and REFERENCE.md:238. 9.0.0: remove ForEachElse (2 fleet sites, codemod `IfAnyElse(xs, (ys) => ForEach(ys, f), e)`). Alternative considered: make IfThen/IfThenElse treat `[]` as absent; rejected here because it silently changes the output of every array-valued value-overload site (102 type-checked canonical sites) instead of adding a name. Name is open (IfAny vs IfNonEmpty); the agent-fitness lens should test which one a blind agent finds.
