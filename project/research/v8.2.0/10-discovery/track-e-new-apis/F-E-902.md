# Nav and tab links mark themselves current

($E9 = <scratch>/track-e/E9)

## Peer capability

- **Unpoly** `[up-nav]`: links inside a nav container get `.up-current` automatically when their href matches the current location; `up-alias` widens the match to a URL pattern for section links.
- **Rails** `current_page?` / `link_to_unless_current`: the view layer answers "is this link the page I am on" from the request.
- fluent-html + template: the route is known at the link (`.nav(route)`, `.tab(route)`), the request path is known in the render context (`pageSeo.canonicalPath`), but nothing joins them, so every app threads an `active` flag by hand and the template's own components never expose it to assistive technology.

## Problem

The template's tab primitive styles the active tab and says nothing about it:

```ts
export function TabItem({ label, active = false }: TabItemProps) {   // shared/ui/nav.ts:39
  return A(label).apply(tabItem(active)).p("b", "2").cursor("pointer");
}
```

Rendered (`npx tsx tabprobe.ts`): the active tab is `<a class="... font-semibold text-primary border-b-2 border-primary ...">Overview</a>`, with no `aria-current`. A sighted user sees the underline; a screen-reader user hears four identical links. The web template's `NavLinkItem` (header.ts:130-141) computes `currentPath === link.href` and uses it only for color. Each controller computes and passes the flag (`TabItem({ label: tab.label, active: tab.route === activeTab })`, analytics-tabs.ts:12), which is a second source of truth next to the URL the link already resolves.

## Evidence (executed)

1. **Template render**: `TabNav({ items: [TabItem({ label: "Overview", active: true }), TabItem({ label: "Cohorts" })] })` renders 0 `aria-current` (tabprobe.ts).
2. **Fleet census** (scan.mjs, 58 repos, `.claude`/node_modules/dist skipped):
   - `export function TabItem` in 41 repos (16/16 canonical-era); 41/41 definition files contain no `aria-current` or `current:`.
   - 18 `TabItem({ ... active ... })` call sites in 13 canonical repos (template included).
   - Function-level classifier (active.mjs): 52 nav/tab-named link components (names matching Tab, Nav, Link, Rail, Crumb, Entry, Item) carry an active flag in 15 canonical repos; 36 emit no `aria-current`, 16 do.
   - 52 hand-rolled `setAria({ current ... })` calls in 9 canonical repos: the authors who noticed wire it by hand, per component.
   - Section links use prefix matching by hand: competify/src/shared/views/app-shell.ts:90 and na-cent/src/shared/views/app-shell.ts:156 (`current === path || current.startsWith(path + "/")`).
3. **Prototype** (`$E9/tpl`, scratch copy of the template): `markCurrent` added at the end of `.nav` and `.tab` (diff in the api sketch). Rendering the four analytics tabs under `pageSeo.run({ canonicalPath: "/admin/analytics/cohorts" })` stamps `aria-current="page"` on Cohorts only (1 of 4); `npx tsc --noEmit` 88 errors before and after, diff empty.
4. **Styling contract**: the pinned Tailwind oracle (tw.mjs, 4.3.3) compiles `aria-[current=page]:font-semibold` to a `[aria-current="page"]` rule, and fluent types the `aria-[${string}]` arm. Trap worth pinning in the design: bare `aria-current:` compiles to `[aria-current="true"]`, which never matches `"page"`.

## Why it matters

- impact 2: the current tab or section is not announced in 16/16 canonical apps' template tab navs (ARIA 1.2 `aria-current`; WCAG 1.3.1 state conveyed by color and border only).
- pain 2: silent. No type, lint or visual check fails; it surfaces only under a screen reader.
- reach 3: the template primitive is in every canonical repo; 15/16 canonical repos thread active flags into link components.
- Dimensions: silent-failure (a11y), decision-closure (the URL is the single source of truth), prior-alignment (the peer prior: Unpoly and Rails derive current from the request).

## Rough idea (not a design)

Framework layer, lane `template`. `.nav` and `.tab` stamp `aria-current="page"` when the route's resolved path equals the request path in the render context; template TabItem/nav presets style `aria-[current=page]` and drop the `active` prop; AnalyticsTabNav calls `.tab()` on every tab (the verb can also omit `hx-push-url` on the current link, which is why analytics-tabs.ts:13-15 skips the verb today). Enforcement: runtime (the verb), backed by a template unit test that renders TabNav under a request path. Open: query-aware matching (needs `request.url`, not only the query-stripped canonicalPath) and a `current: "prefix"` option for section links. Smallest fallback if the verb is rejected: one line in TabItem, `.setAria({ current: active ? "page" : undefined })`, which closes the a11y half only.
