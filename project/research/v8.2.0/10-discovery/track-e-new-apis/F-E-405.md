# No tone badge in the component layer

($E4 = <scratch>/track-e/E4)

## Problem

The task said "a coloured badge for the status". src/shared/ui exports StatCard, EmptyState, Pagination, Alert, buttons and
tabs (index.ts:2-9) but no badge, so each run wrote one: a Span, a status-to-tone map (whenMatch in 2 runs, the template's
`stylers<>` in 2, a palette-literal Record in the 2 pure-prior runs), then the same pill chain
(`inlineFlex/items/p x 2/p y 0.5/rounded/text xs/font medium`). The fleet carries the same component under a new name per
feature.

## Evidence (executed)

- **Agent runs** (recon 02, 6 runs; E4's 4 new runs were denied, see overflow): 6/6 defined StatusBadge/statusBadge
  (blind1:295, blind2:300, guided1:348, guided2:345, pp1 views.ts:157, pp2 views.ts:201). The in-repo four differ only in
  `inlineFlex` vs `inlineBlock`, `rounded("control")` vs `rounded("full")` and `p x 2` vs `2.5`: four designs for one job.
- **Fleet** (`$E4/corpus.py`, app-authored, `function|const *Badge*`): **278 definitions / 50 repos** (canonical 98 / 14);
  90 are tone-mapped pills (whenMatch / stylers / tone or status map + rounded) in 35 repos (canonical 24 / 7). Most
  frequent canonical names: StatusBadge 12, EventBadge 10 (vendored analytics), RoleBadge 4.
- **Prototype** (`$E4/proto.diff`): the api_sketch Badge compiles (tsc 0), renders
  `<span class="bg-warning/10 text-warning inline-flex items-center px-2 py-0.5 rounded-full text-xs font-medium">Invited</span>`,
  and `npm run css` emits `.bg-warning\/10` and `.text-warning` into styles.compiled.css (extractor sees the literal branches).

## Why it matters

impact 2 (the most duplicated component in the fleet; each copy is a design decision an agent re-makes and a place a
palette literal re-enters, as in pp1/pp2) x pain 1 (no failure, only drift and tokens) x reach 3 / S = 6. Moves
decision-closure and context-economy.

## Rough idea (not a design)

Add `Badge` + `BadgeTone` to src/shared/ui/data.ts and export it; a feature maps its own status union to a tone with
`MatchValue` (closed both ways). Enforcement: type (closed tone union) and the existing palette-literal opt-out. The views
guideline's badge example can point at it instead of carrying its own chain.
