# Scroll margin lost its method in the 8.0.0 prune

`$E7` = `<scratch>/track-e/E7`

## Problem

8.0.0 deleted `scrollM` together with the snap family because the census counted 0 method call sites (CHANGELOG.md:118). It kept `scrollP`, which has 0 TS sites in any channel today. Since the prune, canonical apps have written scroll margin 15 times through the hatches, each time as a rem literal converted by hand:

```ts
Section().cssProp("scroll-margin-top", "6rem")   // competify legal.components.ts:145
Section().setStyle("scroll-margin-top:3.5rem")   // everyframe rep-counting.view.ts:335
```

The pure prior (`addClass` with a Tailwind string, 41/39 calls per run in recon 02) meets a dead end:

| Guess | First diagnostic (fluent-html 8.1.0, eslint plugin 4.1.0, tsc 6.0.3) |
|---|---|
| `Section().addClass("scroll-mt-24")` | eslint: `Replace with: .scroll("mt-24"). [autofix]` |
| the autofixed `.scroll("mt-24")` | tsc: `TS2345: Argument of type '"mt-24"' is not assignable to parameter of type 'TailwindScrollBehavior'`; eslint: 0 messages |
| `Section().scrollM("t", "24")` | tsc: `TS2551: Property 'scrollM' does not exist on type 'Tag'. Did you mean 'scroll'?` |
| `Section().scrollMt("24")` | tsc: `TS2551 ... Did you mean 'scroll'?` |

The coverage watch does not see the gap: `scroll-m*` roots count as covered through the kept `scroll` prefix (F-D-203).

Renders: `<section class="scroll-mt-24">`, `<section class="scroll-mt-14">`. Tailwind 4.3.3 `candidatesToCss` returns `scroll-margin-top: calc(var(--spacing) * n)` for n = 6, 11, 14, 24, 28.

## Why it matters

impact 2 x pain 2 x reach 3 / S = **12**.

- The 8.0.0 census counted method calls only. Demand for a pruned utility shows up in the hatches, and this one is the second largest named-utility hatch in canonical code after the table border model (F-E-703).
- prior-alignment: `scroll-mt-24` is the Tailwind spelling the prior writes first.
- error-quality: the lint's one-shot fix does not compile, and tsc's did-you-mean points at `scroll` (scroll-behavior).
- decision-closure: two hatch spellings (cssProp and setStyle) for one static value.

## Rough idea (not a design)

Type layer, additive. Restore the deleted `space("scrollM", ...)` row, overloads and runtime as a mirror of `scrollP`. The eslint plugin and extractor re-derive (S-12), so the `scroll-mt-*` autofix lands on a compiling call and tsc's did-you-mean for `.scrollMt` becomes `scrollM`. Whether scroll margin also gets directional shorthands like `.mt()` is a naming call for the design. No prose added.
