# Change-driven swaps into a fragment have no verb

## Problem

The template's `.onChange(route)` (swap-verbs.ts:161) imposes `target: MAIN` (swap-verbs.ts:357-366). `.search` got a `(target, route)` overload at :151-156; `.onChange` did not. Any control or form whose change must re-render one region, which covers property editors, upload-on-pick and autosave, therefore falls back to one of three shapes:

1. Writing `trigger: "change"` into the route options and chaining `.fragment(id, route)`. everyframe-composer does this 13 times. It is the shape the guideline bans ("never hand-rolled trigger bags").
2. Dropping to raw `setHtmx({ ...route(), trigger: "change", target, swap, sync })`, as in home-page content-panel.components.ts:24 and gzs/stem-50 thesis.sections.view.ts:109.
3. Forking template core. gzs/stem-50 added `onChange(target, route, options?)` to its copy of swap-verbs.ts (:161-176, :371; commit 25a0738) and calls it 3 times.

The hand-rolled autosave also hits a runtime trap that no type or lint catches. gzs/stem-50 puts `change, input changed delay:1200ms` on the `<form>`, and its comment promises it "autosaves as the student types". htmx 4's `changed` modifier compares the listening element's `.value` (`spec.values ... fromElt.value`, htmx 4.0.0 `#onTrigger`). A form has no `.value`, so the input half never fires, and only the blur-time `change` saves.

## Evidence (executed)

- **Census** (`track-e/E3/mine.mjs` then `change.mjs`, 58-repo dedup corpus, app-authored):
  - 98 `trigger:` bags contain `change` (19 repos).
  - 52 of them name an explicit target that is neither `body` nor main content: 15 repos, canonical 13 sites / 4 repos (everyframe-composer 10, sportoawards 1, home-page 1, gzs/stem-50 1). 3 more composer route builders are consumed by `.fragment`.
  - Upload-on-change (multipart plus change): 20 sites / 7 repos, canonical 10 / 1.
  - `.onChange(<Ids>.x, ...)`: 3 canonical sites, all in the gzs/stem-50 fork.
- **Runtime oracle** (`oracle.mjs P1`; Chromium; lib pin 4.0.0-beta6 and template-served 4.0.0, sha 54ac91b6 equals npm 4.0.0). The prototype's emitted form is `hx-post hx-target="#region" hx-swap="outerMorph" hx-trigger="change" hx-include="closest form"`:
  - Selecting an option sends `POST /p/tune` with body `s=b&q=kept`, so the sibling field is carried.
  - `#region` becomes `tuned`, `#main-content` is untouched, and there is 1 `#main-content`.
  - The upload variant sends `multipart/form-data` with `filename="clip.mp4"` into `#region`.
  - Results are identical on both bundles.
- **Autosave trap** (`p9.mjs`, `out-p9.json`), on both bundles, after typing "Thesis" and pausing 800 ms:

  | Trigger | Where | Requests after typing | Requests after blur |
  |---|---|---|---|
  | `change, input changed delay:300ms` (the gzs/stem-50 shape) | form | 0 | 1 |
  | `change, input delay:300ms` | form | 1 | 2 |
  | `change, input changed delay:300ms` | control | 1 | 2 |

- **Type sketch** (`tpl/src/core/htmx/swap-verbs.ts`, 27 changed lines; `tpl/src/probe/onchange.ts`; tsc on the template's own node_modules, fluent-html 8.1.0): exit 0. Five `@ts-expect-error` lines are each consumed:
  - a wrong region: `onChange(ids.otherRegion, routes.tune())` gives TS2345 `Id<"other-region">` vs `Id<"region">`
  - a page route into a fragment
  - an undeclared route (the DeclaresNothing arm)
  - the untargeted form given a fragment route (TS2345 vs `PageRoute`)
  - a numeric `delay`

  The rendered output for a form with `{ delay: "800ms" }` is `hx-trigger="change, input delay:800ms" hx-sync="replace" hx-status:422="swap:outerMorph target:#thesis-form push:false"`; on an input it is `change, input changed delay:800ms`.

## Why it matters

impact 2 x pain 2 x reach 3 / S = 12.

- **decision-closure:** the vocabulary has a hole exactly where the guideline forbids the workaround.
- **silent-failure:** a canonical autosave ships dead.
- **prior-alignment:** `.search(target, route)` already teaches the shape, so an agent's first guess (`.onChange(ids.x, route)`) fails today with TS2554.

## Rough idea (not a design)

Add the targeted overload and `{ invalid, delay }` to the template verb (template lane, no lib release). The enforcement layer is type: the stance check is shared with `.fragment`. Delete the htmx.md lines that send region-targeted change to `setHtmx`, and teach one line. A follow-up lint can flag `trigger:` keys inside route options passed to a verb.
