# .size(): one call for equal width and height

($EG = <scratch>/track-e/E-gaps)

## Peer capability

- **Tailwind 4**: `size-*` sets width and height in one class; the fleet's own design files use it 1,805 times.
- **fluent-html 8.1.0**: the class has no method, so a design's `size-4` becomes `.w("4").h("4")` by hand, and eslint-plugin 4.1.0's `analyzeToken` reports every `size-*` as tailwind-unmapped (no autofix).

## Problem

CHANGELOG.md:439 deferred `size()` because it "collides with the `<select size>` instance field". 8.0.0 privatized storage fields: SelectTag now holds `protected _size?: number` behind `setSize()` (dist/src/elements/forms.d.ts:216-219), so a styling `size()` on Tag shadows nothing. The vocab-coverage watch still parks `size` as backlog (test/vocab-coverage.test.ts:50), and the ledger's evidence gate (L-177, L-159: 0 hits in an 8-app sweep) predates both the design-file corpus and the 16 canonical repos.

## Evidence (executed)

1. **Design census** (`node $EG/design/collect.cjs`, 249 Tailwind design files under the `project/` folders of 15 canonical repos, sales sessions excluded): 33 distinct `size-*` tokens, 1,805 occurrences, 7 repos (everyframe, everyframe-composer, home-page, workshop-toni, popri, stojnica, gzs/stem-50). The Tailwind 4.3.3 oracle compiles `size-4`, `size-full`, `size-[18px]`.
2. **TS census** (`node $EG/size/count.mjs`, app code, tests excluded): 382 `.w(x).h(x)`/`.h(x).w(x)` chains with the same value, 39 equal unit-overload pairs (`.w("px", 18).h("px", 18)`), 2 variant objects with equal `w`/`h` keys: 423 sites, 26% of the 1,649 `.w(` calls, in 16/16 canonical repos (everyframe-composer 94, workshop-toni 82, home-page 37, competify 30, everyframe 27, popri 24, template 24, sportoawards 20, stojnica 15, gzs/stem-50 14, na-cent 14, studio 12, website-sales 12, fluent-html-home-page 7, fl-um 6, competition 5).
3. **Prototype** (`$EG/lib`, a scratch copy): vocab row, `TailwindSize` union, Tag overloads and emitter. `gen:vocab --check` OK; `Div().size("4").size("px", 18).hover({ size: "6" })` renders `size-4 size-[18px] hover:size-6`; `Div().size("screen")` is a compile error. vocab-validity, class-vocab and gen-types pass 1007/1007; vocab-coverage fails only on the now-stale `size` IGNORED_ROOTS row, which this change deletes.
4. **Codemod dry run** (`$EG/size/dry.sh`: per unit a scratch copy of the TS sources, the repo's own node_modules with fluent-html swapped for the prototype, the repo's own tsc before and after `$EG/size/codemod.mjs`): 423/423 rewritten across 17 units (16 repos, template split into full-stack and web), tsc error count equal before and after in every unit, 0 new errors (the two template units carry 154 and 16 pre-existing errors from the partial copy, unchanged).
5. **Agent prior**: recon-02's six team-invite transcripts contain 0 square elements, so there is no run evidence either way (the E4 runs were not executed; see overflow).

## Why it matters

impact 2 (one call per square element; design-to-fluent translation gets an autofix for 1,805 tokens), pain 2 (today the only spelling is a two-call rewrite the tooling never proposes), reach 3 (16/16 canonical repos). Hurts prior-alignment (`size-4` is Tailwind 4's own spelling) and context-economy.

## Rough idea (not a design)

One vocab row (guardrail 9: extractor and eslint re-derive), a closed `TailwindSize` union without viewport keywords, and an optional fold codemod (8.2.0 is additive, so the codemod is a convenience, measured above). Deletes the IGNORED_ROOTS row and the CHANGELOG deferral note; no guideline prose covers `size` today.
