# With the palette opted out, .bg('gray-100') never names a token

## Problem

The template turns the Tailwind palette off (`FluentColorConfig { defaultPalette: false }`), and 13 of 15 canonical repos keep that. The pure prior's first color is a palette literal (recon 02 D4: 43/40 per run). The error names the alias only:

```
p05-palette-optout-on.ts(2,33): error TS2345: Argument of type '"gray-100"' is not assignable to parameter of type 'TailwindColor'.
```

The fix (use a role token from `defineTheme`) is in the seam's JSDoc, not in the message. TypeScript prints the alias name for an aliased union, so no member of `TailwindColor` can carry the hint.

## Evidence (executed)

`$B2 = <scratch>/wave1/B2`. Prototype on `.bg` only (tailwind-methods.d.ts copy):

```ts
bg<const C extends string>(color: C extends TailwindColor ? C : C extends `${TailwindColorName}-${string}` ? "palette literals are off in this app (FluentColorConfig): use a role token from your defineTheme colors, e.g. .bg('surface-2'), or a tint .bg('primary/10')" : TailwindColor): this;
```

After:

```
p05-palette-optout-on.ts(2,33): error TS2345: Argument of type '"gray-100"' is not assignable to parameter of type '"palette literals are off in this app (FluentColorConfig): use a role token from your defineTheme colors, e.g. .bg('surface-2'), or a tint .bg('primary/10')"'.
```

## Why it matters

impact 1 x pain 2 x reach 2 / effort M. The model knows it needs a token after the current message but has to find the theme file to learn which (recon 02 #5, one-shot 'partial').

## Rough idea (not a design)

Type layer, but only through the class-string contract (S-12): the generic signature is emitted by gen:vocab for every color-taking row, never hand-edited; variant-object keys keep their current path. Effort M because it touches the generator and every color method's d.ts. Check-time cost measured within noise on the largest dry-run repo.
