# The rooted Partial overload brands content it never inspected

($B1 = <scratch>/wave1/B1)

## Problem

9d86871 made `Partial(target: Id<N>, content: View, swap?)` return `Tag & Rooted<N>`, justified by "htmx
resolves a partial's destination as hx-target or else the template's own id, i.e. target and root id are one
slot". That holds for an inner swap. The default swap is `outerMorph`, which replaces `#N` with `content`; when
`content` is not rooted at `#N` the id leaves the DOM. The brand is still stamped, so
`reply.renderFragment(ids.teamCount, Partial(ids.teamCount, Span("3 members")))` compiles (probe r01, 0 errors),
and the lib's own type test asserts exactly this call as correct (type-surface.test-d.ts:638, :640).

## Evidence (executed)

1. **Chromium** (`$B1/rt/browser.mjs`; page `<span id="team-count">` + a `.fragment(ids.teamCount, routes.count())`
   button; server answers `render(Partial(ids.teamCount, Span("3 members")))`; clicked twice):

   | Response | beta6: #team-count after click 1 / 2 | 4.0.0 | Console |
   |---|---|---|---|
   | `Partial(id, Span("3 members"))` (compiles as Rooted) | **0 / 0** | **0 / 0** | `htmx: '#team-count' on hx-target did not match any element` |
   | `Partial(id, Span("3 members").setId(id))` (control) | 1 / 1 | 1 / 1 | none |

2. **Prototype** (`$B1/libcopy`): Id overload split into `content: Rooted<N> & View, swap?: Extract<HxSwap, `outer${string}`>`
   and `content: View, swap: Exclude<HxSwap, `outer${string}`>`, both returning `Tag & Rooted<N>`; selector
   overload unchanged. `npx tsc --noEmit -p tsconfig.json`: exactly 2 errors, at type-surface.test-d.ts:638 and
   :640 (the pins of the unsound case); the `"innerHTML"` pin at :639 and every other src/test file compile.
3. **Fleet** (15 repos pinned 8.1.0 + workshop-toni): 11 app-authored `Partial(xIds.y, …)` sites; 11/11 content
   components root at their target (Toast via ToastRegion, SectionCard via a SECTION_REGION lookup); 0 of 175
   `renderFragment(` calls take a `Partial` (all 11 go through `renderView` or an array), so the narrowing
   breaks 0 measured sites.

## Why it matters

impact 2 (the region disappears after one swap and every later update to it is dropped with only a console
warning) x pain 2 x reach 1 (latent: 0 live misuse, and only renderFragment/fragment() consume the brand).
Hurts invariant-safety: the brand is the evidence the contract rests on, and here it is stamped without a witness.

## Rough idea (not a design)

Type layer: brand an outer-swap Partial only when its content is `Rooted<N>`; keep the brand for inner swaps.
The two pins flip to `@ts-expect-error`. No guideline line depends on the current behaviour.
