# The swap-modifier union's did-you-mean points at the inert spelling

## Problem
`HxSwap` is a closed template-literal union (`src/htmx.ts:97-102`). It admits 6 spellings htmx 4 never acts on (recon 03 §2.1 rows 1-6) and rejects the spellings the pinned bundle reads. Because the union is closed, tsc's spelling suggester works against the author: a model that writes the htmx-4 docs spelling is told to change it to the dead one.

```
hx/swap-guesses.ts(4,27): error TS2820: Type '"outerHTML focusScroll:true"' is not assignable to type 'HxSwap | undefined'. Did you mean '"outerHTML focus-scroll:true"'?
hx/swap-guesses.ts(6,27): error TS2820: Type '"innerHTML transition:false"' is not assignable to type 'HxSwap | undefined'. Did you mean '"innerHTML transition:true"'?
```

Following the first suggestion compiles, lints and renders, and does nothing. Following the second inverts the intent.

## Evidence (executed)
tsc 6.0.3 on 11 spellings (`hx(assetUrl("/x"), { swap })`):

| Spelling (read by beta6 htmx.js) | tsc 8.1.0 |
|---|---|
| `focusScroll:true` (:1458) | TS2820 -> `focus-scroll:true` (inert) |
| `focusScroll:false` (:1458) | TS2820 -> `focus-scroll:false` |
| `transition:false` (:1334 `swapSpec.transition !== false`) | TS2820 -> `transition:true` (opposite) |
| `strip:true` (:1115) | TS2322, no suggestion |
| `target:#other` (:1114) | TS2322, no suggestion |
| `scroll:top scrollTarget:#list` (:1218) | TS2322, no suggestion |
| `show:top showTarget:#list` (:1228) | TS2322, no suggestion |
| `focus-scroll:true`, `show:window:top`, `scroll:window:bottom` (htmx 2) | compile clean |

A `const s: HxSwap = "outerMorph focusScroll:true"` gets the same TS2820 (line 16), so typing a helper's parameter as `HxSwap` does not help.

Runtime oracle (Playwright Chromium, markup rendered by fluent 8.1.0 itself, input focused at scrollY 0 between two 3000px spacers, swap replaces it):

| Emitted | lib beta6 winY | template 4.0.0 winY |
|---|---|---|
| `hx-swap="innerHTML focus-scroll:true"` (typed) | 0 | 0 |
| `hx-swap="innerHTML focusScroll:true"` (forced past tsc) | 2659 | 2659 |
| `hx-swap="innerHTML"` (baseline) | 0 | 0 |

The typed spelling is indistinguishable from no modifier on both bundles. The same union class ships in the template: `templates/web` uses `show:window:top` at `post-card.ts:106`, `:135` and `contact.ts:223`, while `templates/full-stack/src/core/htmx/swap-verbs.ts:268` documents that htmx 4 parses it to `show="window:top"` and ignores it. Fleet: 0 app-authored `focus-scroll`/`focusScroll` sites in the 16 canonical repos.

## Why it matters
impact 2 x pain 3 x reach 2 / S = 6. Error quality inverted: the one diagnostic that names a fix names a silent failure (pain 3: every layer passes after the "fix"). Prior alignment: the model's docs-derived guess is right and is corrected into a wrong one.

## Rough idea (not a design)
Type layer, two steps. 8.2.0 (additive): add the members the pinned bundle reads (`focusScroll:true|false`, `transition:false`, `strip:true|false`, `target:${selector}`, `scrollTarget:`, `showTarget:`) so both the value compiles and tsc's nearest match is a working member; pin with the runtime oracle (guardrail 10). 9.0.0: delete the 6 inert members with a codemod (dry run: template-web 3 sites, fluent-html-home-page demo strings). Deletes the template's explanatory comment at swap-verbs.ts:268.
