# addAttribute reserved keys: the hazard is real, the reach is zero, the fix is free

`$B3` = `<scratch>/wave1/B3`.

## Problem

Since 6.0.1 the dedicated field wins over a bag `id`/`class`/`style` (`serialize.ts:251-253`). For `class`, "the dedicated field" is set by any of 186 methods (runtime probe: 184 `Tag.prototype` methods write `class`, plus `setClasses` and `overlay`); for `style`, by `setStyle`/`setStyles`/`addStyle` and by `anchorName`/`positionAnchor`/`positionArea`/`viewTransitionName`, which write inline style. The drop compiles, lints (no rule covers `addAttribute("class"|"id")`), and is silent in dev mode.

## Evidence (executed)

`$B3/devcheck.mjs`, dist 8.1.0, `NODE_ENV=development` (dev checks on) and `production`:

```
Div("x").p("4").addAttribute("class", "mt-7")               -> <div class="p-4">x</div>
Div("x").setId(ids.menu).addAttribute("id", "other")        -> <div id="menu">x</div>
Div("x").setStyle("color:red").addAttribute("style", ...)    -> <div style="color:red">x</div>
Div("x").anchorName(ids.menu).addAttribute("style", ...)    -> <div style="anchor-name: --menu">x</div>
warnings: 0 (both modes)
```

Reach (TS AST over the dedup corpus, 58 repos): 3,969 `addAttribute` sites. In 7.x/8.x repos: 45 sites, 0 with a reserved key (top keys: `hx-headers:inherited` 16, `preserveAspectRatio` 15, `pointer-events` 10). Pre-7: 126 reserved-key sites in 21 repos (`style` 109, `id` 17, `class` 0). Same-chain collision with a setter or styling method: 0 of 126 (4 chains contain `apply`/`when`, which could add a class indirectly). Pure prior (recon 02 pp1/pp2): 0 reserved-key `addAttribute` calls in 2/2 runs; it reaches for `addClass` instead.

## Why it matters

impact 2, pain 2 (a dropped class or id is invisible until the layout or a swap target breaks), reach 1 (no live victim found). The value of this finding is the price: L-066 was parked as breaking, and the break measures 0 canonical-era edits. A type-level exclude closes the decision space (one way to set id/class/style) for free in the 9.0.0 bundle.

## Rough idea (not a design)

Type layer in 9.0.0: `addAttribute<K extends string>(key: K extends "id" | "class" | "style" ? never : K, value: string)` or a message-carrying hint pointing at `setId`/`cssClass`/`setStyle`; codemod dry run from this census: 0 canonical-era edits, 126 pre-7 rewrites (`addAttribute("style", v)` -> `.setStyle(v)`, `addAttribute("id", v)` -> `.setId(v)`). Meanwhile (8.1.x, no byte change): a dev warning in `buildAttrs` when a bag key is shadowed.
