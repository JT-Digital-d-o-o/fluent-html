# The remaining raw-string route sinks, priced

`$B3` = `<scratch>/wave1/B3`.

## Problem

Four navigation sinks still accept `string`: `FormTag.setAction` (`forms.ts:373`), `ButtonTag.setFormaction` (`:317`), `AreaTag.setHref` (`links.ts:118`), `UseTag.setHref` (`svg.ts:519`, absent from the CHANGELOG's out-of-mandate list). Two reasons parked them: "forms route through the swap verbs, which stamp the action" (false, F-B-301) and "zero `<area>` call sites" (still true, which makes the brand free).

## Evidence (executed)

- Surface walk (TS checker over `dist/src/index.d.ts` + `./elements`): 248 public parameters admit a bare `string`. Of the URL-valued ones on navigation elements, only `AnchorTag.setHref` is branded; `LinkTag`/`BaseTag.setHref` are head machinery (L-081).
- tsc + eslint (template config) on `v12-form-sinks.ts`: `Form().setAction("/team/invit")` (typo), `Button().setFormaction("/team/invit")`, `MapEl(Area().setHref("/team/x"))`: 0 errors, 0 lint findings. Render: `<form action="/team/invit" method="post">`, `<button formaction="/team/invit">`, `<area href="/team/x">`. The scheme filter does work (`setAction("javascript:alert(1)")` -> `action="about:blank"`), so the gap is route typing, not XSS.
- Census (dedup corpus): `setAction` 70 sites in 26 repos. 8.x: 13 sites in 9 repos: 10 `routes.x.resolve()`, 2 `route.endpoint` (`gzs/stem-50/src/shared/ui/search.ts:58`, `na-cent/.../analytics.components.ts:624`, already `ResolvedRoute | ExternalHref`), 1 `upload.url` typed `string` (`fl-um/src/app/videos/views/videos.list.view.ts:136`, an S3 presigned policy URL: `externalUrl()`). Pre-7: 57 sites, 11 raw literal paths (e.g. `jt-vault/src/vault/goals/goals.view.ts:407` `"/goals"`), 8 template literals, 4 identifiers. `setFormaction`, `Area(...).setHref`, `Use(...).setHref`: 0 sites.
- Pure prior (recon 02, pp2): 2x `addAttribute("action", ...)`, the untyped path that also skips `sanitizeUrl` (L-069).

## Why it matters

impact 2, pain 2 (a typo'd or stale action fails only on a native submit, the path F-B-301 shows nobody tests), reach 2 (13 live 8.x sites; F-B-301 would add one per verb form if the verbs start stamping). Decision-closure: the brand is the one contract for "a URL the app navigates to" and today it holds on 1 of 5 navigation sinks.

## Rough idea (not a design)

Type layer: `setAction`/`setFormaction`/`AreaTag.setHref`/`UseTag.setHref` take `ResolvedRoute | ExternalHref` (UseTag also `#${string}`, already in `ExternalHref`). Codemod dry run from this census: 8.x 1 edit (wrap in `externalUrl`), pre-7 23 non-branded sites. Deletes the CHANGELOG out-of-mandate caveat and any guideline line that explains it.
