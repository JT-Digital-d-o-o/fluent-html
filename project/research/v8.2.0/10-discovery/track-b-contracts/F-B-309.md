# A bare token means an id in Partial and a tag name in hx()

`$B3` = `<scratch>/wave1/B3`.

## Problem

8.0.0 gave `Partial` a convenience: a bare token like `team-list` becomes `#team-list` (`patterns.ts:89-93`). The `hx()` option bag, the raw `HTMX` bag, status bags and `retarget` pass the same string through `resolveSelector` verbatim (`htmx.ts:387-390`), where htmx reads it as a tag selector. `HxTarget` is plain `string` (L-063), so both compile.

## Evidence (executed)

Chromium, lib `4.0.0-beta6` and template `4.0.0` (`browser-b3.json` S5):

- `Div(Button("Load").setHtmx(hx(assetUrl("/list"), { target: "team-list", swap: "outerHTML" })), Ul(Li("old")).setId(ids.teamList))`, response `<ul id="team-list"><li>NEW</li></ul>`. Emitted `hx-target="team-list"`. After the click: console `warning: htmx: 'team-list' on hx-target did not match any element`; the button is gone (replaced by the response, htmx falls back to the triggering element); `document.querySelectorAll("[id=team-list]").length` = 2 (`NEW`, `old`). The intended list is unchanged. Same on both bundles.
- `Partial("team-list", Ul(Li("NEW")).setId(ids.teamList))` from the same page: emits `hx-target="#team-list"`, the list becomes `NEW`, 0 console lines.

Fleet (TS AST, dedup corpus, `bag.target` literal shapes): 52 bare-token literals, all pre-7, all `target: "main"` in `gzs/inovacije` (e.g. `src/views/admin/admin-evaluation.view.ts:97`), which works only because its layout renders `Main(content).setId("main")` (`layout.view.ts:95`), so the tag and the id coincide. 8.x: 0 bare-token literals (59 identifiers, 20 `.selector`, 17 keywords).

## Why it matters

impact 2 (a mistyped or `#`-less target eats the control that fired it and duplicates an id, which later swaps and `getElementById` resolve to the wrong node), pain 2 (one console warning, no error), reach 1 (0 live 8.x sites). Decision-closure: the library teaches two normalizations for the same string.

## Rough idea (not a design)

One rule for a bare token in every selector sink, decided with L-063: either the `hx()`/status/retarget paths apply Partial's `#` convenience (runtime, bytes change only for a selector that matched nothing on a normal page), or the type rejects a bare-token literal and names `ids.x` (type, closes the `string` arm L-063 is gated on). Filed decision-gated because the second option is L-063's open decision.
