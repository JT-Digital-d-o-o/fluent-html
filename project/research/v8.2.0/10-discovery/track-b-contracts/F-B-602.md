# The round-1 tombstone prototypes fix 17 of 573 misdirecting did-you-means and turn 358 correct ones into detours

## Problem
TS2551's did-you-mean is the self-heal path a single-pass agent follows. Over A4's exhaustive guess matrix it points 573 times at a member that cannot take the value, although the right target exists. The two tombstone prototypes filed in round 1 ([[F-B-203]], [[F-B-204]]) were measured only on their own slots. Joined with the full matrix they fix almost none of the misdirections and degrade correct suggestions.

Misdirect families on 8.1.0 (2,041 TS2551 rows whose correct target is a setter, `.toggle()` or `.setAria()`; A4's overflow counted 299 by its own styling-target rule, this join classifies by correct target):

| family | rows | classes | following the suggestion |
|---|---|---|---|
| `setAriaHidden` / `setAriahidden` -> `setHidden` | 252 | 63 | `Argument of type 'true' is not assignable to parameter of type '"until-found"'.` |
| `ariaDisabled` -> `disabled` (variant) | 126 | 63 | `TS2559 Type 'true' has no properties in common with type 'VariantStyleObject'.` |
| `inert` -> `invert` | 107 | 63 | 44 compile into a CSS filter ([[F-A-401]]) |
| other `setAria*` -> another setter | 46 | 9 | 31 compile ([[F-A-406]]) |
| boolean set-forms (`setDisabled`, `setChecked`, `setItemscope`, `selected`) | 24 | 9 | fail |
| unprefixed setters (F-B-204's slots) | 18 | 8 | 8 compile (colspan/rowspan) |

- **F-B-204 regresses 343 rows** across 24 DOM-property spellings. `contentEditable` was `Did you mean 'setContenteditable'?` and becomes `Did you mean 'contenteditable'?`, a tombstone, so the heal takes 2 compile rounds (spellCheck 88, contentEditable 88, autoCapitalize 44, enterKeyHint 44, strokeDashArray/Offset/LineCap/LineJoin 10 each, crossorigin, maxLength, ...).
- **F-B-203 misnames 15 rows.** `strokeWidth` on SVG shapes now reads `strokeWidth() was renamed in 7.0.0: use .stroke(...)`, losing the `setStrokeWidth` the base suggestion named.
- **The two cannot ship together as written.** Lib d.ts with both, skipLibCheck false: 4 TS2430 + 4 TS2415 (strokeWidth, fontWeight on SvgTag, SvgShapeTag, SvgTextTag, TspanTag). Each set alone: 0.
- **g5** = both, plus:

  - an `inert` tombstone naming `.toggle('inert')`;
  - 92 per-guess tombstones (4 Tag-level, 88 per class) with class-agnostic messages;
  - dual-successor messages for strokeWidth/fontWeight/fontFamily;

- **g5 results.**

  - 420 of the 421 rows with no known target are unchanged.

## Why it matters
impact 2 x pain 2 x reach 1 / M = 2. Reach is 1 because the matrix is an enumeration: the pure prior writes aria through `addAttribute` (10 aria-* calls in 2 runs, 0 `setAria*` guesses). The value is design input. Built as filed, the round-1 tombstone RFCs would lengthen the did-you-mean path on 358 rows and fail the lib's own type check.

## Rough idea (not a design)
One generator for all type-only tombstones: removed names, unprefixed setters, DOM-property spellings and boolean set-forms, plus a single aria pattern index signature. Declare each name once with one message (naming both successors where a Tag method and an SVG setter share it), and mark them `@deprecated` so the 121 extra completions sort last. Every generator change is measured against the full A4 matrix, not only its own slots.
