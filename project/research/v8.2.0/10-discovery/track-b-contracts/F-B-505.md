# Open unions without a stated reason, and open tails no test holds open

## Problem
Guardrail 4: closed unions "unless deliberately open (documented)". Of the 14 open unions the shipped types
contain, 4 state no reason anywhere a consumer or maintainer would look, so nobody can tell a deliberate tail
from a leftover. Separately, a deliberate tail is itself a contract (vendor rel tokens, custom roles, trigger
filters); 8 of 14 have no test showing a custom value compiles, so closing them by accident is also invisible.

## Evidence (executed)
`$B5 = <scratch>/wave1/B5`

| open union | setter (fleet / dedup canonical sites) | reason stated | tests that break when the tail is removed |
|---|---|---|---|
| HxSync | `hx` / route option `sync` | none (JSDoc lists forms only) | 1 (htmx.test.ts:98) -> F-B-503 |
| BrowsingContext | `setTarget` 199 / 72 | none (REFERENCE:660 names it, no reason) | 1 (type-safety.ts:143) |
| LinkRel (anchor) | `setRel` 685 / 187 | none | 3 |
| HttpEquiv | `setHttpEquiv` 1 / 0 | none; not exported from any entry | 0 |
| AutocompleteHint | `setAutocomplete` 103 / 84 | CHANGELOG:466 | 1 (type-safety.ts:53) |
| PermissionsPolicyDirective | `setAllow` 6 / 1 | REFERENCE:689; src `//` comment stripped from d.ts | 0 |
| LinkElementRel | `Link().setRel` | JSDoc + REFERENCE:642 | 2 |
| LinkAs, LinkType, ScriptType, MetaName | `setAs` 32, `setType`, `setName` | JSDoc + REFERENCE:642 | 0 each |
| Charset | `setCharset` 182 / 34 | JSDoc + REFERENCE:642 | 1 |
| HxTrigger | route option `trigger` | JSDoc ("click[ctrlKey]", "click, keyup") | 0 |
| AriaRole | `setRole` 138 / 82 | JSDoc (custom roles) | 0 |

"Reason stated" = the d.ts JSDoc (`$B5/enum.mjs`), or a hit for the name with a reason in README, REFERENCE,
FLUENT-STYLING or CHANGELOG. `$B5/close-open.mjs` removes the `(string & {})` member per alias in a scratch copy
and counts new errors in test files: 0 for HxTrigger, HttpEquiv, PermissionsPolicyDirective, LinkAs, LinkType,
ScriptType, MetaName, AriaRole. `HttpEquiv`: `grep HttpEquiv src/index.ts src/elements/index.ts` -> 0; the
enumeration's entry-point export map lists it under none of the 11 `package.json` exports.

## Why it matters
reach 2 (`setRel` 685 and `setTarget` 199 fleet sites sit on undocumented tails), impact 1, pain 1: the cost
is decision time (is this tail deliberate? may I close it?) and silent regressions of deliberate tails.
Dims: decision-closure, invariant-safety.

## Rough idea (not a design)
CI/test layer: a small type test enumerating `(string & {})` aliases (the enumeration script already does it)
that fails unless each has a REFERENCE line and an accept-a-custom-value line in `type-surface.test-d.ts`.
Rationale stays in docs, not JSDoc (S-24). Export `HttpEquiv` or inline it.
