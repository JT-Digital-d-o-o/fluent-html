# The route brand rejects the right things and explains none of them

`$B3` = `<scratch>/wave1/B3`.

## Problem

The 8.0.0 brand has exactly three sanctioned producers for a string URL: `routes.x.resolve()` (or a route callable), `assetUrl()`, `externalUrl()`. The error a raw string gets is `Argument of type '"/team"' is not assignable to parameter of type 'ResolvedRoute | ExternalHref | undefined'.` (1 line, 109 chars, recon 02 probe #10). None of the three names appears; the CHANGELOG itself says "hover on the type names the three fixes", which a single-pass agent reading tsc output does not do. The lib's own test locks this text in: `test/brand-errors.test.ts:59` and `:64` assert `/not assignable to parameter of type 'ResolvedRoute/`.

## Evidence (executed)

- `node --test dist/test/brand-errors.test.js`: 7/7 pass; the pins above are the only message assertions, neither requires a fix to be named.
- Pure prior (recon 02): `hx("/team/members", ...)` in 2/2 runs (2 sites each), first layer tsc TS2345 with no fix named.
- Prototype (`$B3/hint/hint3.ts`, `tsc --strict --pretty false`), parameter typed `({ readonly ["route paths come from routes.x.resolve(); static files from assetUrl(); runtime externals from externalUrl()"]?: never } & (ResolvedRoute | ExternalHref))`:
  - `setHref("/team")` -> `TS2345 Argument of type '"/team"' is not assignable to parameter of type '({ readonly "route paths come from routes.x.resolve(); static files from assetUrl(); runtime externals from externalUrl()"?: undefined; } & (ResolvedRoute | ExternalHref)) | undefined'.` The fix starts at char 94 of 281.
  - `setHref(s)` with `s: string`: same, fix in line 1.
  - Compile clean: a `ResolvedRoute`, a `ResolvedRoute | ExternalHref` union variable, `"https://x.com"`, `"#top"`, a `` `https://${string}` `` value, `undefined`. Written as a named alias the hint disappears from the message (tsc prints the alias name), so it has to be inline in the declaration.

## Why it matters

impact 2, pain 2 (the agent knows the string is wrong but not which of three constructors to use; `assetUrl` vs `externalUrl` is not guessable), reach 3 (the raw-route reflex appears in 2/2 pure-prior runs and every brand sink shares the message). Error-quality is the scorecard dimension; this is the same device the template already uses for its render-stance error.

## Rough idea (not a design)

Type layer: every brand sink (`hx`, `setHtmx` endpoint overload, `hxGet`/`hxPost`, `AnchorTag.setHref`, `HTMX.endpoint`, plus the F-B-303/F-B-304 sinks when branded) declares the inline hint intersection; accepted set unchanged, so no break. Re-pin `brand-errors.test.ts` to require `resolve()`, `assetUrl()` and `externalUrl()` in the first line. Lets the guideline paragraphs that enumerate the three escapes be deleted.
