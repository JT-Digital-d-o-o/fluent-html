# Pruned names die anonymously, and 8 of them self-heal into a different utility

## Problem
The seed's second half ("pruned methods die as anonymous TS2339"), swept over all 38 names 8.0.0 removed. None of the diagnostics names what replaced the method (`.cssProp(...)`, or `setHtmx(hx(url, { method }))` for the htmx shorthands). Worse, 8 names are within tsc's spelling window of a live method with a different job, so the one suggestion given leads to code that compiles and renders the wrong CSS:

```
pr/pruned.ts(...): error TS2551: Property 'rotateX' does not exist on type 'Tag'. Did you mean 'rotate'?
```

`Div().rotate("45")` renders `<div class="rotate-45"></div>` (2D rotation, z axis), not an x-axis rotation.

## Evidence (executed)
`tsc --strict --pretty false` on one call per pruned name (hx* on `Button`, the rest on `Div`), dist 8.1.0:

| Result | Count | Names |
|---|---|---|
| TS2339, no suggestion (79-105 chars) | 30 | hxPut, hxPatch, hxDelete, 7 backdrop*, mask, maskFrom, maskTo, maskType, perspectiveOrigin, backface, snap, snapAlign, snapStop, placeContent, placeItems, placeSelf, breakBefore, breakAfter, isolation, hyphens, scheme, fieldSizing, skewX, skewY |
| TS2551 to a live method with a different job | 8 | rotateX/rotateY/rotateZ -> rotate; scaleX/scaleY/scaleZ/scale3d -> scale; scrollM -> scroll |

Rendered after following the suggestion: `Div().rotate("45")` -> `class="rotate-45"`; `Div().scale("150")` -> `class="scale-150"` (uniform, not one axis); `Div().scroll("smooth")` -> `class="scroll-smooth"` (scroll-behavior, not scroll-margin). Same shape as the `.colspan` -> `colSpan` hazard (A4).

Prototype: a `FluentCustomMethods` augmentation with `rotateX(removed: Removed<"rotateX was removed in 8.0.0: write .cssProp(...)">): never` (and placeItems, hxDelete) turns the three calls into one-line errors naming the successor, e.g. `error TS2345: Argument of type 'string' is not assignable to parameter of type 'Removed<"placeItems was removed in 8.0.0: write .cssProp(\"place-items\", \"center\")">'.`

Reach: 0 fleet call sites (the names do not compile), and recon 02's pure-prior runs produced 0 nonexistent methods, so the exposure is agents recalling pre-8 or Tailwind-shaped names (recon 02 probes #3, #4).

## Why it matters
impact 2 x pain 2 x reach 1 / S = 4. Error quality: 0/38 name a fix; 8/38 name a wrong one that passes every later layer (tsc, lint, extractor, Tailwind).

## Rough idea (not a design)
Type layer: tombstone members whose only parameter type is the redirect message (zero runtime, `@deprecated` so editors strike them through), or a lint rule `no-removed-method` with the same messages if the added members cost too much. Tombstones add 38 members to every `this` instantiation, so measure against the F-B-404 budget before choosing the layer. Converge check (guardrail 7): a tombstone adds no second way, it only redirects.
