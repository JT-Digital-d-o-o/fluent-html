# A path string handed to any swap verb names no fix at compile time and renders hx-undefined at runtime

($B1 = <scratch>/wave1/B1)

## Problem

`A("Team").nav("/team")`, the guess the 2026-08-14 scorecard recorded, still fails with a message that names
neither a route callable nor `defineRoutes`:

```
error TS2345: Argument of type 'string' is not assignable to parameter of type 'PageRoute'.
  Type 'string' is not assignable to type 'HTMX'.
```

The same shape holds for all 8 verbs. When the error is skipped (no tsc in the loop, a cast, a JS file), the
verb spreads the string into its bag (`{ ...withInvalidTarget(busyWhileRequesting(this, route)) }`,
swap-verbs.ts:260-262), so the bag carries keys `0`..`4` and no `method`/`endpoint`. `Tag._setHx`
(tag.ts:638-642) stores it unchecked, and `buildHtmx` (serialize.ts:140) concatenates `'hx-' + htmx.method`:

```html
<a class="cursor-pointer" role="button" tabindex="0" hx-undefined="undefined" hx-target="#main-content" hx-swap="outerMorph show:top" hx-push-url="true" hx-indicator="#global-loading">Team</a>
```

No `hx-get`: the link is inert in every htmx bundle, with no dev warning.

## Evidence (executed)

1. **tsc, one fixture per verb** (`$B1/app/run-probe.sh`, TypeScript 6.0.3 in the Wave-0 scaffold):

   | Verb call | Lines | Chars (incl. path) | Names a fix |
   |---|---|---|---|
   | `.nav("/team")` | 2 | 141 (from `error`) | no |
   | `.submit("/team")`, `.tab`, `.search`, `.onChange` | 2 | 180 each | no |
   | `.fragment(ids.teamList, "/team/list")` | 2 | 279 | no |
   | `.poll("/team/list")` | 2 | 274 | no |
   | `.fire("/team/hook")` | 1 | 126 | no |

   0/8 mention a route callable, `defineRoutes`, or `routes.x()`.
2. **Runtime** (`node $B1/rt/render.mjs $B1`, lib dist 8.1.0 + template verbs bundled with esbuild): `A.nav`,
   `Button.nav`, `Button.submit`, `Input.fragment(id, "/team")` and a bare `setHtmx({})` all emit
   `hx-undefined="undefined"` and no verb attribute, 5/5 under `NODE_ENV=development` and 5/5 under `production`.
3. **Fix-naming prototype** (`$B1/proto-verbs`, template copy): `nav<R extends PageRoute | string>(route: R extends string ? RawPath<".nav"> : R, …)`.
   The first diagnostic becomes one line naming the fix:
   `Argument of type '"/team"' is not assignable to parameter of type '".nav takes a route callable result, e.g. .nav(teamRoutes.index()); a path string has no method and renders hx-undefined"'.`
   Full template tsc: exit 0 over 164 src files (plus tests) with 42 `.nav(` lines; the route-union rejection
   (q08) still fires. The fragment verbs already prove the seam can carry a sentence: their `DeclaresNothing`
   key puts the fix at char 225 (recon 02, probe 29).
4. **Lib dev-check prototype** (`$B1/libcopy`, scratch copy built with `npx tsc -p tsconfig.json`): a throw in
   `_setHx` when `method`/`endpoint` is not a string. `node --test` over the 36 files in `scripts.test`:
   **2159/2159 pass**. Re-bundled verbs: `.nav("/team")` -> `TypeError: setHtmx: the HTMX bag has no
   method/endpoint (keys: 0, 1, 2, 3, 4, target); pass a route callable result such as teamRoutes.index(), not a
   path string`; `.nav(routes.index())` renders unchanged.
5. **Reach**: 0/4 in-repo phase-2 features (blind1/2, guided1/2) put a path into a verb (feature.patch grep);
   the 2026-08-14 guided run did (scorecard.md:131). Fleet sites: 0 by construction (tsc blocks them).

## Why it matters

impact 2 (tsc catches it; the runtime artefact is silent when tsc is not run) x pain 3 (seed marked "did not
move" on two scorecards; the message sends the agent to the `HTMX` type, not to the routes file) x reach 2.
Hurts error-quality and silent-failure resistance.

## Rough idea (not a design)

Type layer, template-owned: a conditional parameter per verb that maps a string to a string-literal error type
naming `routes.x()`. Dev-throw layer, lib-owned: `_setHx` rejects a bag with no `method`/`endpoint` (covers
every verb, `setHtmx`, and any future template seam). No guideline line is deleted by this alone.
