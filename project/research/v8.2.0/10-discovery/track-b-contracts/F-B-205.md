# setAction, setFormaction and AreaTag.setHref accept raw paths; the stated exemption does not hold

## Problem

8.0.0 branded the route sinks but left three out of mandate (CHANGELOG.md:133): `FormTag.setAction` and `ButtonTag.setFormaction` because "forms route through the swap verbs, which stamp the action from a route callable", and `AreaTag.setHref` because the fleet had no `<area>`. Recon 02 #7-9: `Form().setAction("/team/invite")`, `Button().setFormaction(...)`, `Area().setHref("/team")` pass tsc, eslint, the extractor and the dev runtime.

The premise is false in the render: the verbs stamp `hx-post`, never `action`:

```
Form(Button("Invite").setType("submit")).submit(teamRoutes.invite())
-> <form hx-post="/team/invite" hx-target="#main-content" hx-swap="outerMorph" hx-indicator="#global-loading" hx-disable="findAll button"><button type="submit">Invite</button></form>
```

So a form that wants a no-JS action reaches for `setAction`, and there the route contract ends. The lint layer pushes agents there: pure-prior run pp2 wrote `addAttribute("action", "/team")` twice, and `prefer-set-method` answered, verbatim, `Use .setAction("/team") instead of .addAttribute("action", "/team"). Dedicated methods provide type safety and autocomplete.` Its autofix applies it: a raw path moves from the escape hatch into a typed-looking sink that checks nothing.

Sanitization is not the gap: `Form().setAction("javascript:alert(1)")` renders `action="about:blank"`. The gap is route drift (a renamed path keeps compiling) and a missing redirect for the agent.

## Why it matters

impact 2 x pain 2 x reach 2 / effort S. Invariant safety: a route rename is caught at every anchor and hx call but not at the form that posts to it. Decision closure: two layers disagree (types say brand, lint autofix writes raw).

## Rough idea (not a design)

9.0.0, codemod-first: brand the three sinks; codemod wraps non-route runtime strings in `externalUrl()` (measured: 1 site in the canonical fleet). Lint lockstep: `prefer-set-method` stops autofixing `action`/`formaction`/`href`. Deletes the CHANGELOG exemption paragraph.
