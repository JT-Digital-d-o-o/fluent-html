# A typo'd token to a typed styling method never gets did-you-mean; the same typo in a variant object does

## Problem

The closed unions (S-04) make a typo a compile error, but TypeScript only offers `Did you mean '...'?` (TS2820) inside a nested relation. For a top-level argument the head message `Argument of type ... is not assignable to parameter of type ...` is set, and reportRelationError skips the suggestion (typescript.js:69729-69740). Every one of the 159 vocab methods takes its token as a top-level argument, so none of them can self-heal; the variant-object path (`.hover({ bg })`) can.

## Evidence (executed)

`$B2 = <scratch>/wave1/B2`. Probes against the scaffold's theme (palette off, role tokens on):

```
t.ts(3,40): error TS2345: Argument of type '"centre"' is not assignable to parameter of type 'TailwindJustifyContent'.
t.ts(6,34): error TS2345: Argument of type '"semi-bold"' is not assignable to parameter of type '"brand" | `[${string}]` | "black" | "thin" | ... | "semibold" | ...'.
t.ts(8,28): error TS2345: Argument of type '"surfce"' is not assignable to parameter of type 'TailwindColor'.
t.ts(10,33): error TS2820: Type '"surfce"' is not assignable to type 'TailwindColor | undefined'. Did you mean '"surface"'?
```

(line 10 is `Div().hover({ bg: "surfce" })`). `.text("centre")` and `.shadow("medium")` print a 300+ char inline union because merged-prefix params are not aliased.

Typed-lint prototype (checker contextual type of the literal, literal members of the union, `ts.getSpellingSuggestion`):

```
t.ts:3 .justify("centre"): did you mean "center"?  [6 literal members]
t.ts:4 .items("centre"): did you mean "center"?  [5 literal members]
t.ts:5 .text("centre"): did you mean "center"?  [56 literal members]
t.ts:6 .font("semi-bold"): did you mean "semibold"?  [13 literal members]
t.ts:7 .rounded("crad"): (no candidate within TS's spelling window)  [26 literal members]
t.ts:8 .bg("surfce"): did you mean "surface"?  [26 literal members]
t.ts:9 .shadow("medium"): (no candidate within TS's spelling window)  [35 literal members]
```

5/7 get the intended token; tsc gets 0/7 on the method path. A type-level workaround (single-element rest tuple) was tried and changes nothing.

## Why it matters

impact 2 x pain 2 x reach 3 / effort M. Reach: every literal to a typed styling method (`.text()` alone has 12,984 app-authored canonical-era sites, recon 01). Pain 2: `centre -> center` self-heals from the union, but `.bg("surfce")` names only the alias `TailwindColor`, whose members live in the app's theme file.

## Rough idea (not a design)

Lint layer (the strongest that reaches this path): a typed rule in the eslint plugin, which already runs typed rules (`match-subset-default`), reporting the nearest member with TypeScript's own heuristic. No prose to add or delete; it closes the gap between the method path and the variant-object path.
