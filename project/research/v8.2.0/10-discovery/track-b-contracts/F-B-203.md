# 94 removed or renamed method names die as anonymous TS2339 while the house's own exemplars still teach them

## Problem

7.0.0 renamed 49 methods and removed `.on/.at/.display/.position/.bold/.outlineHidden`; 8.0.0 pruned 38 more. Every one of them now fails as `Property 'X' does not exist on type 'Tag'` with no successor, although the successor is machine-known: the codemod carries the map (canonical-names.ts:49-99) and the coverage watch carries the prune reasons.

The guesses are not hypothetical. The house teaches them:
- `guidelines/web-development/views.md:84` shows `Div(...children).flex().alignItems("center")` as the correct form.
- The template's `src/shared/stylers.ts:21-22` JSDoc shows `t.background("success/10").textColor("success")`. It is vendored into every template-derived app: the census scan finds it in 16 files across 15 canonical-era repos. Blind agents learn from src (recon 02: 94/96 src accesses).
- `templates/web/CLAUDE.md` teaches `.padding/.margin/.background/.textColor/.textSize/.fontWeight` under "DO: Use chainable fluent methods" (10 lines), and its README 13 more.
- The naming rule itself (S-09, method name = Tailwind class prefix) derives the 38 pruned names: `place-items-center` -> `.placeItems("center")`.

Design constraints the prototype measured:
- Returning `this` from a method whose `this` is the message literal breaks the chain (`Property 'gap' does not exist on type 'FluentCustomMethods'`); `never` cascades (`'gap' does not exist on type 'never'`). `any` reproduces TS2339's no-cascade behaviour.
- 3 rename sources are also bare SVG setter names (`fontWeight`, `fontFamily` on SvgTextTag/TspanTag; `strokeWidth` on SvgShapeTag/SvgTag). A second, per-class tombstone with a different message makes the subclass unassignable to `Tag` (`Argument of type 'CircleTag' is not assignable to parameter of type 'Tag'`; the template's src/shared/ui/button.ts:41 fails). One message per name, naming both successors.
- The diagnostic column moves from the property to the receiver start (p03: col 41 -> 24).

## Rough idea (not a design)

Type layer, generated (one source, like the vocab): tombstones from the codemod maps + the coverage watch's pruned rows, in a separate d.ts; hierarchy-invariant messages. It is not an alias or shim (L-389): nothing removed becomes callable. Same change deletes the stale lines: views.md:84, the two stylers.ts/context.ts JSDoc blocks, templates/web CLAUDE.md/README pre-7 blocks.
