# All 8 template swap verbs reject a raw URL as 'string is not assignable to HTMX' and never name the route callable

## Problem

The pure-prior guess for a swap verb is a URL: `A("Team").nav("/team")`. On 8.1.0 every verb rejects it, but the diagnostic names the type the verb wants (`PageRoute`, then `HTMX`), not the thing to write (a route callable from `defineRoutes`). The same shape hits all 8 verbs the template registers (`nav tab submit search onChange fragment poll fire`).

If the error is bypassed (a cast, a JS caller, an `any`), the verb spreads the string into the HTMX bag and the lib serializer emits `hx-` + `undefined`:

```
<a class="cursor-pointer" role="button" tabindex="0" hx-undefined="undefined" hx-target="#main-content" hx-swap="outerMorph show:top" hx-push-url="true" hx-indicator="#global-loading">Team</a>
<form hx-undefined="undefined" hx-target="#main-content" hx-swap="outerMorph" hx-indicator="#global-loading" hx-disable="findAll button"></form>
```

Measured cost: for a route-typed argument with the wrong stance the message member now also appears on line 1. p29 (undeclared stance into `.fragment`) keeps its `DeclaresNothing` text but it moves from line 2 to line 3; n6 (fragment route into `.nav`) gains the member on line 1 and keeps its 4-line elaboration. A generic conditional variant (`nav<R extends PageRoute | string>(route: R extends string ? MSG : R)`) prints only the message for strings but also adds it to n6. The unsatisfiable member `{ readonly "<message>": never }` prints the same way and accepts no new value (tested on the lib sink in F-B-206).

## Why it matters

impact 2 x pain 3 x reach 2 / effort S. Error quality is the only layer a single-pass agent reaches (recon 02: 4/4 in-repo agents ran tsc, 0/4 booted the app), so an error that names the wrong object (HTMX) costs a round of reading d.ts. The runtime half (`hx-undefined`) is silent on every layer.

## Rough idea (not a design)

Type layer: one message member per verb parameter (template-owned, additive widening), ASCII-only text. Runtime backstop: a dev throw in the verbs (or in `buildHtmx` when `method`/`endpoint` is undefined, which is Track A's layer). Deletes the need for any prose saying "verbs take route callables, never URLs" (guidelines CLAUDE.md swap-verb bullets).
