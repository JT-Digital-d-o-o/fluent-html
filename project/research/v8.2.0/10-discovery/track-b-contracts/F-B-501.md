# Most closed unions in the shipped types are not pinned closed

## Problem
Guardrail 4 makes closed unions the default, and `type-surface.test-d.ts:1-5` states the mechanism: "A
`@ts-expect-error` whose line stops erroring (e.g. a closed union gets widened …) … FAILS the build." The
mechanism only protects unions that have such a line. Measured over the whole shipped surface, 65% have none:
widening them to accept any string leaves `tsc`, the probe harnesses and all 155 directives green.

## Evidence (executed)
`$B5 = <scratch>/wave1/B5`

1. Enumeration (TS compiler API over the 11 `package.json` export entry points): 199 type aliases with
   literal members in `dist/src/**/*.d.ts`, `QueryParamValue` excluded as a value type -> 198: 184 closed
   (74 of them carry a bounded template arm such as `[${string}]`), 14 open, all through a `(string & {})` tail.
   102 of the 184 are nameable from an entry point. Plus 52 inline literal unions in public signatures
   (`setDecoding`, `setWrap`, `setPreload`, SVG text setters, `AriaAttrs.*`, behavior options, side args).
2. Mutation, per union, in a scratch copy of `src/` (in-process tsc with program reuse; root project +
   color-optout + setter-probe + brand-probe): widen -> any TS2578 = reject pin; `never` -> any new error =
   accept pin.

   `TailwindEase`, `TailwindResize`, `ImgTag.setDecoding`, `FormTag.setAutocomplete`, the SVG text
   `setFontWeight/FontStyle/TextDecoration` setters.

## Why it matters
reach 3 (47 methods, 33,640 fleet sites), impact 2, pain 2: a widening refactor, a generator change in
`gen:vocab`, or an accidental `| string` turns typo rejection into dead classes or dead attributes with no
red test. Recon 02 measured that types plus exemplars carry all of blind-agent correctness (13 -> 0 tsc
errors), so closure is the load-bearing contract. Dims: invariant-safety, verification-loop, decision-closure.

## Rough idea (not a design)
CI/test layer, no public-shape change: generate `test/types/closed-unions.gen.test-d.ts` from the vocab rows
(Tailwind unions) and the element-setter unions (one valid member + one near-miss each, both directions),
checked by `gen:vocab --check`; run `$B5/mutate.mjs` (or a trimmed version) in CI to fail any closed union
without a reject pin. Ranking the backfill by the reach column above covers 8,901 + 6,786 + 4,574 sites with
the first three lines.
