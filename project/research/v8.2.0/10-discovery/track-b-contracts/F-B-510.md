# Raw-string URL sinks carry no stated reason and no pin

## Problem
8.0.0 branded the route-bearing sinks and declared the rest "out of mandate" in one CHANGELOG line. At the
point of use nothing says so: the six raw sinks are plain `string` in the d.ts with no comment, REFERENCE
teaches one of them with a hardcoded path, and no test fixes the stance in either direction. The brand probe's
own comment states the rule "a raw request-body string can never become a redirect/link target", which holds
for `AnchorTag.setHref` and fails for a form's `action`/`formaction`, which are navigation targets.

## Evidence (executed)
`$B5 = <scratch>/wave1/B5`

`$B5/probe/sinks.ts` passes `body.next` (a request-body string) or a route literal to all 7 URL setters:
```
sinks.ts(10,25): error TS2345: Argument of type 'string' is not assignable to parameter of type 'ResolvedRoute | ExternalHref | undefined'.
```
(line 10 = `A("x").setHref(body.next)`; lines 4-9, the other six sinks, compile). Render (`sinks.mjs`):
```
Form.setAction         <form action="/team/invite?x=1"></form>
Button.setFormaction   <button formaction="/team/invite?x=1">Go</button>
Area.setHref           <area href="/team/invite?x=1">
Link.setHref           <link href="/team/invite?x=1">
Base.setHref           <base href="/team/invite?x=1">
Use.setHref            <use href="/team/invite?x=1"></use>
```
Stated reason: the six d.ts declarations (`forms.d.ts:131,150`, `links.d.ts:51`, `svg.d.ts:148`,
`document.d.ts:65,91`) have no JSDoc; `CHANGELOG.md:133` names LinkTag/BaseTag ("head machinery"), AreaTag and
FormTag/ButtonTag; UseTag appears nowhere. Pins: `grep -c` for these setters in
`test/types/brand-probe/probe.ts` -> 0; `$B5/strip-expect.mjs` -> 0 of 155 directives. Census: `setAction` 72
fleet / 15 canonical-era / 13 dedup canonical-era, `setFormaction` 0, `setHref` 2,023 (all receivers).
Recon 02 probes #7-9 found the same three calls clean on tsc, eslint, extractor and runtime.

## Why it matters
reach 2 (13 dedup canonical `setAction` sites; the template's forms route through the swap verbs), impact 1,
pain 1. The cost is contract ambiguity: an agent cannot tell "deliberately raw" from "forgotten", and a
later brand decision would have nothing pinned to flip. Dims: invariant-safety, decision-closure.

## Rough idea (not a design)
Test layer now: six must-PASS lines in `brand-probe/probe.ts` (the harness asserts the exact diagnostic set,
so the stance becomes a pinned contract) and a REFERENCE line per sink. Whether to brand
`setAction`/`setFormaction` stays with B3 and L-075; `UseTag.setHref` joins the out-of-mandate list or the
brand.
