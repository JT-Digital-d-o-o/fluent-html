# htmx grammar unions are closed but almost entirely unpinned

## Problem
`htmx.d.ts` declares 29 literal-union aliases (27 closed, 2 open). The closed ones encode htmx's value grammar:
swap styles and modifiers, triggers, selector keywords, status keys. Only one test line rejects anything in
that grammar. The status-key union carries a security claim in its JSDoc ("Bare strings are rejected at compile
time so a malformed key cannot be concatenated into the attribute NAME (injection)"), yet no test checks the
compile-time half: the two tests that feed a bad key bypass the type with a cast and exercise only the runtime
regex.

## Evidence (executed)
`$B5 = <scratch>/wave1/B5`

`$B5/mutate.mjs` widens each alias in a scratch copy of `src/` with `| (string & {})` (reject direction: a pin
shows as TS2578) and replaces it with `never` (accept direction: a pin shows as a new error), across the root
project, color-optout, setter-probe and brand-probe. htmx.d.ts rows (rej = directives that fire on widen,
acc = errors on never):

22 of 27 closed aliases: 0 reject pins. HxStatusKey's `never` mutation is invisible because the bag is
`Partial<Record<HxStatusKey, …>>` (an empty record admits object literals), which is why a direct
`// @ts-expect-error` line is the only way to pin it. Valid keys are used at runtime (`htmx.test.ts:168-186`,
`security.test.ts:89,93`). Invalid keys: `security.test.ts:97` and `stream.test.ts:427`, both
`as unknown as Parameters<typeof hx>[1]`.

The swap-modifier members recon 03 §2.1 rows 1-6 measured as inert on both bundles (`show:window:top|bottom`,
`scroll:window:top|bottom`, `focus-scroll:true|false`) sit in the two aliases with 0 positive test uses: no
test renders them, so no test could have observed them doing nothing.

## Why it matters
reach 2 (`setHtmx`/route callables in every canonical repo; status bags via the template `{ invalid }` verb
option), impact 2 (the type-level half of an injection guard and the whole swap grammar can widen silently),
pain 2. Dims: invariant-safety, verification-loop, silent-failure.

## Rough idea (not a design)
Test layer (8.1.x): add both-direction pins per htmx union to `type-surface.test-d.ts`, including
`hx(url, { status: { "404 onload": "x" } })` under `@ts-expect-error` with no cast. Generate the valid-member
list from the same inventory the bundle oracle (Track A1) executes, so a member that htmx does not read cannot
be pinned as valid.
