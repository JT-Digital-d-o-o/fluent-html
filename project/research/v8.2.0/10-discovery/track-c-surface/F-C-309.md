# Zero-use names that duplicate a live spelling

## Problem

The C seed "108 methods at 0 call sites" (L-153) was never turned into a committed list, and the 8.0.0 prune left 92 names at zero.

A prune is cheapest, and its error most useful, where the dead name is a *second spelling* of something that lives: the removal then has an exact successor to name. This finding measures that subset. Removal remains C1's call.

## Evidence (executed)

**Fresh census.** `census-dedup.mjs --json` (the official script with `.claude/` skipped): 58 repos, 12,811 files, 259,484 sites.
- 92 method names at 0 fleet sites;
- 108 at 0 canonical-era sites.

The 92 match recon 01 by count.

**Dead halves of a live two-way.** Output compared byte for byte:

| Dead spelling | Fleet / canonical | Live twin | Twin canonical app | Output |
|---|---|---|---|---|
| `.after({…})` | 0 / 0 | `.variant("after", {…})` | `.variant` 289 | IDENTICAL `after:content-['']` |
| `.checked({…})` | 0 / 0 | `.variant("checked", {…})` | 289 | IDENTICAL `checked:bg-black` |
| `.dark({…})` | 0 / 0 | `.variant("dark", {…})` | 289 | IDENTICAL `dark:bg-black` |
| `.even({…})` | 0 / 0 | `.variant("even", {…})` | 289 | IDENTICAL `even:bg-black` |
| `.odd({…})` | 0 / 0 | `.variant("odd", {…})` | 289 | IDENTICAL `odd:bg-black` |
| `.setNonce(n)` | 0 / 0 | render-time nonce | `renderWithNonce` 61 fleet | IDENTICAL `<script nonce="n1">a</script>` |
| `.multipart()` | 2 / 0 | `.setEnctype("multipart/form-data")` | 2 (49 dedup canonical) | IDENTICAL `<form enctype="multipart/form-data">` |
| `.hxPost(e)` | 41 / 0 (AST) | `.setHtmx(route())` | 18 | IDENTICAL `<button hx-post="/team">` |
| `Repeat(n, fn)` | 1 / 0 | `ForEach(n, fn)` | 1,261 | IDENTICAL; `Repeat` is `return ForEach(times, content)` (`iteration.ts:178-183`) |
| `setHtmx(endpoint, opts)` overload | 0 / 0 | `setHtmx(hx(endpoint, opts))` | (rung 3) | IDENTICAL `hx-get="/team" hx-target="#t"` |
| `render(view, { nonce })` overload | 0 / 0 | `renderWithNonce(n, view)` | 61 fleet | IDENTICAL |
| `renderToStream(view, opts)` overload | 0 / 0 | `renderToStreamWithNonce` | 28 fleet | same `streamOf` path (`stream.ts:26`, `:34`) |

**The `.variant()` type admits every tier-1 prefix.** `tailwind-methods.ts:178` types `name` as `TailwindState | TailwindBreakpoint`, and that union contains all 21 tier-1 prefixes. So the 5 zero tier-1 methods are not needed for any output, and their generic spelling is also at 0 sites.

**Excluded after execution:** `spaceX` (0 sites) is not a byte twin of `.flex().gap("x", …)` (`space-x-4` vs `flex gap-x-4`). Its retirement rests on the guideline preference, not on equivalence.

## Why it matters

- **Scoring:** impact 2 × pain 1 × reach 2 / effort M(2) = 2.
- **Context economy:** 12 spellings that autocomplete and appear in `.d.ts` reads (blind agents read `dist/src/*.d.ts` 36-39 times per run, recon 02 §2.2) while contributing no output the twin does not.
- **Error quality:** each is a prune whose successor is proven identical, so the post-prune error can say exactly what to write.

## Rough idea (not a design)

- **One successor map** (dead spelling → twin) drives the 9.0.0 codemod: 0 canonical sites for 11 of 12, and `hxPost` sites are pre-7 only.
- **The same map drives the pruned-name diagnostic B2 is designing:** `Property 'dark' does not exist … use .variant("dark", {…})`.
- **Enforcement:** type (the name is gone) plus the named redirect.
- **Prose:** none to delete for 10 of 12. `hxPost` has 12 teaching lines (F-C-308); `Repeat` is taught at `gl/fluent-html.md:383` (recon 01 §5).
