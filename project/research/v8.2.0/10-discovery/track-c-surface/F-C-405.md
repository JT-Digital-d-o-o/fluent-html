# CHANGELOG 8.1.0 omits render none, RootedView and the rooted Partial overload, which 15 of 15 8.1.0 repos already use

$C4 = <scratch>/wave1/C4

## Problem

Commit 9d86871 ("render \"none\" stance, RootedView, rooted Partial, widened-Id gate") shipped inside 8.1.0. The 8.1.0 entry (CHANGELOG.md:5-41) predates it:

- CHANGELOG.md:33 documents `render: "page" | Id`. The code is `RenderStance = "page" | Id<string> | "none"` (src/routes.ts:121).
- `RootedView<N>` (a new root type export, src/index.ts) is not mentioned.
- The `Partial(target: Id<N>) -> Tag & Rooted<N>` overload is not mentioned.
- The widened-Id gate exists only as a test pattern (test/types/type-surface.test-d.ts, `string extends N ? "renderFragment needs a narrow Id…"`) with no src symbol, yet the commit title advertises it.

Two more labels are wrong. The entry is split across `[8.1.0]` and `[8.1.0-a]` (:43), a version that never existed in package.json (commit 3e22e25 says 8.1.0). `[Unreleased — 7.0.0]` (:230) still sits below 7.0.1 through 8.1.0.

## Evidence (executed)

- `$C4/probe/cl-changelog.ts` against dist:
  - `defineRoutes("/hooks", { stripe: { method: "post", path: "/stripe", render: "none" } })` compiles.
  - `const s: RenderStance = "none"` compiles.
  - `import { type RootedView }` resolves.
  - `const p: Rooted<"user-count"> = Partial(ids.userCount, …)` compiles (with kebab ids).
  - `Partial("#user-count", …)` is correctly not `Rooted` (the `@ts-expect-error` holds).
- `grep` of CHANGELOG.md for `RootedView|"none"|widened`: 9 hits, all older entries (lines 307-849).
- Fleet (15 repos pinned 8.1.0, `.claude`/node_modules/dist excluded):
  - `render: "none"`: 285 lines in 15 of 15 repos, 201 of them app-authored (outside core/ and tests/) in 91 files.
  - `RootedView`: 133 lines in 15 of 15 repos (5 app-authored).
  - `Rooted<`: 20 lines in 13 of 15.
- Why the CHANGELOG is the only record: `git tag` stops at v5.7.0, npm `latest` is 5.7.0, and consumers pin SHAs. Resolved: 12 at 656e812, 2 at 9d86871, 1 vendored `fluent-html-8.1.0-9d86871.tgz`, and the template on `#main`. Every 8.1.0 install includes 9d86871, so every 8.1.0 consumer has an API its release note does not describe.

## Why it matters

impact 1 x pain 2 x reach 3 / S. An agent reading the CHANGELOG to learn the 8.1 swap contract learns a two-value stance. The third value is the one 91 app files use to opt a machine endpoint out of every swap verb. `RootedView` is the annotation the RootedView JSDoc says a component should reach for. Dims: context-economy, evolvability (the upgrade path is read from here).

## Rough idea (not a design)

Layer: ci. Add the four items to `[8.1.0]` and merge `[8.1.0-a]` into it. Rename `[Unreleased — 7.0.0]` to `[7.0.0]`. Add a check in test.yml that diffs the export names of `src/index.ts` between the last release commit and HEAD, and fails if a new name is absent from the topmost CHANGELOG section. This is release-record canon, so the prose stays.
