# REFERENCE.md, linked as the full reference, teaches pre-8.0.0 raw-string routing on 52 lines that no longer compile, plus 5 removed or runtime-inert htmx options

$C4 = <scratch>/wave1/C4

## Problem

README.md:33 sends readers to REFERENCE.md as "The full long-form reference (HTMX, routes, behaviors, …)". Its HTMX chapter predates the 8.0.0 `ResolvedRoute` brand. Almost every example passes a raw string to `hx()`, `hxGet`, `hxPost`, `setHtmx` or `A().setHref()`, none of which compile on 8.x. Examples: `Button("Save").hxPost("/api/save")` (:116), `Div().setHtmx(hx("/api", { swap: "outerMorph" }))` (:373), `A("Login").setHref("/login")` (:1808).

## Evidence (executed)

Block harness, bare lib (dist 8.1.0), unknown free names declared `any`:

- 93 ts blocks. 12 are pseudo-code. 81 compile.
- 23 of the 81 have a failing unmarked line. 54 diagnostics on 52 lines in 15 blocks are `Argument of type '"/api/…"' is not assignable to parameter of type 'ResolvedRoute | ExternalHref'`. Lines: :115-117, :120, :127, :143, :290-293, :297, :301, :310-328, :338-362, :373-392, :399-448, :483, :726, :764, :824, :1499, :1808, :1822.
- REFERENCE.md:296 `setHtmx("/api/items")`: TS2769, no overload.

Htmx options that are removed or do nothing, re-checked with a resolved route (`$C4/probe/cl-ref.ts`):

| Line | Option | Result |
|---|---|---|
| :426 | `hxGet(…, { boost: true, preload: "mouseover" })` | TS2353 `'preload' does not exist in type 'Omit<HxOptions, "method">'` (deleted 7.2.0) |
| :406 | `config: { timeout: 120000, credentials: true }` | Compiles. Recon 03 row 11 (S8): `fetch` throws TypeError and 0 requests reach the server. |
| :386 | `swap: "outerMorph show:window:top"` | Compiles. Recon 03 rows 1-4 (S1): no scroll on beta6 or 4.0.0. |
| :441 | `hx("/page", { boost: true })` | Recon 03 row 14 (S14/S15): boosts 0 of 2 configurations. |
| :438 | `Video().setId("player").setHtmx(hx("/api/page", { preserve: true }))` | Recon 03 row 15: the typed path co-emits `hx-get`, so the preserved video becomes a request trigger. |

REFERENCE.md is not in the installed package (package.json:82-89 `files`, F-C-401). It reaches agents working in the lib repo and GitHub readers.

## Why it matters

impact 2 x pain 2 x reach 1 / M. It is the only long-form htmx teaching the library owns, and 15 of its blocks teach a routing style the compiler now rejects. The 8.0.0 brand made raw strings a compile error, but this doc still shows them 52 times. Dims: context-economy, verification-loop.

## Rough idea (not a design)

Layer: ci. Rewrite each raw-string example against a small `defineRoutes` declared once at the top of the chapter. Delete `preload`, `credentials: true`, `show:window:*`, `boost` and `preserve` examples until their A-track fixes land. Extend the README compiled-block test (F-C-401) to REFERENCE.md so the next brand-style change fails CI instead of silently orphaning the doc. Prose deleted: sections duplicated by README patterns 1-2.
