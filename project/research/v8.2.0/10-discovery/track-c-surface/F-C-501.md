# Compound HTML setters: lowercase attribute token vs the DOM IDL name the model writes

## Problem
Multi-word HTML attribute setters follow two casing rules. Of the 32 lowercase multi-word HTML attributes that
have a setter, 29 mirror the attribute token (`setMaxlength`, `setTabindex`, `setFormaction`, `setColspan`,
`setDatetime`, `setImagesrcset`, ...) and 3 use the DOM IDL camelCase (`setCrossOrigin`, `setFetchPriority`,
`setReferrerPolicy`). One class carries both: LinkTag has `setImagesrcset` (document.ts:221) beside
`setFetchPriority` (:208) and `setReferrerPolicy` (:214), added in one CHANGELOG entry (CHANGELOG.md:483).
No file in the teaching corpus states either rule (0 lines in guidelines/web-development/**, README, REFERENCE,
CLAUDE.md). The model, writing from its prior, uses the DOM IDL property name; primed with lowercase exemplars
it generalizes lowercase and then misses the 3 camelCase names. Either way it misses.

F-D-160 (v6.0.1) re-measured: it named `setHttpEquiv`, `setCrossOrigin`, `setViewBox` as the intercapped
outliers and proposed `setHttpequiv`/`setCrossorigin`/`setViewbox`. At runtime, 146 of 149 single-attribute
setters follow "set + the attribute, hyphen and camel boundaries capitalized"; `setViewBox` mirrors SVG's
case-sensitive `viewBox` and `setHttpEquiv` mirrors the hyphenated `http-equiv`. The true outliers are
`setCrossOrigin`, `setFetchPriority` (missed by F-D-160) and `setReferrerPolicy` (missed). History runs the
other way too: 6.0.0 renamed `setCrossorigin` -> `setCrossOrigin` and `setReferrerpolicy` -> `setReferrerPolicy`
(CHANGELOG.md:703); 46 pre-7 fleet sites still call `setCrossorigin`.

## Rough idea (not a design)

(IDL, `Element` suffix dropped: `setPopoverTarget`, `setCommandFor`). 9.0.0, receiver-checked rename codemod over
12 non-zero names (8 names rename at zero cost), eslint map regenerated rather than hand-edited (F-C-506), no
aliases. The unprimed guess then compiles with no error at all. If 9.0.0 cannot carry it, F-C-502's one-pass lint
with case-only autofix is the non-breaking fallback. In both cases retire F-D-160's lowercase direction: it adds
5 unprimed misses and renames setViewBox's 266 sites. Prose deleted: none required; REFERENCE/guidelines
mentions move with the codemod.
