# method-census.mjs double-counts agent worktrees, lets Array.fill and Playwright calls through the .fill guard, and counts vendored template code as app code

$C4 = <scratch>/wave1/C4

## Problem

The census feeds the README head, the prune list and this run's ranks. It has three measured defects.

1. **Worktrees counted twice.** `SKIP_DIRS` (method-census.mjs:60) lacks `.claude`. `repoRootOf` (:159) treats each `projects-template/.claude/worktrees/agent-*` (it has a `.git` file) as its own repo, and the projects-template walk also descends into it.
2. **`.fill` guard.** `fill: { requiresArg: true }` (:77) cannot tell `.fill("primary")` from Playwright's `.fill("admin@example.com")`. `NON_TAG_RECEIVER` (:88) matches only `Array.`, so `new Array(60).fill("word")` counts as the Tailwind `fill` method.
3. **Vendored template code.** Every 8.1.0 app carries the template's `src/core` and `tests/`. The canonical-era column credits those copies to each app.

## Evidence (executed)

Fresh runs (2026-10-01), same script, three corpora:

| Corpus | Repos (canonical) | Files | Sites | Canonical-era sites |
|---|---|---|---|---|
| official (committed script) | 63 (19) | 16,033 | 299,694 | 113,491 |
| dedup (+ `.claude` in SKIP_DIRS) | 58 (16) | 12,811 | 259,484 | 81,635 |
| app-authored (dedup minus core/ tests/ scripts/ e2e/ fixtures/ *.test.ts) | 58 (16) | 7,928 | 251,084 | 76,635 |

- Worktree share: 40,210 fleet sites (13.4%), 31,856 canonical-era (28.1%).
- Canonical rank flips: `addClass` #30 official vs #72 dedup; `addAttribute` #71 vs #122. `.first(` drops from 19 official sites to 5 dedup; of those 5, 1 is non-fluent (`website-sales-funnel-automation-system/src/worker/crawl/renderer.ts:71`). The `.first` collision is a worktree artifact.
- `.fill(` over the dedup corpus (`$C4/fill.mjs`): 543 sites pass the guard. 33 are `Array(n).fill(x)` / `Array.from(…).fill` (e.g. `buzzin/scripts/fetch-quiz-info.ts:173`, `everyframe-composer/scripts/parse-notion-script.ts:216`, `everyframe-composer/tests/unit/experiments-model.test.ts:77`). 8 are Playwright `locator(…).fill("…")` (`projects-template/tests/e2e/specs/htmx-smoke.spec.ts:144-145, :190`). That leaves 41 non-fluent sites (7.6%).
- Vendored share of canonical-era sites (dedup, then app-authored):

| Name | Dedup canonical (rank) | App-authored canonical (rank) | Vendored |
|---|---|---|---|
| `setHtmx` | 267 (#42) | 35 (#132) | 87% |
| `.behavior` | 370 (#33) | 82 (#91) | 78% |
| `Partial` | 69 | 11 | 84% |
| `hx` | 33 | 1 | 97% |
| `defineRoutes` | 667 | 329 | 51% |
| `.apply` | 3,972 (#4) | 3,850 (#4) | 3% |

- The `--markdown` mode (:342-348) emits 3 columns. The README head has 5 (rank and signature are hand-merged), so "regenerate" is manual, and it would bake in all three defects.

## Why it matters

impact 3 x pain 2 x reach 2 / S. Every census-driven decision inherits these errors: prune eligibility, head membership (`.behavior` looks rising, but its app-authored rank is #91), and escape-hatch framing (a canonical `addClass` rank of #30 vs #72). Guardrail S-23 says additions and prunes are evidence-gated. The evidence tool itself is off by 28.1% in the column that gates 8.x decisions.

## Rough idea (not a design)

Layer: ci.
- Skip `.claude` and any nested dir that holds a `.git` file below a repo root.
- Add receiver guards for `.fill`: `Array(…)`, `new Array(…)`, `locator(…)`, `getBy…(…)`, `page.`.
- Emit an app-authored column driven by the template's own list of vendored dirs.
- Add a census self-test fixture (a tiny fake org dir with a worktree, a Playwright spec and an `Array.fill`) whose totals are pinned.
- Emit the README head in its final 5-column form, so regeneration is one command.
