# SVG paint has two spellings and the closed-token rule covers one

$R = <scratch>/wave1/C-reseed

## Problem

An SVG colour can be written as a presentation attribute (`.setFill("#111827")`, typed `string`) or as a class (`.fill("text")`, typed `TailwindColor | "none"`, closed by `defineTheme` and the template's palette opt-out). Only the class spelling is held to "never write a palette literal in a view". The template converged on 2026-08-19 (b9b057f): its chart kit colours every mark with `.fill(token)`/`.stroke(token)` and uses the setters only for `none`/`transparent`. The apps scaffolded before that carry the old `src/shared/ui/charts.ts`, which encodes the Tailwind palette as hex constants (`"#3b82f6", // blue-500`). The same split exists for hit-testing: `addAttribute("pointer-events", "none")` next to the vocab row `.pointerEvents("none")`.

## Evidence (executed)

**Census** (`$R/paint-census.mjs`, dedup corpus, AST, canonical app-authored):

| Spelling | Sites / repos |
|---|---|
| `setFill` hex literal / `setStroke` hex literal | 20 / 4, 5 / 5 |
| `setFill` / `setStroke` expression (constants such as `LABEL_COLOR`, a `color` param) | 53 / 7, 38 / 6 |
| `setFill` / `setStroke` keyword (`none`, `transparent`, `currentColor`) | 135, 49 |
| `.fill(token)` / `.stroke(token)` | 378 / 10, 97 / 10 (+ `current` 7, 4) |
| `addAttribute("pointer-events", "none")` | 10 / 5 |

- Hex constants: the 6 charts.ts copies hold 116 hex literals (22, 22, 22, 22, 15, 13), 103 of them commented with the Tailwind palette name they encode. 4 copies are live (imported by analytics views in fluent-html-home-page, na-cent, workshop-toni, home-page); fl-um's and gzs/stem-50's have 0 importers.
- Template kit: 44 `.fill/.stroke("<token>")`, 4 `.pointerEvents("none")`, 0 hex literals, setters only with `none`/`transparent` (6).
- Layers on the legacy spellings, probe in the 3.7.0 scaffold: `Circle().setFill("#111827").setStroke("#ffffff")` and `Circle().addAttribute("pointer-events", "none")`: 0 tsc errors, 0 eslint reports. The template theme guard's regex matches named palette tokens only: 0 hits over the 6 copies' 116 hex literals.
- Equivalence (`$R/paint-browser.mjs`, Chromium, Tailwind 4.3.3 CSS from fl-um's tokens): bytes differ 5/5 (attribute vs class), computed `fill`/`stroke`/`pointer-events` and `elementFromPoint` equal 5/5 (e.g. `fill="#111827"` and `class="fill-text"` both `rgb(17, 24, 39)`; pointer-events attr and class both let the hit fall through to the element below).
- Codemod dry run (`$R/codemod2`, scratch copies of the 16 canonical repos, 8 with sites, tsc before/after):
  - `addAttribute("pointer-events","none")` -> `.pointerEvents("none")`: 10/10.
  - hex -> `.fill/.stroke("<token>")` only where exactly one theme token holds that hex: 5/25. 13 are ambiguous because the hex is held by 2-3 role tokens (`#ffffff`: on-accent, surface, on-inverse; `#111827`: inverse, text), 7 have no token (4 are Google's brand colours in na-cent's sign-in logo, where `.fill("[#4285F4]")` compiles).
  - tsc 0 -> 0 in all 6 repos touched by these two rewrites.
- Closed-type prototype (`$R/t1/paint.ts`, `SvgPaint = "none" | "currentColor" | "transparent" | "context-fill" | "context-stroke" | url(#…)`; hex mapped to a message type): `setFill("#111827")`, a `const AXIS_COLOR = "#9ca3af"` and an `as const` palette entry each get `TS2345 ... not assignable to parameter of type '"palette literal: use .fill(token) / .stroke(token) with a defineTheme color role"'` (3/3); the 4 keywords compile; a `string` variable gets `TS2345 'string' is not assignable to 'SvgPaint'` with no fix named.

## Why it matters

impact 2 x pain 1 x reach 2 / M = 2. A rebrand edits theme.ts and every class-coloured mark follows; 116 hex constants in 6 apps do not, and nothing tells the author ("two jobs sharing one hex today are two tokens" cannot even be applied mechanically: 13 of 25 literal sites map to 2-3 roles). The template already shows the converged form, so this is a fleet residue the lib's open `string` keeps legal. Dims: decision-closure (two spellings for one paint job), evolvability (rebrands miss charts), prior-alignment (the attribute spelling is what the HTML/SVG prior writes).

## Rough idea (not a design)

Layer: lint in 8.2.0 (additive, warn): a hex/`rgb()`/`hsl()` literal or a `const` initialized with one reaching `setFill`/`setStroke`/`setStopColor`, and `addAttribute("pointer-events", …)`, each report naming the class successor; the template theme guard adds a hex pattern for `.set(Fill|Stroke)(`. Type in 9.0.0: `SvgPaint` on the three setters (keywords + `url(#id)`), colours through `.fill(token)` or the bracket hatch; codemod covers 15 of 35 literal sites mechanically and reports the rest with their candidate roles.
