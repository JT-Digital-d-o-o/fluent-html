# One wrong setter name types the rest of its chain as `any`

## Problem
TypeScript types a failed property access as the error type (`any`), so after the first unknown method in a
fluent chain every later call in that chain is unchecked. fluent-html views are long chains: the `Input()`
chain in run H1 carries 12 setters, 7 of them casing misses (`setMinLength`, `setMaxLength`, `setInputMode`,
`setEnterKeyHint`, `setDirName`, `setTabIndex`, ...). tsc prints only the first miss per chain. An agent that
fixes what tsc prints needs one tsc round per miss depth, and each fix exposes the next.

## Evidence (executed)
`$C5` = `<scratch>/wave1/C5`.

1. Source: the 8 context-withheld generations of F-C-501 (claude-opus-5-5, `--restricted`, tools [Write] only,
   3,682-4,083 starting context tokens, 0 reads). `prior/heal.cjs` compiles each `design.ts` against
   `dist/src/index.d.ts`, applies only the reported `Did you mean` fixes, and repeats:

   | run | TS2551 per round | rounds | names fixed |
   |---|---|---|---|
   | H1-H3 | 9, 5, 2, 2, 1, 1, 0 | 6 | 20 |
   | D1 | 10, 5, 2, 2, 1, 1, 0 | 6 | 21 |
   | D2 | 9, 5, 2, 2, 1, 1, 0 | 6 | 20 |
   | E1-E3 | 5, 2, 1, 0 | 3 | 8 |

   Round-1 visibility: 45% (9/20) unprimed, 62.5% (5/8) primed. Value-type errors in the masked tail
   (5 `number` -> `string` SVG coordinates per run, F-C-503) also stay hidden until the names heal.
2. `onepass.cjs`: comparing every `.set*`/`.add*` call name with the 8.1.0 surface finds 20/20 (H), 22/22 and
   21/21 (D, incl. the nonexistent `setClipPath`), 8/8 (E) in a single pass; every case-only miss has exactly one
   case-insensitive match on the surface.
3. `unknown-scan.cjs` (precision): canonical era has 570 non-surface `.set[A-Z]*(` calls, all on non-fluent
   receivers (`reply.setCookie`, `server.setErrorHandler`); gating on a chain rooted at a fluent factory call
   leaves **0** of them. Pre-7 repos: 157 gated hits, all real 8.x breaks: `setToggles` 73, `setCrossorigin` 46
   (case-only, renamed in 6.0.0, CHANGELOG.md:703), named boolean setters removed in 6.0.0 (`setDefer` 11,
   `setControls` 9, `setDisabled` 3, ...).
4. recon 02: in-repo agents reached for tsc 1-2 times per run (02-agent-fitness-delta.md:90-92), below the 6
   rounds the unprimed chain needs.

## Why it matters
impact 2 x pain 2 x reach 2 / S = 8. verification-loop: the only layer a single-pass agent reliably reaches
(tsc) reveals less than half the naming misses per round. error-quality: every masked miss is invisible, not
merely badly worded. Reach 2: every unprimed first write (5/5 runs) and every pre-7 upgrade (157 gated sites);
in-repo agents that read d.ts first did not hit it (recon 02 blind/guided: 0 casing errors).

## Rough idea (not a design)
Lint layer (the type layer cannot un-mask a chain): an AST-only rule, no parser services (avoids the L-349
no-op), whose surface list is derived from `dist/` at plugin load like the class vocab. It reports every unknown
`.set*`/`.add*` in chains rooted at a fluent factory, with the unique case-insensitive match as autofix
(20/20 of the measured misses). It is also the non-breaking alternative to F-C-501's rename, and it turns the 46
pre-7 `setCrossorigin` sites into autofixes on upgrade. Prose deleted: none needed; no guideline teaches
setter casing today.
