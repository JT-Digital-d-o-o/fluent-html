# Pure-prior divergence map against 8.1.0

## Problem
What the model writes with no context (recon 02 pp1/pp2) is aligned on names and divergent on layer choice: it reaches for `addClass`/`addAttribute`/raw strings and an htmx-2 vocabulary. Whether a divergence costs anything depends on the redirect it meets. Measured below, the redirects land on compiling code for 44-50% of non-class sites and 73% of class tokens; 10-31% of sites meet no layer at all.

## Evidence (executed)
Method: typescript 6.0.3 AST inventory of both runs vs a runtime walk of 8.1.0 dist; files copied into the scaffold (sqlite+auth) with relative imports normalized to `.js`; eslint with the template config (plugin 4.1.0); tsc; `npm run css`; per-token and per-shape probes. Outcome classes: **absorbed** (no layer fires, code is correct), **one-shot** (the first report names a fix that compiles as written, or autofixes into compiling code), **miss** (a layer fires but names the brand only, a multi-step restructure, or a fix that fails the next layer), **silent** (no layer fires on wrong or off-policy code).

Tallies, non-class sites (K1, K4, K6, K7-K14): pp1 55 = 24 one-shot + 14 miss + 17 silent; pp2 60 = 30 + 24 + 6. Class tokens (isolated literal probe per token): pp1 124/171 one-shot (72.5%), pp2 123/168 (73.2%).

Recurrence: 16/16 kinds occur in both runs (K8 with a different name per run, K12 in a different shape). Repeated verbatim across runs: the `Html` import, `hx("/team/members", ...)` x2, `role === selected ? option.addAttribute("selected", "") : option`, `.addAttribute("lang", "en")`, both CDN URLs, 76 of 110 distinct class tokens (20 of 32 palette).

tsc correction: recon 02's "13 tsc errors in the template" is 3 fluent-attributable per run (K1 + 2x K4); pp1 has 9 TS2835 + 1 TS7006 cascade, pp2 7 TS2835 + 2 TS7006 + 1 Fastify Buffer type. With those 3 fixed, `npm run css` builds and every prior class reaches the CSS (93/93, 88/88).

No silent caps: n = 2 runs. Launching 4 more pure-prior runs from this finder was not permitted in this session, so recurrence is measured over 2 runs.

## Why it matters
Naming is already aligned (K3: every fluent name the prior writes exists). The outcome is decided by redirects, and 5 kinds (K4, K5a, K6, K9, K13) redirect without landing while 4 (K8, K11, K12-pp1, K15) are silent. Reach 3 (every kind recurs), impact 2, pain 2; prior-alignment and verification-loop.

## Rough idea (not a design)
Ci: freeze pp1/pp2 (about 1k LOC) as prior fixtures and add a prior-replay test in the template and plugin CI: `eslint --fix` then tsc must not raise the error count ([[F-C-201]] fails it today: 3->27, 4->30), every kind in this table must be reported by some layer (K8, K11, K12, K15 fail), and every fix a message names must compile ([[F-C-203]], [[F-C-206]] fail). The table becomes the regression suite and each RFC can be priced by the rows it moves.
