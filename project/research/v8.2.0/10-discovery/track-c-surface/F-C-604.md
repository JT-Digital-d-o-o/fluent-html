# `.variant("group-hover")` is a second spelling of `.groupHover()`

$R = <scratch>/wave1/C-reseed

## Problem

The convention is "tier-1 states/breakpoints are direct methods, the long tail goes through `.variant(name, {…})`" (gl CLAUDE.md:218), and the lint already encodes it: `no-tailwind-in-raw-class` turns `addClass("group-hover:opacity-100")` into `.groupHover({ opacity: "100" })`. But `.variant()`'s name type is `TailwindState | TailwindBreakpoint`, which contains every tier-1 prefix, so `.variant("group-hover", {…})` compiles, lints clean and renders the same bytes. Four apps use that second spelling. The lib's own JSDoc (tailwind-methods.ts:167) endorses one more: `.variant("2xl", …)` beside `.xl2()`.

## Evidence (executed)

- Census (`$R/tier1-census.mjs`, dedup corpus, AST, 4 channels; canonical app-authored): `.variant()` with a tier-1 prefix 14 sites in 4 repos: group-hover 10 (everyframe 9, na-cent 1), focus-within 2 (sportoawards), focus-visible 1 and peer-checked 1 (home-page). Method calls for the same 4: groupHover 55, focusWithin 11, focusVisible 22, peerChecked 11. All tier-1 method calls: 2,485. `.variant("hover"|"sm"|"md"|"lg"|"2xl"…)`: 0.
- Bytes (`$R/codemod2/bytes-a.mjs`): each site's own style object rendered through `.variant(p, obj)` and `.<method>(obj)`: 14/14 identical (e.g. `<div class="group-hover:border-tally"></div>`).
- Codemod dry run (`$R/codemod2`, scratch copies, mode A): 14/14 rewritten, 0 skipped; tsc 0 -> 0 in everyframe, home-page, na-cent, sportoawards.
- Layers, probe in the 3.7.0 scaffold: `.variant("group-hover"|"focus-within"|"focus-visible"|"peer-checked", …)` 0 tsc, 0 eslint; the same file's `addClass("group-hover:opacity-100")` gets `'group-hover:opacity-100' in .addClass() bypasses the typed surface. Replace with: .groupHover({ opacity: "100" }). [autofix]`.
- Prototype (`$R/t1/variant.ts`): `name: N extends Tier1Prefix ? \`tier-1 prefix: write .${ByPrefix[N]}({ … })\` : N` derived from `DIRECT_VARIANTS` (minus `2xl`). `variant("group-hover", …)` -> `TS2345: Argument of type '"group-hover"' is not assignable to parameter of type '"tier-1 prefix: write .groupHover({ … })"'`; same for focus-within (2/2). `has-[:checked]`, `placeholder`, `2xl`, `data-[state=open]` compile (4/4).
- Generation runs: 0 tier-1 `.variant()` spellings in the 6 recon-02 runs and the 8 prose-only runs of F-C-602 (they write `.focus(` 16, `.focusVisible(` 18, `.hover(` 12).

## Why it matters

impact 1 x pain 1 x reach 2 / S = 2. Small, but it is the cheapest remaining two-way: one spelling per prefix is already the lint's and the guideline's position, the output is byte-identical, and the codemod is total. Closing it in the type also lets the 21-name tier-1 list (gl CLAUDE.md:229, fluent-html/CLAUDE.md:233) leave the always-loaded prose, since the error names the method. Dims: decision-closure, context-economy.
