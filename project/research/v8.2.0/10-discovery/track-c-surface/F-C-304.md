# addAttribute has converged in canonical code; its key type has not

## Problem

`addAttribute(key: string, value: string)` (`tag.ts:227`) accepts every key. For 3,512 of the 3,965 fleet call sites a typed path exists:
- a typed `set*` setter;
- `.toggle()` for boolean attributes;
- `.setAria`, `.setDataAttrs`;
- `.setHtmx` or a swap verb.

Three warn/error lint rules (`prefer-set-method`, `prefer-toggle`, `prefer-htmx-api`) and repeated prose ("never use addAttribute for standard props") hold the line.

In canonical app code the two-way has already collapsed. Every remaining call is a key with no setter, which leaves the type wide open for exactly the guesses the pure prior makes (recon 02 D5: 23/30 typed-attribute `addAttribute` calls per run, including htmx-2's `hx-disabled-elt`).

## Evidence (executed)

**Census** (`$C3/twoway-census.mjs`). The first argument is classified against the runtime setter map of `dist/` 8.1.0: 158 set* names, BooleanAttribute, `aria-`/`data-`/`hx-` prefixes.

|---|---|---|---|---|
| element attribute with a subclass setter | 2,436 | 2,436 | 0 | 0 |
| `data-*` (`setDataAttrs`) | 305 | 305 | 0 | 0 |
| `hx-*` with a typed path | 225 | 224 | 1 (vendored `hx-preserve`) | 0 |
| global attribute with a Tag setter (`role`, `tabindex`, `title`…) | 215 | 215 | 0 | 0 |
| boolean (`toggle`) | 151 | 151 | 0 | 0 |
| `id` / `class` / `style` | 126 | 126 | 0 | 0 |
| `aria-*` (`setAria`) | 54 | 54 | 0 | 0 |
| `hx-on*`, `hx-*:inherited` (no typed path) | 169 | 153 | 16 (vendored `core/behaviors/runtime.ts:122`) | 0 |
| no typed setter | 260 | 232 | 28 | **28 (15 repos)** |
| non-literal key | 24 | 24 | 0 | 0 |

- **Typed-alternative share:** 3,512 / 3,965 = 88.6% fleet; canonical app 0 / 28.
- **The 28 canonical app sites:**
  - `preserveAspectRatio` 15 (two chart helpers, one site in each of 15 repos);
  - `pointer-events` 10, which has a class twin `.pointerEvents("none")` (`vocab.ts:274`) that no rule knows;
  - `onclick` 1: inline JS in `packages/ui/src/feedback/Alert.ts:61`, CSP-dead;
  - `fill-opacity` 1;
  - `paint-order` 1.

For comparison, the typed spellings in canonical app code: `setAria` 456 (14 repos), `setDataAttrs` 164 (8), `toggle("…")` 575 (16).

**Prototype** (`$C3/probe/addattr-proto.ts`, `tsc --strict`, 3 of 4 lines verbatim):

```
addattr-proto.ts(15,14): error TS2345: Argument of type '"required"' is not assignable to parameter of type '"use .toggle(\"required\")"'.
addattr-proto.ts(16,14): error TS2345: Argument of type '"aria-label"' is not assignable to parameter of type '"use .setAria({…})"'.
addattr-proto.ts(17,14): error TS2345: Argument of type '"hx-disabled-elt"' is not assignable to parameter of type '"use .setHtmx(route(…)) or a swap verb"'.
```

The fourth line (`"tabindex"` → `"use .setTabindex(…)"`) fails the same way. `preserveAspectRatio`, `hx-headers:inherited` and a widened `string` key compile. The `K & Redirect<K>` formulation was also tried: it collapses to `never` and names nothing, so the conditional shape matters.

**Teaching contradiction.** `guidelines/web-development/fluent-html.md:43` shows the hatch as `.addAttribute("role", "dialog") // escape hatch — ONLY when no typed setter exists`, but `setRole` exists (`tag.ts:476`). The template's `prefer-set-method` (error, `eslint.config.mjs:62`) flags that very line.

## Why it matters

- **Scoring:** impact 2 × pain 2 × reach 3 (pure-prior recurrence 2/2 runs; 88.6% of fleet sites) / effort M(2) = 6.
- **Error quality:** today a typed-attribute guess compiles, and at most a warn-level rule fires. `prefer-htmx-api` is warn in the template (`eslint.config.mjs:77`), and its message names neither the attribute nor htmx 4's spelling (recon 02 D9).
- **The strongest layer is free here:** the census shows no canonical code to break.
- **It converts 3 rules plus prose into one type contract.**

## Rough idea (not a design)

Enforcement layer: **type**.
- `addAttribute<K extends string>(key: K extends Redirect<K> ? K : Redirect<K>, value: string)`.
- The Redirect map is generated from the same setter walk the census used, so there is no hand list (§5.9 spirit).
- **Stays open:**
  - URL attributes, which S-03 keeps as the explicit sanitization opt-out;
  - `hx-*:inherited` and `hx-on*`;
  - widened `string` keys.
- **9.0.0** (breaking in type terms): the codemod is the existing `prefer-set-method`/`prefer-toggle` autofix, run over the pre-7 repos when they upgrade.
- **Deleted:** 3 lint rules, the CLAUDE.md "never use addAttribute for standard props" block, and the fluent-html.md:43 example.
