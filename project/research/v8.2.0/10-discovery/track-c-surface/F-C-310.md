# The IfThen / .when two-ways have converged; the ✗ prose that teaches them has not been retired

## Problem

The guidelines spend ✗ lines on control-flow spellings that duplicate a primitive:
- `IfThen(!!x, …)` and `IfThen(x != null, …)` instead of narrowing `IfThen(x, (x) => …)` (`CLAUDE.md:163-164`);
- `IfThen(x, () => …x!)` (`:162`);
- a ternary (`:165`);
- complementary `IfThen` pairs instead of `IfThenElse` (`:166-167`);
- `.when(x)…when(!x)` instead of `.whenElse` (`:199`).

The census shows canonical app code no longer writes these shapes in measurable numbers, while the prose is loaded into every guided session.

## Evidence (executed)

**TypeScript-AST census** (`$C3/ctl-census.mjs`, `$C3/twoway-census.mjs`), dedup corpus:

| Shape (taught ✗) | Survivor | Pre-7 fleet | Canonical app | Survivor canonical app |
|---|---|---|---|---|
| `IfThen(!!x, …)` (`:163`) | `IfThen(x, (x) => …)` | 74 | 6 | IfThen 1,601 |
| `IfThen(x != null, …)` (`:164`) | same | 109 | 5 | |
| `IfThen(x, () => …x!)` (`:162`) | same | 3 | 1 | |
| complementary `IfThen` siblings (`:166-167`) | `IfThenElse` | 80 | 7 | IfThenElse 620 |
| `.when(x)` + `.when(!x)` on one chain (`:199`) | `.whenElse` | 113 | 1 | whenElse 346 |
| `IfThenElse(c, () => X.a, () => X.b)`, same root factory and args | `X.whenElse(c, …)` | 20 | 6 | whenElse 346 |
| `.when(c, t => t.toggle(x))` | `.toggle(x, c)` | 31 | 1 | toggle("…") 575 |

- The canonical-era shapes total 19 of 1,601 `IfThen` calls (1.2%).
- The `.when` pair is 1 of 347 (0.3%).
- `prefer-match` already covers the chained-`.when`-on-a-discriminant case (CLAUDE.md:149).

**Cause is not separable.** Canonical code was written with this prose loaded, so the census cannot tell prose credit from exemplar and type credit. Recon 02 priced the whole prose layer at ≤ 0 with context truly withheld (blind − guided = 0 tsc, −1 lint/run, 0/25 acceptance). Whether the blind runs wrote any of these shapes was not inventoried (recon 02 §2.2 lists ternaries 1-2 per blind run, not IfThen shapes).

## Why it matters

- **Scoring:** impact 1 × pain 1 × reach 3 (every guided session loads these lines) / effort S(1) = 3.
- **Context economy:** 7 ✗ lines, plus the surrounding explanation at `:158-161` and `:208-210`, guard shapes that occur ≤ 7 times each in canonical code.
- **Guardrail §5.12:** net guideline lines go down unless the canon is prose-only.

## Rough idea (not a design)

- Delete `CLAUDE.md:162-167` and `:199` (and the fluent-html/CLAUDE.md twins).
- Keep `prefer-match` (lint) for the discriminant case.
- If the 1.2% residual is judged worth guarding, the strongest layer is lint: L-334's `prefer-ifthenelse` and `no-boolean-collapsed-ifthen`. Ship them with a same-day prose deletion.
- Type-level narrowing already makes the ✓ spelling the shorter one.
