# hxGet/hxPost are legacy-only but still taught as a rung

## Problem
The 8.0.0 prune removed `hxPut`/`hxPatch`/`hxDelete` and kept `hxGet`/`hxPost` because the fleet used them (CHANGELOG.md:114). Split by era, every use is pre-7: 0 real calls in the 16 canonical-era repos (the census's 3 canonical `hxGet` sites are code samples inside strings on the fluent-html marketing page). The canonical era converged on the template verbs and `setHtmx` (dedup canonical: `setHtmx` 267, `.submit` 906). Each shorthand is `setHtmx(endpoint, { ...options, method })` by definition (htmx-methods.ts:44-50), so it is a second spelling of one job, and the guidelines still teach it as rung 4 of a four-rung ladder (htmx.md:209, :215) with three more examples (:250, :318, :511). REFERENCE.md teaches it with raw-string endpoints that have not compiled since the 8.0.0 brand.

## Evidence (executed)
- Census (dedup): `hxPost` 42 fleet / 0 canonical-era; `hxGet` 77 / 3, the 3 being `home.act-routes.view.ts:65/:73/:80` string samples (grep).
- Codemod dry run (`hx-codemod-dry.mjs`, TS AST): `hxGet` 74 calls in 7 repos (jt-chess@5.7.0 40, pokemon@5.7.1 11, mngmt@5.10.0 8, rideshare@5.11.0 8, planet-positive-sport@5.11.0 4, ttl@5.10.0 2, jtdigital-landing-page@5.10.0 1); `hxPost` 41 calls in 5 repos (rideshare 16, jt-chess 11, planet-positive-sport 11, cms@6.1.0 2, mngmt 1). Shapes: 68 endpoint + object literal (insert `method`), 45 endpoint + non-literal options (`{ ...opts, method }`), 2 endpoint only; 0 reported. 59/115 pass raw-string endpoints, which the 8.0.0 brand migration touches regardless.
- Byte equivalence (`hx-equiv.mjs`): `hxPost(e, o)` vs `setHtmx(e, { ...o, method: "post" })`, `hxPost(e)`, `hxGet(e, o)`, `hxGet(e)` vs `setHtmx(e)`, `hxPost(e)` vs `setHtmx(routes.create())`: 5/5 IDENTICAL.
- `ref.ts` (REFERENCE.md:115-116 verbatim): 2x TS2345 naming `ResolvedRoute | ExternalHref`.

## Why it matters
impact 2 (one fewer rung in the ladder every guided agent loads; two methods off `Tag.prototype`; one fewer way to emit `hx-post`), pain 1 (no failure today, a decision to make), reach 3 (taught in gl/htmx.md and its template mirror, REFERENCE.md, README.md:147, and named in the `prefer-htmx-api` message).
