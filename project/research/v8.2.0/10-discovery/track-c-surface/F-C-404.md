# README census head is built on the 46-repo 8.0.0 corpus and mis-states today's ranks, shares and escape-hatch positions

$C4 = <scratch>/wave1/C4

## Problem

The README calls itself "the census-ranked head" (README.md:25). Its numbers come from the one 8.0.0 run: 46 repos, 8,817 files, 197,837 sites, with 3 canonical repos (generated/full-surface.md:4-8). Nothing regenerates or checks it. The 5-column table is hand-merged from a 3-column `--markdown` output (method-census.mjs:342-348).

## Why it matters

impact 2 x pain 1 x reach 3 / S. The head is the teaching budget. It spends rows on `setClass`, `addClass`, `addAttribute`, `setValue`, `setRel` and `setSrc`, which today sit at canonical #52 to #122. It omits `.behavior`, `.whenElse`, `.variant` and `.whenMatch`, which the canonical era uses. The escape-hatch paragraph (:107-110) cites ranks that are 12 to 35 places off. Dims: prior-alignment, context-economy.

## Rough idea (not a design)

Layer: ci. After fixing F-C-402, generate the full README head (rank, name, counts, signature from a data file) between markers. Add `method-census.mjs --check README.md` in test.yml against a committed census JSON, so drift fails CI instead of accruing. Regenerate `generated/full-surface.md` the same way. Prose deleted: the hand-maintained paragraphs at README:107-124 become generated.
