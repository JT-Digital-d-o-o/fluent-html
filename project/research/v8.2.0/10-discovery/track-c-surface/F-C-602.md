# The always-loaded guideline prose grew 4,438 tokens after the scorecard priced it at zero

$R = <scratch>/wave1/C-reseed

## Problem

On 2026-08-14 (guidelines fd0ae85) the scorecard found the guidelines bought almost nothing and set the lever "actually shrink". Recon 02 re-ran the comparison with context truly withheld on 8.1.0: blind and guided tie on tsc and on 25 of 25 acceptance checks, and guided is worse on lint, for +19,579 always-loaded tokens. F-C-406 counts the growth since then in lines and blocks. Nobody had priced it in tokens or asked what the extra tokens bought. Measured here: the always-loaded file grew 29.3%, and the growth moves no idiom and no error count beyond run-to-run noise, even in the prose's best case (no repo, no exemplars).

## Evidence (executed)

**Token cost.** Same tokenizer, two methods that agree:

| | fd0ae85 (2026-08-14) | 95067fa (2026-09-28) | Delta |
|---|---|---|---|
| CLAUDE.md as loaded by Claude Code (first-turn context of the run minus the 2,875-token no-CLAUDE.md run) | 15,136 | 19,574 | +4,438 (+29.3%) |
| CLAUDE.md as a prompt (`count.sh`, minus 1,904 baseline) | 14,946 | 19,386 | +4,440 |
| CLAUDE.md + fluent-html.md + htmx.md | 42,248 | 49,754 | +7,506 (+17.8%) |
| all 7 web-development files | 54,090 | 66,937 | +12,847 (+23.8%) |
| fenced share of the 3 files | 17,353 (41.1%) | 20,207 (40.6%) | +2,854 |

On-demand reads come on top: recon 02's guided runs pulled .ai/ files 12 and 6 times, 100,052 and 61,877 chars of tool results.

**What the tokens buy.** Eight fresh prose-only runs (CLAUDE.md loaded, no repo, Write tool only, the recon-02 prior task; $1.43-1.80 each), evaluated inside the 3.7.0 scaffold after a `.js`-extension normalization. Pure prior = recon 02 pp1/pp2 re-evaluated with the same script.

| Condition (always-loaded prose) | tsc per run | eslint | API-level tsc | template-path TS2307 | typed styling calls | addClass / palette |
|---|---|---|---|---|---|---|
| pure prior (0) | 3, 4 | 170, 187 | 3, 4 | 0, 0 | 0, 0 | 41/43, 39/40 |
| gfd, fd0ae85 (15,136) | 16, 14, 13, 12 | 2, 2, 1, 1 | 6, 3, 3, 2 | 4, 5, 4, 4 | 72-84 | 0 / 0 in 4 of 4 |
| g95, 95067fa (19,574) | 11, 13, 10, 11 | 0, 2, 0, 0 | 2, 4, 3, 1 | 4, 5, 3, 4 | 78-117 | 0 / 0 in 4 of 4 |

Per 1,000 always-loaded tokens:
- growth fd0ae85 -> 95067fa (+4,438): tsc -0.56, lint -0.23, API-level errors -0.23 per run. The tsc ranges overlap (10-13 vs 12-16), and the idiom columns are identical in 8 of 8 runs (`defineRoutes` 1, `{ invalid:` 1, `Match` 2-4, `addClass` 0, palette 0 in every run).
- whole file, no repo (0 -> 19,574): lint -9.09, tsc +0.40, API-level -0.05. The idiom shift (typed styling, no palette) was already bought by the fd0ae85 file.
- whole file, in-repo (recon 02, +19,579): tsc 0, lint +0.05 (guided1's 2 `match-subset-default` errors, induced by the prose's subset-plus-default idiom), acceptance 0 of 25. Acceptance was not run for the prose-only code: it does not boot (next bullet).
- 33 of 33 TS2307 in the 8 prose runs are imports of template modules the prose names with no path: CLAUDE.md teaches `defineController` 7 times, `renderPage` 13, `requireAuth` 4, `Layout` 4, `isHtmxRequest` 1, and has 0 import lines. The model guessed `../../core/controller.js`, `../../core/routing/define-controller.js`, `../auth/auth.guards.js`, `../../../shared/layout.js`; the real modules are src/core/render/define-controller.ts, src/app/auth/shared/guards.ts, src/core/layout/layout.view.ts, src/core/htmx/htmx-request.ts. 0 of 33 guesses exist. Each carries a TS7006/TS7031 cascade (3-6 per run).

## Why it matters

impact 2 x pain 2 x reach 3 / M = 6. Every guided session pays the 19,574 tokens before its first tool call, plus 15K-25K of on-demand reads; guardrail 12 says net guideline lines go down every release, and the always-loaded file went up 29.3% in six weeks. The measured return of that growth is within one run of noise, and in-repo the whole file returns 0. Dims: context-economy (the cost), verification-loop (no CI holds a budget, so growth is invisible until a review like this one).

## Rough idea (not a design)

Layer: ci. A template root test (next to tests/guidelines-tokens.test.ts) that fails when CLAUDE.md exceeds a pinned line and byte budget, set at or below fd0ae85, and ratchets down. Shrink by deletion: the 95067fa additions moved no measured outcome, so they are the first candidates; taught blocks become compiling fixtures (F-C-406, F-G-101). The prose cannot replace the repo: without exemplars it produces invented import paths (33 of 33), so the budget should not be spent on adding paths either.
