# Guideline code blocks: 163 inline, 34 not compilable as taught, 2 exemplar targets

## Problem
The seed counted 117 inline blocks against 1 pointer to a compiling exemplar. Re-measured at guidelines 95067fa: 163 TypeScript blocks in the 6 agent-facing files (CLAUDE.md 33, fluent-html.md 31, htmx.md 48, fastify.md 20, typescript.md 16, views.md 15), and 27 more in fluent-html's own diverged CLAUDE.md. Pointers to compiling template source: 4 lines naming 2 targets (`src/app/auth/` at fastify.md:27 and CLAUDE.md:408; the sign-in 422 form at CLAUDE.md:274 and htmx.md:302). The blocks are the teaching; a compile sweep shows which of them are exemplar-grade.

The canonical "Use typed methods" example teaches the pure prior's own divergence: `A("Link").setHref("/page").setTarget("_blank") // AnchorTag` (fluent-html.md:27) is `TS2345 Argument of type '"/page"' is not assignable to parameter of type 'ResolvedRoute | ExternalHref | undefined'` since 8.0.0, the same error the prior's raw routes hit (map row K4).

## Evidence (executed)
Harness: each TS block -> its own module in the scaffold's `src/app/glprobe/` (fluent-html 8.1.0 + template swap verbs); lines containing ✗ dropped; used fluent-html exports auto-imported; a parse gate first (tsc suppresses semantic diagnostics program-wide when any file has a syntax error, so unparseable blocks are moved out); then free identifiers auto-declared `any` (value and type) over up to 4 tsc iterations.

## Why it matters
Every guided session loads these blocks (recon 02: +19,579 always-loaded tokens for 0 tsc and 0 acceptance delta vs blind). 34 of 163 (21%) cannot be copied as written, and the typed-methods example re-teaches the prior's raw-route error. Blind agents learned from compiling src exemplars instead (94/96 src accesses). Reach 3, impact 2, pain 2; context-economy and verification loop.

## Rough idea (not a design)
Ci over docs: the harness above as a guidelines test in the template (blocks compiled in the scaffold, fail on API errors, parse failures allowed only in blocks tagged as pseudo-code). Then replace blocks that restate a template file with a pointer to it (`src/app/auth/*`, the sign-in 422 form, `src/core/htmx/swap-verbs.ts`), and delete blocks whose rule a lint already carries. Net guideline lines go down (guardrail 12).
