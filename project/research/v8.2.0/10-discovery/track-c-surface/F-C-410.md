# 48 of the 92 zero-use methods are still taught in lib and guideline docs, contradicting the 8.0.0 de-documented freeze

$C4 = <scratch>/wave1/C4

## Problem

The 8.0.0 freeze says the zero-use set "stays in the package … but is no longer taught: … the frozen names appear only in the generated full-surface listing" (CHANGELOG.md:123-125). The listing repeats it: "zero-count names are frozen (kept, undocumented, candidates for a future prune)" (generated/full-surface.md:9-10). Measured today, about half of them are still documented, and CHANGELOG's own named example `setAbbr` is one of them.

## Evidence (executed)

**Zero-use re-census (fresh, 2026-10-01).** 92 method names have 0 fleet sites in both the official and dedup corpora: 46 Tag methods and 46 setters, the same set in both. 108 are at 0 in the dedup canonical era, and 112 at 0 app-authored canonical. Deleting the 92 takes 361 to 269 callables.

**Taught occurrences** (`$C4/zero-taught.mjs`, regex `\.name\(` per doc line):

| Doc | Zero-use names | Lines | Examples |
|---|---|---|---|
| REFERENCE.md | 25 | 32 | :1148-1152 `checked` `dark` `even` `odd` `after`; :1651 `setAbbr` `setHeaders`; :1771-1773 `setCite` `setDatetime`; :1185 `containerQuery` |
| FLUENT-STYLING.md | 29 | 29 | :270-276 `brightness` `contrast` `grayscale` `hueRotate` `invert` `saturate` `sepia`; :88 and :168 `textShadow`; :224 `insetS` `insetE` |
| guidelines/web-development/fluent-html.md | 5 | 7 | :257 `bgConic`; recon 01 §5 lists `setCite`/`setDatetime` at :503-506 |
| README.md | 1 | 1 | :105 `.static()` |
| fluent-html/CLAUDE.md and gl/CLAUDE.md | 1 each | 1 each | `textShadow` naming-rule example |

In total, 48 distinct zero-use names are taught on 70 lines. Not taught anywhere: the other 44.

## Why it matters

impact 1 x pain 1 x reach 1 / S. Each taught zero-use name spends reader context on an API with 0 exemplars and 0 fleet evidence. It also keeps the prune from ever being "zero blast radius": the docs have to be un-taught first. The freeze's claim, which the prune seed relies on, is false. Dims: context-economy, prior-alignment. Reach stays 1: README.md:105 is the only shipped occurrence (F-C-401).

## Rough idea (not a design)

Layer: ci. Once F-C-402's census fixes land, write the zero-count set to a committed JSON. Add a docs check that fails when README/REFERENCE/FLUENT-STYLING or the guidelines show `.name(` for a name in that set. Delete the 70 lines now. Deleting the 92 methods themselves (C1, 9.0.0, codemod 0 sites) can then proceed with no doc edits. Prose deleted: 70 lines.
