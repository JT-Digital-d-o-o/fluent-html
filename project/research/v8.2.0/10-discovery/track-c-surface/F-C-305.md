# The CSP-nonce options bag has 0 call sites; the named functions carry all 89

## Problem

The library ships two spellings for a render-time CSP nonce:
- the named functions `renderWithNonce(nonce, ...views)` (`render.ts:40`) and `renderToStreamWithNonce(nonce, view)` (`stream.ts:33`);
- the options-bag overloads `render(view, { nonce })` (`render.ts:24`) and `renderToStream(view, { nonce, … })` (`stream.ts:23`).

`RenderOptions` has exactly one field, `nonce` (`serialize.ts:76-83`).

The v6 design picked the bag as the survivor:
- L-230 rejected "named-only, no bag";
- L-141 (deprecate the named family) is decision-gated;
- L-154 (cut `renderToStreamWithNonce`) was never applied.

The fleet converged the other way.

## Evidence (executed)

**Census** (`$C3/twoway-census.mjs`, dedup corpus, AST):

| Spelling | Dedup fleet | Dedup canonical | App canonical | Where |
|---|---|---|---|---|
| `renderWithNonce(n, …views)` | 61 | 47 | 1 | template `core/server/server.ts:250,260,269` vendored into every canonical app; `templates/web/src/index.ts:111` |
| `renderToStreamWithNonce(n, view)` | 28 | 16 | 0 | template `server.ts:277` |
| `render(view, { nonce })` | **0** | 0 | 0 | only in `fluent-html/test/security.ts:291-305` and JSDoc (`render.ts:21`) |
| `renderToStream(view, { nonce/chunkSize/highWaterMark })` | **0** | 0 | 0 | 5 pre-7 calls, all single-argument `renderToStream(view)` |

**Why the bag lost** (probe). The bag overload takes one view, and the template's `renderView(...views)` decorator renders many:

```
render(Div(Script("a")), Span(Script("b")), { nonce: "n1" });
multi.ts(3,47): error TS2353: Object literal may only specify known properties, and 'nonce' does not exist in type 'Tag | RawString | View[]'.
```

The error names neither `renderWithNonce` nor the one-view restriction.

**Equivalence:** `render(Div(Script("a")), { nonce: "n1" })` and `renderWithNonce("n1", Div(Script("a")))` both emit `<div><script nonce="n1">a</script></div>`.

## Why it matters

- **Scoring:** impact 1 × pain 1 × reach 3 (16 of 16 canonical repos vendor the named form) / effort S(1) = 3.
- **Converge (§5.7):** two spellings, one of them dead; the doc comment on `render` (`render.ts:21`) teaches the dead one.
- **Decision closure:** an agent that finds the bag in the JSDoc and passes two views gets TS2353 with no pointer to the working spelling.
- **Blast radius:** removing the dead spelling touches 0 sites.

## Rough idea (not a design)

**Decision-gated:** choosing the named survivor reverses L-230 and resolves L-141 in the direction opposite to its proposal.

- **Option A** (0-site migration): delete the nonce-only `render(view, opts)` overload and `RenderOptions.nonce`. Keep `renderWithNonce`/`renderToStreamWithNonce`. Keep `chunkSize`/`highWaterMark` on a stream-only bag (0 sites today). Enforcement: type (the overload is gone).
- **Option B:** keep the bag and widen `render(...views, opts)`; codemod the 89 vendored sites.

Either way the JSDoc at `render.ts:21` and `stream.ts:20` loses one spelling.
