# The tier-1 tail is live on two channels; freeze it

$R = <scratch>/wave1/C-reseed

## Problem

Recon 01 seed 10 listed `active` 1, `last` 3, `first` 4 real and `before` 5 app-authored canonical sites as candidates to move under `.variant(name, …)`, and seed 7 flagged 15 of 19 `.first(` sites as collisions. F-C-106 decided only the 5 names at 0. Counting the method channel alone undercounts these four, and the proposed successor fails for the nested shapes they are used in.

## Evidence (executed)

**Per-channel census** (`$R/tier1-census.mjs`, dedup corpus, AST; M = method call, K = nested key in a variant object, V = `.variant()` name segment, C = raw class token):

| Name | canonical app M | K | V | C | pre-7 (C / `.on()`) |
|---|---|---|---|---|---|
| active | 1 (+2 `resultRoutes.active({ id })` route callables, already excluded by the census's `\w*Routes.` receiver rule) | 0 | 0 | 0 | 29 / 22 |
| first | 4 (+1 Playwright `.first()`) | 6 | 0 | 0 | 3 / 0 |
| last | 3 | 4 | 0 | 0 | 37 / 15 |
| before | 5 | 1 | 0 | 0 | 14 / 0 |

24 live sites (13 M + 11 K) in 7 repos (home-page, everyframe-composer, na-cent, workshop-toni, competify, fluent-html-home-page, projects-template's web template). 10 of the 11 keys are `.lg({ first: {…} })` / `.lg({ last: {…} })`; 1 is `.variant("has-[:checked]", { before: {…} })`. 14 generation runs (recon 02 and F-C-602's) wrote 0 of the four.

**Successors.**
- Method form: `.X(obj)` vs `.variant("X", obj)` with the live sites' own objects: 4/4 byte-identical (`$R/t1/bytes.mjs`).
- Nested form: the compound names `.variant("lg:first")`, `.variant("lg:last")`, `.variant("has-[:checked]:before")` are each `TS2345: Argument of type '"lg:first"' is not assignable to parameter of type 'TailwindState | TailwindBreakpoint'` (`$R/t1/probe.ts`). The only typed alternative swaps the order.
- Order swap, Tailwind 4.3.3 oracle (`$R/t1/order.mjs`): `lg:first:pl-0` vs `first:lg:pl-0`, `lg:last:pr-0` vs `last:lg:pr-0`, `lg:first:border-l-0` vs `first:lg:border-l-0`, `lg:active:scale-100` vs `active:lg:scale-100`: same declarations under the same media query. `has-[:checked]:before:bg-blue-500` compiles to `…:has(:is(:checked))::before`, the swap `before:has-[:checked]:bg-blue-500` to `…::before { &:has(*:is(:checked)) {…} }`.
- Chromium (`$R/t1/before-browser.mjs`, checked checkbox inside the label): nested-key form `::before` background `oklch(0.623 0.214 259.815)`; swapped form `rgba(0, 0, 0, 0)`. The key is the only typed spelling of `<state>:before:` that works.

**Census collision** (`$R/first-official.mjs`, official corpus): `.first(` 19 sites = 4 with an object argument + 15 zero-arg (14 in `projects-template/.claude/worktrees/*/research/**`, counted twice, and `website-sales-funnel-automation-system/src/worker/crawl/renderer.ts:71`). Dedup corpus: 5 = 4 + 1. `last`, `before`, `active`, `after`: 0 zero-arg sites. All 13 real sites pass exactly one argument, so `requiresArg` on the tier-1 names removes 15/15 collisions and 0 real sites.

## Why it matters

impact 1 x pain 1 x reach 2 / S = 2. The disposition matters more than the size: moving these four under `.variant()` would break 24 sites, 11 of them with no same-order successor, and 1 with no working successor at all. The same evidence bears on F-C-106: pruning `after` with its key removes the only typed spelling of `<state>:after:` (0 uses today; its `before` twin has 1). Dims: decision-closure (a prune that leaves a shape inexpressible), verification-loop (the census needs a guard, not a per-name exception).

## Rough idea (not a design)

Freeze: keep `active`, `first`, `last`, `before` as tier-1 methods and nested keys (agrees with L-226 / L-348; teaching trim stays a G decision). Census: add `{ requiresArg: true }` for every `DIRECT_VARIANTS` name in COLLISION_GUARDS, alongside F-C-402's worktree and `.fill` fixes. For F-C-106: if `after` goes, keep `after` as a nested key or accept compound names in `.variant()`.
