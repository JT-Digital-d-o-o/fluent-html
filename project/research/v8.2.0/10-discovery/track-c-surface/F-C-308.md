# The teaching corpus still teaches the losing spellings

## Problem

The 2026-08-14 scorecard measured "117 inline code blocks against 1 pointer to a real template source file" and set guidelines item 1 as "convert the 117 inline code blocks to pointers at compiling exemplars" (`scorecard.md:122-126`, `:185`).

The block count has not moved. Joined with this run's two-way census, a measurable share of those blocks teaches spellings that canonical app code has abandoned:
- 2 htmx rungs with 0 canonical app sites;
- a hatch example whose attribute has a typed setter;
- static `setStyle` as ✓.

Blind agents learn from exemplars, not prose (recon 02 §2.4). What prose adds is a second answer.

**Compile check.** REFERENCE.md's 10 htmx example lines fail `tsc --strict` on 8.1.0: 11 × TS2345, raw `"/api/…"` strings are not `ResolvedRoute | ExternalHref`. One of them also uses `preload`, deleted in 7.2.0.

**An exemplar already sits next to the code.** `swap-verbs.ts:12-20` documents all 8 verbs plus `{ invalid }` in 9 lines that sit next to the implementation they describe (a JSDoc header, not compiled today; pointing at it makes the verb signatures the reference).

## Why it matters

- **Scoring:** impact 2 × pain 2 × reach 3 (every guided session loads CLAUDE.md; +19,579 tokens, recon 02 §1.2) / effort M(2) = 6.
- **Context economy:** 57 lines teach htmx spellings with 0 canonical app sites (45 + 12).
- **Decision closure:** the htmx ladder presents 4 answers where the census has 1 (98.8%). The hatch example contradicts the rule printed beside it.
- **Guardrail §5.12:** net guideline lines must go down. This is a measured deletion list, not a rewrite.

## Rough idea (not a design)

**Enforcement layer: ci.** A docs-typecheck that extracts every fenced TS block not marked ✗ and compiles it against the pinned lib and template. It would have caught REFERENCE.md's 10 failing lines.

**Deletions** (net negative):
- htmx.md rungs 3-4 plus the examples at `:223-225`, `:250-253`, `:318-325`, `:511-514`;
- REFERENCE.md's htmx section;
- fluent-html.md `:39`, `:43`, `:69`, `:85`, corrected or removed.

**Replace** the ladder prose with one line pointing at `templates/full-stack/src/core/htmx/swap-verbs.ts:12-20`.
