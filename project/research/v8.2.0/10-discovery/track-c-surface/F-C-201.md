# no-tailwind-in-raw-class autofix is type-blind

## Problem
The pure prior routes all styling through `.addClass("tailwind string")` (41/39 calls, recon 02). The first redirect it meets is `no-tailwind-in-raw-class`, which reports each token as `'<cls>' in .addClass() bypasses the typed surface. Replace with: <chain>. [autofix]` (`no-tailwind-in-raw-class.ts:26`). The replacement is derived from class prefixes (`derive-fixable.ts`, including hand-kept residue tables) and is never checked against the value unions, so the autofix rewrites working code into code tsc rejects. `npm run lint:fix` (`eslint . --fix`) is the template's own script, and 4/4 in-repo agents reached for lint (recon 02 section 1.2).

Verbatim lint text, then tsc on 8.1.0:
- `border-b-2` -> `Replace with: .border("b-2")` -> TS2345. The typed form `.border("b", "2")` compiles and renders the same `class="border-b-2"`. `rounded-t-lg` -> `.rounded("t-lg")` -> TS2345; `.rounded("t", "lg")` compiles.
- `focus-visible:outline-2` -> `.focusVisible({ outline: "2" })` -> `TS2322 Type '"2"' is not assignable to type 'TailwindOutline | undefined'` (the union is `none|hidden|dashed|dotted|double`, `vocab.ts:288`), although the pinned Tailwind oracle compiles `outline-2`, `outline-offset-2` and `ring-inset`.
- `rotate-x-45` (3D rotate, pruned 8.0.0) -> `.rotate("x-45")` -> `TS2345 ... 'TailwindRotate'` (residue prefix `rotate-`, `derive-fixable.ts:112`). `bg-cover` -> `.bg("cover")` -> `... 'TailwindColor'` (the `bg` row is color-only, `vocab.ts:117`).

## Evidence (executed)
1. Whole class space. `design.getClassList()` of the pinned tailwindcss 4.3.3 (via `dist/scripts/gen-vocab/load-design-system.js`): 23,286 classes, 8,700 without a palette hue. One `Div().addClass("<cls>")` per line; eslint with only this rule; `eslint --fix`; `tsc --strict` against fluent-html 8.1.0 dist (default palette, no theme):

| lint outcome | classes |
|---|---|
| `Replace with ... [autofix]`, rewrite compiles | 2,344 |
| `Replace with ... [autofix]`, rewrite fails tsc | **1,888** |
| `... no fluent method. Use .cssProp()` | 4,082 |
| unflagged (378 are pruned `mask-*`) | 386 |

Split of the 1,888 (root via `design.parseCandidate`; every one-arg rewrite also re-compiled as a two-arg split):
- 194: `border-<side>-<v>` and `rounded-<corner>-<v>`. A correct two-arg typed call exists and compiles; the residue emits the one-arg form (`derive-fixable.ts:72`: "sizes/corners flow through the prefix residue").
- 1,050 over 201 roots that no compiling rewrite ever emits. 591 of them are 8.0.0-pruned or uncovered families routed to a surviving merged prefix (`scroll-m*` and logical `scroll-p*` -> `.scroll()`, `rotate-x|y|z` -> `.rotate()`, `scale-x|y|z` -> `.scale()`, `perspective-origin` -> `.perspective()`). The rest sit behind a covered prefix with no typed arm: `bg-cover|center|no-repeat|clip-text`, `justify-items|self`, `text-start|end`, `table-*` displays, `border-spacing`, logical insets, `ring-offset`, `outline` widths.
- 644 over 29 roots the vocab does emit: values Tailwind compiles but the union omits (`min-w-7`, `leading-4`, `flex-10`, `translate-x-1/6`, ...).
2. Pure prior in the template. Recon 02 pp1/pp2 copied to `src/app/team` of the scaffold (sqlite+auth), relative imports normalized to `.js` so only fluent errors remain. Baseline tsc: 3 (pp1: `Html` import, 2 raw routes) and 4 (pp2: same + a Fastify Buffer type). `eslint src/app/team --fix`: lint 170->41 and 187->42; tsc 3->27 and 4->30. All 24 and 26 new errors are rewrites of prior tokens, e.g. `P(...).mt("1").text("sm").text("slate-500")` (TS2345), `.border("slate-200")` (5-line TS2769), `.hover({ bg: "indigo-500" })`, `.focusVisible({ outline: "2" }).focusVisible({ outline: "offset-2" })` (TS2322).
3. Per distinct prior token (107 distinct over both runs, each probed in the template): 70 rewrites compile, 36 fail tsc (32 palette, 4 `outline-2` / `outline-offset-2` / `ring-inset` forms), 1 has no replacement (`focus-visible:outline`).

## Why it matters
Reach 3: every `addClass` token the prior writes, in both runs, and any session that runs `lint:fix`. Impact 3, pain 3: the message promises `[autofix]`, the autofix raises the tsc count, and `guidelines/web-development/fluent-html.md:46` states the rule "autofixes to the fluent chain". The prior's #1 divergence lands on a second error instead of on compiling code (error-quality, verification loop).

## Rough idea (not a design)
Strongest layer: ci in the plugin, backing the lint. A plugin test runs lint -> fix -> tsc over the pinned Tailwind class list against the pinned lib and fails on any rewrite that does not compile; classes that cannot be expressed get the existing report-only cssProp message. Fix the residue for side/corner two-arg forms (the plugin already does two-arg fixes for `overflow-x-auto`). Optionally consult `parserServices` (as `match-subset-default` does) to withhold a fix the host's own union rejects (theme opt-out). This makes `fluent-html.md:46` true rather than adding prose.
