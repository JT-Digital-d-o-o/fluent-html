## How Wave-1 finders use this file

- **Dedup key** (ALGORITHM §4): normalized title (the lowercase, punctuation-free column) OR primary evidence path+symbol. Match either and the finding is a re-raise.
- **Re-raise rule** (ALGORITHM §0): set `prior: L-NNN` in the finding frontmatter and state the new evidence (a measured number or `file:line` that post-dates the row's source). Without new evidence, the finding is dropped.
- **Status meanings.**
  - `decision-gated`: waits on a named human/guardrail call.
  - `parked-major`: valid but breaking. Goes to the 9.0.0 lane, codemod-first.
  - `parked`: valid, not scheduled (includes open backlog and by-design known limitations).
  - `deferred`: explicitly postponed, or accepted and then never built.
  - `rejected`: declined on the merits.
  - `withdrawn`: retracted by its own author/source.
  - `superseded`: overtaken by a later decision or redesign.
  - `shipped-since`: resolved after being parked/deferred; the source column carries `-> version (file:line)`.
- **Path prefixes.**
  - `fh/` = `fluent-html/`
  - `src/`, `test/` = `fluent-html/src/`, `fluent-html/test/`
  - `rs/` = `fluent-html/project/research/`
  - `pm/` = `fluent-html/project/pm/`
  - `tpl/` = `projects-template/`
  - `eslint/` = `fluent-html-eslint-plugin/`
  - `ext/` = `fluent-html-tailwind-extractor/`
  - `mem/` = `~/.claude/projects/<project>/memory/`
  - v6.3.0 synthesis rows cite `rs/v6.3.0/40-synthesis/fresh-eyes-synthesis.md:N`, where synthesis table row N sits at line 14+N.
- **Seeds.** Rows tagged "ALGORITHM … seed" are the §6 seed backlog. Those are expected re-raises: measure them fresh, don't re-debate them.
