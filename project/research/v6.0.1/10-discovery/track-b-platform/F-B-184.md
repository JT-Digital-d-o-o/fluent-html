# `transition-behavior: allow-discrete` is missing, leaving the shipped `starting:`/`open:` variants unusable for display/overlay transitions

## Problem
v6.0.0 already shipped the `starting` and `open` variant arms (tailwind-types.ts:232) — i.e. it bought into the `@starting-style` + popover/dialog `:open` transition model. But that model only works if the transitioning element *also* sets `transition-behavior: allow-discrete`, otherwise `display`, `overlay`, and `content-visibility` snap instead of animating, and the exit transition (and the popover's top-layer fade-out) never plays. Tailwind v4 exposes this as the `transition-discrete` utility. fluent-html has no method for it: the `TailwindTransition` union (tailwind-types.ts:172) is `none|all|colors|opacity|shadow|transform` with no discrete arm, and there's no separate `transitionDiscrete` static. So the `starting:`/`open:` variants the lib advertises produce broken half-animations unless the author drops to `addClass("transition-discrete")`.

## Evidence
```ts
// src/core/tailwind-types.ts:232  — variant arms present…
| "starting" | "open" | "inert"
// src/core/tailwind-types.ts:172  — …but the transition union can't express allow-discrete
export type TailwindTransition = "none" | "all" | "colors" | "opacity" | "shadow" | "transform";
```
Grep: no `transition-discrete` / `transition-behavior` / `allow-discrete` token anywhere in `src/`.

## Why it matters
This is a coherence gap in a feature the core already claims to support: shipping `starting:` and `open:` without `transition-discrete` is shipping the lock without the key. Any popover/dialog/menu exit animation — the exact thing `starting:`/`open:` exist for — silently fails to animate on close. Medium pain because it's a common, surprising bug, not a niche feature.

## Rough idea (not a design)
Additive (6.1.0): a zero-arg `.transitionDiscrete()` emitting the static class `transition-discrete`, registered in vocab as `stat("transitionDiscrete", "transition-discrete")`. One row in vocab.ts + the mirror in tailwind-methods.ts + extractor/eslint sync. Completes the @starting-style triad (`starting:` + `open:` + `transition-discrete`).
