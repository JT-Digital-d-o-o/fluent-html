# Self-sizing / text-wrap CSS platform hooks have no fluent surface

## Problem
A cluster of small but high-utility TW4-era CSS properties is unreachable as typed methods:

1. **`field-sizing: content`** — auto-growing `<textarea>`/`<input>` with zero JS (TW4 `field-sizing-content`). No method exists; the auto-grow textarea (a perennial HTMX-form need) falls back to JS or inline style.
2. **`text-wrap: balance | pretty`** — balanced headings / orphan-free paragraphs (TW4 `text-balance`, `text-pretty`). The `whitespace` setter (vocab.ts:103, `TailwindWhitespace` at tailwind-types.ts:199) covers `text-wrap`'s `wrap/nowrap` values via the *old* `white-space` property, but cannot express `balance`/`pretty`, which live on the separate `text-wrap` property.
3. **`interpolate-size: allow-keywords`** — animating to/from `height: auto` (the long-standing "can't transition to auto" pain). No method; inline style only.

## Evidence
```ts
// src/core/tailwind-types.ts:199 — covers white-space, NOT text-wrap balance/pretty
export type TailwindWhitespace = "normal" | "nowrap" | "pre" | "pre-line" | "pre-wrap" | "break-spaces";
// src/class-vocab/vocab.ts:103
pre("whitespace", "whitespace"),
// src/class-vocab/vocab.ts:245 — resize is the only adjacent self-sizing hook; no field-sizing
opt("resize", "resize"),
```
Grep: no `field-sizing` / `text-wrap` / `text-balance` / `interpolate-size` token in `src/`.

## Why it matters
Individually low-pain, but together they are the "modern form & typography polish" toolkit and all share the same gap shape: a one-line CSS property with a TW4 utility, no HTML attribute, currently reachable only via `addClass`/inline `style`. `field-sizing-content` in particular removes a real JS dependency from auto-grow textareas, which directly serves the SSR/zero-runtime-dep constitution.

## Rough idea (not a design)
Additive (6.1.0): `.fieldSizing("content"|"fixed")` → `field-sizing-{v}`; `.textWrap("wrap"|"nowrap"|"balance"|"pretty")` → `text-{v}` (typed union, distinct from `.whitespace`); `.interpolateSize()` → `[interpolate-size:allow-keywords]` arbitrary property. Three vocab rows + mirrors + extractor/eslint sync.
