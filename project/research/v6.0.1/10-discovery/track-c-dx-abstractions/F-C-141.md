# f.select binding is flat-only — no placeholder, optgroup, or multiple

## Problem
The typed `f.select(name, options)` only accepts a flat `readonly { value, label }[]`. Three extremely common select shapes are unreachable through the binding: (1) a leading placeholder/empty option ("Select a role…"), (2) `<optgroup>`-grouped options, (3) a multi-select bound to an array field. For any of these the author must hand-build `Select(...)` with raw `Option`/`Optgroup`, losing the `keyof T` name binding and the auto-`selected` wiring.

## Evidence
```ts
// src/elements/forms.ts:320
export type SelectOption = { value: string; label: string };
```
```ts
// src/elements/forms.ts:354
select(name, options) {
  const selected = values[name];
  const opts = options.map((o) => {
    const opt = Option(o.label).setValue(o.value);
    if (selected !== undefined && String(selected) === o.value) opt.toggle("selected");
    return opt;
  });
  return Select(...opts).setName(name);
},
```
The match is a scalar `String(selected) === o.value`, so an *array* value (multi-select) can never mark more than one option selected, and there is no `setSize`/`multiple` hook from the binding. `Optgroup` exists as an element (forms.ts:449) but the binding can't reach it.

## Why it matters
Role/status/category selects with a "— choose —" placeholder are on nearly every admin form; grouped selects (country-by-continent, category-by-section) and multi-selects (tags, permissions) are common enough that the binding's flat shape forces a frequent escape hatch. Medium pain: the workaround is verbose but not silently wrong.

## Rough idea (not a design)
Additive (6.1.0): widen `SelectOption` to a union that also accepts `{ label: string; options: readonly SelectOption[] }` (an optgroup) and an optional `disabled`/placeholder marker; give `f.select` an optional third `opts?: { placeholder?: string; multiple?: boolean }` that prepends an empty `<option>` and sets `multiple`, with array-aware `selected` matching when `multiple`. Stays a primitive — no styling.
