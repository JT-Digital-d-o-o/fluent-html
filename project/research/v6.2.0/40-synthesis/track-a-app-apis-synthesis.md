# Track A — App APIs · Synthesis (v6.2.0)

Consolidated from ten discovery lenses (a01–a10) mining two real consumer apps — `planet-positive-sport` (v5) and `pm-gui` (v6 template). Deduplicated across lenses, re-verified against CHANGELOG 6.0.0→6.1.1, and ranked by value vs effort.

The strongest signal in the corpus: **the `Styler`/variant-map/Icon composition trio** (raised independently by a04, a07, a08) and **the flex/spacing/container Tailwind shortcuts** (a03, a07). These are convergent *primitives*, not opinionated components — consistent with the "fluent-html is an instruction set" memory. Several lenses also re-proposed opinionated components (Badge, EmptyState, Pagination, BreadcrumbTrail); a08 explicitly argues these stay user-land and that the right library answer is the composition primitives (`Styler`/`variants`). That tension is resolved below.

## Quick wins (high value · small effort — ship first)

These are pure-type or single-overload additions with large call-site footprints and zero opinion:

- **#1 `Styler` type** + **#2 `variants()`** — the composition foundation. Ship as a pair; unblocks every "tone/variant→style" duplication and lets the parked components (Badge/StatCard/EmptyState) be built DRY in user-land.
- **#3 `padding`/`margin` axis-pair**, **#4 `size()`**, **#5 `container()`**, **#6 responsive `gridCols(map)`** — four extractor-safe Tailwind overloads collapsing 400+, 54, 49-file, and 107 call sites respectively.
- **#7 `.whenElse` nullable overload** (boolean form may already be shipped — see Cut list), **#8 `stack/row(gap?)`** — control-flow + flex ergonomics.
- **Forms cluster: #9 `HiddenFields`, #11 `formError`, #12 `revalidate`, #13 `setEditable`** — small, high-leverage on the `Form<T>` surface; #11+#12 fix the structural reason PPS renders zero per-field/validation errors today.
- **#15 `Options()`, #16 `ariaCurrent()`** — expose existing-but-trapped logic / close an a11y gap.

## Bigger bets (medium effort, or surface-area / framework-boundary judgement)

- **#10 `f.field()`** — composite shell on `FormBinding`; the single change most likely to drive `Form<T>` adoption, but it bakes a labelled-field structure (returns a Tag for styling to stay un-opinionated). Worth a design pass.
- **#8 `stack/row`** — confirm the `row` = `flex-row items-center` default against real usage (a03 evidence supports it; a07 wanted an options bag — prefer the terse form, keep atoms chainable).
- **#19/#25 htmx-aware redirect + `HxResponse`-into-render**, **#20 `defineSwaps()`**, **#21 `Shell`/`htmxSwitch`** — high real-world value but they sit on the **framework-glue boundary** (MEMORY: core is a pure HTML builder; context/DI + Fastify integration move to `@fluent-html/fastify`). Ship the *pure* pieces in core (`isHtmxRequest`/`hxRedirect`/`hxRefresh` descriptors are framework-agnostic data; `htmxSwitch(isHtmx, …)` takes an explicit boolean — both fine), and route the `reply.renderView`/onSend integration to the framework layer.
- **#14 `Icon()`, #22 `BreadcrumbTrail`, #23 `ForEachGroup`** — primitives/combinators, medium leverage.

## Cut / already-shipped / verify

- **`whenElse` (boolean form)** — CHANGELOG 6.1.1 (line 53) states `apply`/`when`/**`whenElse`** accept `(tag)=>unknown` modifiers, which implies `whenElse` **already exists** as a Tag method. a06#1 was likely measured against the v5 app. **Re-scope #7 to only the nullable-value-narrowing overload** if the boolean branch already shipped; do not re-propose the boolean form.
- **`Badge`/`Pill`/`Chip` primitive (a04#2), `EmptyState` (a04#3), `Pagination` (a04#4), `StatCard`/`Card`/`ThCell`/`TdCell`/`DashboardSection`/`CenteredPage` (a08 parked list)** — **CUT as library components.** These are opinionated design-system components, not primitives (MEMORY: "ship primitives, not Alert/Badge/Modal; design system is user-land"). a08 explicitly argues the right answer is the *mechanisms* (#1 `Styler`, #2 `variants`, #14 `Icon`) that let apps build them DRY. The component duplication is real but is **evidence for the primitives**, not for shipping the components.
- **`alignText(align)` (a04#5)** — folds into **#2 `variants()`**; it is just the canonical built-in `variants` instance for `text-left|right|center`. Ship `variants()`; optionally document `alignText` as a one-line recipe, don't add a bespoke export.
- **`stylers` (a04#1, a07#4) vs `variants` (a08#2)** — **same proposal, two names.** Merged into #2. Recommend the name **`variants`** (a08's argument: "`stylers` plural reads oddly"; it's a variant→style map). The pm-gui user-land file is named `stylers.ts` — note the rename in migration docs.
- **`screenColumn()` (a03 P3)** — folds into **#8** as `.stack().minH("screen")`; do not ship a separate method.
- **`f.field` error slot vs `formError`** — distinct (per-field shell vs form-level/cross-field slot); keep both #10 and #11.
