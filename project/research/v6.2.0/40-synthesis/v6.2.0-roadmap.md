## Executive summary

Across all three tracks the strongest signal is **collapsing repeated multi-call idioms into single typed methods** that the Tailwind extractor and the type system can both see: axis-pair `padding`/`margin`, `size`, `container`, responsive `gridCols(map)`, `from/via/to` stop positions, and the SVG `fill`/`stroke` color family each replace a verbatim chain (or a forbidden `setClass`) that appears dozens-to-hundreds of times in the consuming apps. The second theme is **closing half-built loops** — features where the library already *emits* something but won't *type* the consumer: `.on()` can't target the `aria-invalid`/`data-*`/`group-*` attributes the library itself produces, `whenElse` narrows values but apps still hand-pair `.when(x)`/`.when(!x)`, and `f.error()` is dead because `ErrorBag<T>` has no slot for form-level errors. The third theme is **typed-token safety on security- and a11y-critical attributes** that are currently bare `string` or unreachable without `addAttribute`: iframe `sandbox`/`allow`, declarative shadow DOM, `Ins`/`Del`/`Q`/`Blockquote` semantics, table `headers`/`abbr`, and `crossorigin` on media. Track A also surfaces a deliberately-bounded **framework-glue boundary**: HTMX redirect/shell/swap-preset ergonomics belong as *pure descriptors* in core with the `reply` wiring deferred to the `@fluent-html/fastify` layer, honoring the no-framework-glue memory. Net: 6.2.0 is mostly a large batch of small, extractor-resolvable, type-only-or-thin-emitter wins, with three genuine "bigger bets" (the `mask*` family, declarative shadow DOM + `::part`, and the HTMX shell/swap combinators). Nothing here re-treads 6.1.x (popover, native dialog, anchor positioning, `Form<T>`, relational state hooks).

## Bigger bets (large effort or cross-cutting)

These need their own design pass and likely a dedicated mini-RFC; they don't fit the "thin overload" mold.

1. **`mask*` family (Tailwind v4.1)** — #75. The single highest-value individual feature but the only **Large** item. Signature v4.1 capability, previously arbitrary-only. **Phase it**: ship `maskImage` + `maskLinear/Radial/Conic` + `maskFrom/To` edge fades + `maskComposite` first; defer `maskRepeat/Clip/Origin/Position`. Discovery: [`../10-discovery/track-c-tailwind-v4/c08-effects-filters.md`](../10-discovery/track-c-tailwind-v4/c08-effects-filters.md).

2. **Declarative Shadow DOM + `::part`/slot theming** — #22 + #38. `TemplateTag` with `setShadowrootmode` + the `shadowroot*` boolean tokens is the *only* zero-JS way an SSR builder ships shadow trees (DSD, Baseline 2024-08), and `setPart`/`addPart`/`setExportparts`/`setSlot` are the standards-track way to theme inside one. Designed and shipped together so the web-components surface is coherent; aligns with the "ship primitives, design-system is user-land" memory. Discovery: [`../10-discovery/track-b-html-elements/b10-templating-shadow.md`](../10-discovery/track-b-html-elements/b10-templating-shadow.md), [`b09-global-attrs.md`](../10-discovery/track-b-html-elements/b09-global-attrs.md).

3. **HTMX shell + swap-preset combinators (framework-glue boundary)** — #35 + #42 + #25 + #73. **⟂ Largely already resolved app-land in the template** — `core/htmx/swap-verbs.ts` ships `nav`/`submit`/`fragment` (hardcoding this app's `#main-content`/`#global-loading` via the `FluentCustomMethods` seam, under the recorded *no-`defineSwap`-in-core* decision), and `core/htmx/htmx-request.ts`'s `htmxRequest` context + `layout.view.ts` already do the document-vs-fragment fork. So this is **not a v6.2.0 core bet**: the only open question is whether to lift the *pure* descriptors (`HxResponse.status`, `hxRedirect`/`hxRefresh`) into **`@fluent-html/fastify`** — the `reply` wiring stays out of core per the *no-framework-glue* memory. Discovery: [`../10-discovery/track-a-app-apis/a02-htmx-boilerplate.md`](../10-discovery/track-a-app-apis/a02-htmx-boilerplate.md), [`a10-fullstack-glue.md`](../10-discovery/track-a-app-apis/a10-fullstack-glue.md); cross-ref [`template-cross-reference.md`](./template-cross-reference.md).

4. **3D transform bundle** — #27–#29, #60. Not large individually, but `perspective` *gates* the set (3D transforms render flat without it) and `transformStyle`/`backfaceVisibility` only matter for nested scenes — so they ship as one coherent unit or not at all. Discovery: [`../10-discovery/track-c-tailwind-v4/c04-transforms-3d.md`](../10-discovery/track-c-tailwind-v4/c04-transforms-3d.md).

5. **`f.field()` composite + `Form<T>` completion** — #24 + #7 + #59 + #34. The cluster that most likely drives `Form<T>` adoption: a labelled field shell (`f.field`), the form-level error slot it needs (`formError`), `multiselect`, and bulk `f.hidden`. Sequenced after `formError` (#7) since `field` composes `f.error`. **⟂ Reframe per template:** the template's `FormField`/`FormGroup` (`src/shared/ui/form.ts`) is an *untyped* wrapper — the net-new core value is the **typed `f.field("email", …)` method on the `Form<T>` builder** that auto-wires name/value/error from state (which a standalone component cannot do). Discovery: [`../10-discovery/track-a-app-apis/a01-forms-validation.md`](../10-discovery/track-a-app-apis/a01-forms-validation.md); cross-ref [`template-cross-reference.md`](./template-cross-reference.md).

## Deliberately deferred / already shipped in 6.1.x

**Already shipped in 6.1.x (verified against CHANGELOG — do NOT re-propose):** popover (`setPopover`/`setPopovertarget`/`popovertargetaction`); native `<dialog>` (`setClosedby`, `formmethod="dialog"`, `command`/`commandfor("show-modal")`); anchor positioning (`anchorName`/`positionAnchor`/`positionArea`/`viewTransitionName` inline-style emitters); `setMicrodata`; the editing/i18n global setters (`setContenteditable`/`setEnterkeyhint`/`setSpellcheck`/`setAutocapitalize`/`setLang`/`setDir`/`setTranslate`); `setHidden("until-found")`; `setForm`/`setList`/`setFor` by `Id`; the `Form<T>` typed builder (`input`/`textarea`/`select`/`hidden`/`checkbox`/`radio`/`error`); `ForEachKeyed`; `addChild`/`addStyle`; `has-`/`group-has-`/`peer-has-`/`in-` relational state hooks; closed sizing unions; unit overloads for `textSize`/`leading`/`tracking`/`underlineOffset`; the `FluentCustomMethods` seam; `defineRoutes` typed+enum params.

**Re-scoped after verification:**
- **`whenElse` boolean + value-narrowing form** — CHANGELOG 6.1.1 confirms `when`/`whenElse` already branch on `!= null` with `NonNullable<T>` narrowing and accept `(tag)=>unknown`. Only the *explicit two-branch nullable overload that passes the unwrapped value into `ifFn`* (#33) is potentially net-new — **re-verify before building**; if `whenElse(value, ifFn(v), elseFn)` already passes `v`, drop the item entirely.
- **`size()` / `container()`** — confirmed **absent** (only `resize` and `containerQuery` exist), so #1 and #5 are genuine adds, not duplicates.

**Deferred out of 6.2.0:**
- **Logical sizing `inlineSize`/`blockSize`** (#74) — niche until an app goes RTL; weigh against the converge / one-way-to-do-each-thing rule.
- **Opinionated style mixins** `focusRing`/`disabledStyle` (#70) — edge toward shipping a design system; prefer expressing these via `variants()` (#19) in user-land. Ship only the unstyled-token form if at all.
- **`reply` decorator / `renderView(HxResponse)` integration** — framework-glue; routes to `@fluent-html/fastify`, not core (only the pure `HxResponse.status` descriptor lands here).
- **9 + 6 + 4 = 19 cross-track duplicate proposals** were merged during per-track synthesis (e.g. `size` from a04+c06; `accentColor`/`caretColor`/`scheme`/`fieldSizing` from c01+c10; media `referrerpolicy`/sizing from b04+b05+b08). See the per-track files for the merge ledger.

- **Consolidate the `/ui` layer.** Generic components exist **twice** — `projects-template/packages/ui/src/**` (`Container`, `Stack`, `Row`, `Card`, `FormField`, inputs, `Alert`) and `templates/full-stack/src/shared/ui/**` (`Card`, `CenteredPage`, `FormGroup`, `Alert`, plus app-specific `StatCard`/`DashboardSection`/`TabNav`/skeletons).
